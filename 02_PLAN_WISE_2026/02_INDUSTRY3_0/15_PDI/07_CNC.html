1. Definition of CNC

CNC (Computer Numerical Control) is a system in which a computer-based controller executes programmed instructions to control machine-tool movements, spindle operation, tool changes, and machining processes.

A CNC system converts a part program into coordinated machine actions using axis drives, servo motors, feedback devices, spindle controls, machine PLC logic, and other supporting systems.

In industrial Pre-Delivery Inspection (PDI), CNC inspection verifies that the supplied CNC controller, machine tool, drives, motors, feedback devices, tooling interfaces, electrical systems, safety provisions, software configuration, and documentation conform to the approved specifications.

CNC PDI is not simply checking whether the controller powers up. The machine must be inspected as an integrated electromechanical system, with functional testing performed only under approved and safe conditions.

2. Objectives of CNC PDI

  • Verify the CNC machine model, configuration, capacity, and manufacturer details.
  • Confirm the CNC controller, axis drives, spindle drive, motors, and feedback devices.
  • Inspect electrical panels, wiring, earthing, cooling, and cable routing.
  • Verify axis travel, reference return, limits, and machine-coordinate configuration.
  • Check spindle operation, tool-changing systems, and auxiliary equipment where fitted.
  • Confirm CNC parameters, PLC programs, machine data, and software revisions.
  • Verify communication between the CNC, machine PLC, HMI, drives, and peripheral devices.
  • Inspect lubrication, coolant, pneumatic, hydraulic, and chip-management systems.
  • Verify guarding, interlocks, emergency stops, and other required safety functions.
  • Review machining capability, geometric accuracy, repeatability, and acceptance-test records.
  • Confirm software backups, maintenance documentation, and defect closure.

The CNC controller calculates the required motion from the part program. The drives convert control commands into motor operation, while feedback devices report actual motion. The machine PLC manages auxiliary sequences such as tool changing, clamping, lubrication, coolant, and machine-state coordination.

The exact division of responsibilities varies by CNC platform and machine builder.

5. CNC Machine Types and Applications

Machine type Primary function Typical application
CNC turning center Rotates the workpiece while cutting tools remove material Shafts, hubs, cylindrical components
CNC machining center Uses a rotating tool to machine a stationary or indexed workpiece Housings, brackets, complex components
CNC milling machine Removes material using rotating cutting tools Surfaces, slots, pockets, profiles
CNC grinding machine Uses an abrasive wheel for precision finishing Shafts, bearing surfaces, precision diameters

PDI must verify the actual machine configuration rather than assuming that all machines described as machining centers or turning centers have identical capabilities.

6. CNC Controller and Machine Builder

The CNC controller is the numerical-control platform. The machine builder integrates it with the machine structure, tooling, drives, sensors, hydraulic systems, PLC sequences, and safety systems.

Examples of CNC control platforms include Siemens SINUMERIK, FANUC CNC, and Haas CNC controls. Machine builders such as DMG MORI, Mazak, Makino, Okuma, and others may use different controller platforms across their product ranges.

During PDI, record both the machine builder and the actual controller model. The builder name alone is not sufficient for identifying parameters, service procedures, backup tools, or programming conventions.

Verify:

  • Controller model and installed options.
  • Axis configuration and names.
  • Spindle configuration.
  • Supported programming functions.
  • Installed software and firmware versions.
  • Machine-builder PLC and HMI software.
  • Licensed options where applicable.
  • Backup and restoration method.
  • Approved parameter and program revisions.

7. CNC Coordinate Systems

7.1 Machine coordinates

Machine coordinates define axis positions relative to the machine's reference system. They are established through the machine's reference procedure, absolute-position system, or other approved architecture.

Machine-coordinate configuration must not be changed casually. Incorrect reference or limit data can lead to overtravel or collisions.

7.2 Work coordinates

Work coordinates establish the part's reference position for machining. Common G-code work-coordinate systems include G54 through G59 on many controllers, but available systems and exact behavior depend on the control.

Verify the required work-offset configuration against the approved setup documentation.

7.3 Tool offsets

Tool offsets compensate for tool geometry and, depending on the controller and programming method, wear or other corrections.

Incorrect offsets can cause dimensional errors, tool collisions, or scrap.

7.4 Axis naming

Common axis designations include:

  • X, Y, and Z for linear axes.
  • A, B, and C for rotary axes associated with the X, Y, and Z axes respectively.

The actual axis arrangement depends on machine design. Turning centers, five-axis machines, and special-purpose machines may use different physical orientations and conventions.

7.5 Reference return and homing

A reference-return procedure establishes the required axis reference. Depending on the machine, it may use a reference switch, encoder marker, absolute encoder, or another approved system.

PDI should verify:

  • Correct reference procedure.
  • Correct axis direction.
  • Reference completion indication.
  • Expected machine-coordinate behavior.
  • Overtravel protection.
  • Recovery procedure after loss of reference where applicable.

8. CNC Program and G-Code Verification

A CNC part program defines machining operations through motion commands, spindle commands, feed rates, tool calls, offsets, and other instructions.

Typical command categories include:

Command category Common examples Purpose
Rapid motion G00 Rapid positioning
Linear interpolation G01 Controlled linear movement
Circular interpolation G02, G03 Circular movement
Plane selection G17, G18, G19 Selects the interpolation plane
Work coordinate system G54 to G59 Selects a work-coordinate system on supported controls
Absolute or incremental positioning G90, G91 Selects positioning interpretation on supported controls
Spindle control M03, M04, M05 Spindle direction and stop commands
Tool change M06 on supported configurations Requests a tool change
Program end M30 on many controls Ends and resets the program state according to control behavior

G-code and M-code behavior can vary by controller, machine builder, and configuration. Some codes are modal, some require machine-specific handling, and some may be reassigned.

PDI principle: Verify program compatibility and machine-builder conventions. Do not assume that a program safe on one CNC machine is automatically safe on another.

8.1 Program verification

Check:

  • Program identity and revision.
  • Correct units and coordinate assumptions.
  • Tool calls and tool-offset references.
  • Work-offset references.
  • Feed and spindle-speed limits.
  • Safe approach and retract positions.
  • Required auxiliary functions.
  • Tool-change sequence.
  • Program-end behavior.
  • Approved simulation or dry-run evidence where required.

Use graphics simulation, approved dry-run modes, and other manufacturer-supported verification tools as appropriate. Simulation does not replace machine-specific safety checks.

9. CNC Axis Drive and Feedback Inspection

9.1 Servo drive and motor

Verify the axis drive and motor combination against the machine documentation. Inspect power connectors, feedback cables, cooling, grounding, and diagnostic status.

Confirm the correct axis-to-drive mapping. Incorrect mapping can cause a command intended for one axis to affect another axis or create unexpected movement.

9.2 Encoder and linear scale

Feedback may be provided by a motor-mounted encoder, a linear scale, or a combination of devices.

Check:

  • Feedback-device compatibility.
  • Correct connector and cable.
  • Feedback diagnostics.
  • Resolution and scaling.
  • Direction and sign conventions.
  • Position feedback plausibility.
  • Required compensation data.
  • Cable protection and routing.

A linear scale can measure actual table or slide position and may improve accuracy by reducing the effect of transmission errors. It also introduces requirements for correct scale installation, alignment, and feedback configuration.

9.3 Axis performance

Where the acceptance plan requires it, verify:

  • Smooth travel through the approved range.
  • Positioning accuracy.
  • Repeatability.
  • Backlash or reversal behavior.
  • Following error.
  • Vibration and abnormal noise.
  • Limit and reference behavior.
  • Axis synchronization where applicable.

Acceptance limits must come from the approved machine specification or applicable test standard, not from invented generic tolerances.

10. Spindle System Inspection

The spindle rotates the cutting tool or workpiece depending on the machine type.

PDI checks may include:

  • Spindle motor model and rating.
  • Drive compatibility.
  • Speed range.
  • Spindle orientation function.
  • Encoder or speed feedback.
  • Tool-holder interface.
  • Bearing condition where inspectable.
  • Cooling and lubrication.
  • Vibration and noise.
  • Required runout or accuracy measurements.
  • Spindle-load and alarm display.

For machines with automatic tool changers, verify that spindle orientation and tool-release functions follow the specified sequence.

Do not command high-speed rotation merely to prove that the spindle works. The permitted speed, tool-holder condition, guarding, and test method must be established first.

11. Automatic Tool Changer and Tool Magazine

The automatic tool changer (ATC) transfers tools between the magazine and spindle or another defined machine position.

Typical components include:

  • Tool magazine.
  • Tool pockets or chain.
  • Tool gripper or arm.
  • Tool-presence sensors.
  • Magazine position sensors.
  • Spindle orientation interface.
  • Tool-release mechanism.
  • Pneumatic or hydraulic actuators where fitted.
  • PLC sequence logic.

PDI should verify:

  • Correct magazine and tool-holder configuration.
  • Tool-pocket identification.
  • Tool-presence detection.
  • Tool-change sequence.
  • Spindle orientation.
  • Clamping and unclamping feedback.
  • Door and access interlocks.
  • Recovery procedure after an interrupted tool change.
  • Relevant alarms and diagnostics.

An ATC sequence should not be tested with hands or loose objects in the mechanism. Use approved tooling, guarding, and recovery procedures.

12. CNC Machine Auxiliary Systems

12.1 Lubrication

Verify lubricant type, level, delivery, pressure or flow indication where specified, and low-level alarms.

Insufficient lubrication can damage guideways, ball screws, bearings, and other moving components.

12.2 Coolant

Check coolant tank condition, pump operation, delivery paths, filtration, leakage, and level monitoring.

For through-spindle coolant or high-pressure coolant systems, verify the specific pressure and safety requirements.

12.3 Pneumatics and hydraulics

Inspect:

  • Supply pressure.
  • Regulators and filters.
  • Hoses and fittings.
  • Valve operation.
  • Cylinder movement.
  • Pressure switches.
  • Clamping feedback.
  • Leakage.
  • Stored-energy hazards.

Pressure settings must match the machine specification. Do not increase pressure to overcome a sequence or clamping fault without investigating the cause.

12.4 Chip conveyor and extraction

Check conveyor direction, motor protection, guards, jam detection where fitted, and chip-discharge arrangements.

Verify that chip-management equipment does not interfere with machine travel, access, or maintenance.

13. CNC Electrical Panel and Wiring

Inspect:

  • Incoming supply and protective devices.
  • Control-power supplies.
  • CNC and PLC hardware.
  • Servo and spindle drives.
  • Terminal condition and labeling.
  • Protective earthing and bonding.
  • Shield termination.
  • Cable segregation.
  • Panel cooling and filtration.
  • Network switches and communication wiring.
  • Electrical drawings and actual installation consistency.

Power cables and low-level feedback or communication cables should be routed and shielded according to the approved design and manufacturer requirements.

Do not insulation-test a connected CNC controller, drive, encoder, or electronic module without following the manufacturer-approved isolation procedure. Test voltages can damage sensitive electronics.

14. CNC PLC, HMI, and Sequence Integration

The CNC and machine PLC coordinate the machining program with auxiliary machine functions.

Typical PLC-managed functions include:

  • Door and guard status.
  • Clamping and unclamping.
  • Tool-change sequencing.
  • Coolant and lubrication.
  • Chip conveyor operation.
  • Hydraulic and pneumatic permissives.
  • Machine-ready conditions.
  • Alarm handling.
  • Mode-dependent operation.

PDI should verify the interface between the CNC and PLC rather than testing each device in isolation only.

For example, a machining cycle may require the CNC to request a clamp, the PLC to operate the clamp valve, and a sensor to confirm the clamp state. The sequence should proceed only when the required conditions are satisfied.

Check that:

  • Requests and acknowledgments are correctly mapped.
  • Timeouts produce appropriate alarms.
  • Missing feedback prevents unsafe sequence progression.
  • HMI indications match the actual machine state.
  • Fault recovery follows the approved procedure.
  • Software revisions match the accepted configuration.

15. CNC Safety Inspection

CNC machines combine rotating tools, moving axes, sharp tooling, workholding systems, high electrical energy, and potentially high-pressure fluids.

Inspect the safety provisions specified for the machine, including:

  • Emergency-stop devices.
  • Guard doors and interlocks.
  • Required guard-locking functions.
  • Safe operating modes.
  • Safe speed or motion functions where provided.
  • Overtravel protection.
  • Workholding and clamping safeguards.
  • Tool-change access protection.
  • Electrical isolation and lockout provisions.
  • Warning labels and safe access.
  • Safety-related control configuration and validation records.

The presence of an emergency-stop button does not establish that the machine's safety system is compliant. Required functions must be verified against the risk assessment, design, and validation plan.

Never bypass an interlock to complete an inspection. Safety-function tests must follow the approved validation procedure and be performed by authorized personnel.

16. CNC Accuracy and Acceptance Testing

The exact tests depend on machine type, specification, contract, and applicable standards.

Test Purpose Typical verification
Axis travel test Confirms permitted movement Travel range, smoothness, limit behavior
Positioning accuracy Evaluates commanded versus actual position Measurement against specified tolerance
Repeatability Evaluates consistency across repeated moves Variation across repeated positioning
Backlash or reversal test Evaluates motion behavior when direction changes Measured reversal error against criteria
Spindle runout Evaluates rotational accuracy Measurement at specified locations
Geometric accuracy Evaluates alignment and machine geometry Applicable geometry test results
Thermal behavior Evaluates performance under specified operating conditions Drift or dimensional change where required
Test-piece machining Evaluates integrated machining performance Dimensions, surface finish, and other specified characteristics
Tool-change test Verifies automatic tool handling Correct sequence, clamping, feedback, recovery
Alarm and interlock tests Verifies response to defined conditions Expected alarm and safe response
Continuous operation test Evaluates sustained operation Stability, alarms, temperature, and performance

Measurement methods and acceptance limits must be defined in the approved test plan. Precision measurements require suitable calibrated instruments and controlled measurement conditions.

17. CNC Fault Diagnosis

Symptom Possible causes Verification approach
Axis will not move Drive fault, missing enable, active interlock, limit condition Check CNC and drive diagnostics, machine state, and permissives
Reference return fails Sensor fault, feedback issue, incorrect reference configuration Check reference signals and manufacturer-approved diagnostic data
Following error Mechanical obstruction, feedback fault, tuning or load issue Inspect diagnostics, mechanics, and approved control settings
Spindle will not start Spindle-drive fault, missing permissive, clamp or orientation condition Review spindle status, interlocks, and drive diagnostics
Tool change fails Sensor mismatch, actuator problem, sequence timeout Check tool-change state, sensor feedback, and pneumatic or hydraulic supply
Poor dimensional accuracy Tool offsets, work offsets, thermal drift, geometry, tool wear Verify setup, measurements, tool condition, and machine accuracy
Surface finish is poor Tool condition, vibration, cutting parameters, spindle or axis issue Inspect tooling, process settings, vibration, and machine condition
Lubrication alarm Low level, blocked line, pump fault, sensor fault Check supply, delivery, pump, and monitoring signals
Communication alarm Network issue, configuration mismatch, controller fault Check network diagnostics, settings, and device status
Repeated program interruption Program logic, auxiliary timeout, machine condition, safety or permissive state Capture alarm history and trace the sequence before changing logic

Fault symptoms do not prove a particular root cause. Preserve diagnostic evidence and investigate the initiating condition before modifying parameters or replacing components.

18. CNC Software Backup and Configuration Control

The handover package should contain the required versions of:

  • CNC machine parameters.
  • CNC part programs.
  • Tool and work-offset data where applicable.
  • PLC program and hardware configuration.
  • HMI application.
  • Servo and spindle drive parameters.
  • Compensation and calibration data.
  • Network configuration.
  • Machine-builder options and settings.
  • Safety-related configuration and validation records.
  • Manuals, drawings, and restoration procedures.

The backup method must be compatible with the controller and software revision. A partial parameter export may not restore the complete machine configuration.

Record the final accepted revision and protect backup files from unauthorized modification. Any later parameter change should follow the site's configuration-control process.

19. CNC PDI Versus FAT and SAT

Activity Primary purpose CNC verification examples
PDI Verify pre-delivery conformity and condition Hardware, ratings, wiring, software identity, documentation
FAT Verify specified functionality before shipment Axis operation, spindle functions, tool change, alarms, accuracy tests
SAT Verify the installed system at the destination Site utilities, foundations, connections, network integration, production readiness
Production validation Confirm suitability for actual production requirements Approved cycle, part quality, repeatability, process capability where required

PDI may include functional checks when specified, but it does not automatically replace FAT, SAT, or production-process validation.

20. Practical Automotive Manufacturing Example

Consider a CNC machining center used to machine an automotive transmission housing.

The PDI inspection identifies the following issues:

  • The CNC controller model matches the specification, but the PLC software revision differs from the approved record.
  • One axis drive reports normal status, but the reference-return test has not been documented.
  • The automatic tool changer completes a tool exchange, but the tool-clamped feedback is not correctly displayed on the HMI.
  • The lubrication low-level alarm does not appear during the approved alarm verification.
  • The CNC parameter backup does not match the installed machine configuration.
  • The geometric accuracy report is missing a required measurement.

The correct response is to record each discrepancy, verify the required software revision, complete the authorized reference-return test, correct and retest the tool-clamped indication and lubrication alarm, create a verified configuration backup, and obtain the missing measurement evidence.

A successful machining cycle alone is not enough to close these defects. Correct machine status, fault detection, safety-related behavior, configuration control, and documented acceptance evidence matter as well.

21. Common CNC PDI Mistakes

  • Checking the controller but ignoring the complete machine system.
  • Assuming all CNC platforms use identical G-codes, M-codes, and parameters.
  • Ignoring the difference between machine coordinates and work coordinates.
  • Accepting axis movement without verifying direction, reference, and limits.
  • Ignoring tool-offset and feedback configuration.
  • Assuming an ATC is acceptable because one tool change succeeded.
  • Treating a drive-ready indication as proof of axis accuracy.
  • Changing machine parameters without authorization.
  • Bypassing guards or interlocks during testing.
  • Accepting missing geometric or machining test evidence.
  • Ignoring lubrication, coolant, and hydraulic or pneumatic systems.
  • Failing to verify software and backup revisions.
  • Clearing faults before preserving useful diagnostic evidence.
  • Closing defects without documented retesting.

22. Interview Questions and Answers

Q1. What is CNC?

CNC is a computer-based control system that executes programmed instructions to control machine-tool movements and machining operations.

Q2. What is the difference between CNC and PLC?

CNC specializes in numerical control and coordinated machining motion. A PLC commonly manages machine sequences, auxiliary equipment, interlocks, and general automation logic. Their functions can overlap depending on the architecture.

Q3. What is interpolation?

Interpolation calculates the coordinated axis movement needed to follow a programmed path, such as a straight line or circular arc.

Q4. What is the difference between machine coordinates and work coordinates?

Machine coordinates refer to the machine's reference system. Work coordinates establish the part's reference position for machining.

Q5. Why are tool offsets important?

Tool offsets account for tool geometry and related corrections so that the programmed path produces the intended machined dimensions.

Q6. What is a following error?

Following error is the difference between the commanded position and the actual position reported by the motion-feedback system, as defined by the controller.

Q7. Why is a linear scale used on some CNC axes?

A linear scale measures actual linear position and can improve positioning accuracy by providing feedback closer to the physical axis movement.

Q8. What is the function of a spindle drive?

It controls spindle motor operation, including speed and torque-related behavior, and supports functions such as orientation where configured.

Q9. What is an ATC?

An automatic tool changer transfers tools between the magazine and spindle or another specified location according to the machine's sequence logic.

Q10. Why should CNC parameters be backed up?

A verified backup supports recovery after controller replacement, hardware failure, configuration changes, or other events that affect machine operation.

Q11. Why can a CNC machine run but still fail acceptance?

It may have inaccurate positioning, incorrect software revisions, defective interlocks, missing alarms, dimensional errors, or incomplete test evidence despite being able to execute a program.

Q12. What is the key principle of CNC PDI?

Verify the CNC machine as an integrated system, including motion, machining, auxiliary sequences, electrical controls, safety, accuracy, software configuration, and acceptance evidence.

23. Final CNC PDI Checklist

  • Machine identity, configuration, and controller model match the approved specification.
  • CNC, PLC, HMI, drive, and firmware revisions are recorded and verified.
  • Electrical panels, power wiring, earthing, shielding, and cooling are inspected.
  • Axis drives, motors, feedback devices, and mechanical transmissions are verified.
  • Machine coordinates, reference return, travel limits, and axis mapping are checked.
  • Spindle operation, speed feedback, and required orientation functions are verified.
  • Tool changer, magazine, clamping, and tool-presence feedback are checked.
  • Lubrication, coolant, pneumatics, hydraulics, and chip handling are inspected.
  • PLC and CNC sequence interfaces, alarms, and status mapping are verified.
  • Guards, interlocks, emergency stops, and other required safety functions are validated.
  • Required accuracy, repeatability, geometric, and machining tests are documented.
  • Fault diagnostics and approved recovery procedures are verified.
  • CNC parameters, PLC programs, drive settings, and required calibration data are backed up.
  • Defects are recorded, corrected, retested, and closed with evidence.
  • Required engineering, quality, and safety approvals are complete.

Key principle: CNC PDI establishes whether the delivered machine conforms to its specified configuration and can proceed through the required acceptance process with its motion, machining, auxiliary systems, safety functions, and documentation verified.
