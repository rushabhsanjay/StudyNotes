1. Definition and Purpose

CNC parameters are configuration values stored in a Computer Numerical Control system that determine how the controller operates the machine, interprets commands, controls axes and spindles, applies compensation, and communicates with other machine components.

Parameters define the operating characteristics of the CNC and its machine-builder configuration. They are different from the machining program itself. A G-code program tells the machine what operations to perform, while parameters help determine how the controller and machine execute those operations.

CNC parameters may control:

  • Axis movement, direction, scaling, speed, acceleration, and travel limits.
  • Servo motor and feedback-system configuration.
  • Spindle speed ranges, orientation, and synchronization.
  • Machine reference return and coordinate behavior.
  • Backlash, pitch-error, and other compensation functions.
  • Tool changer, probing, rigid tapping, and other machine-specific functions.
  • Communication, input/output behavior, alarms, and display settings.
  • Machine-builder options and controller-specific functions.

Incorrect parameters can cause inaccurate positioning, unexpected axis movement, servo alarms, spindle problems, failed reference return, tool-change faults, or machine collisions. Parameter management is therefore a controlled engineering activity, not a trial-and-error exercise.

2. CNC Parameters vs Other CNC Data

Several types of data coexist in a CNC system. They must be distinguished before troubleshooting or making changes.

Data type Purpose Example
CNC parameters Configure controller and machine behavior Axis scaling or spindle configuration
Part program Defines machining operations G01 linear cutting move
Tool geometry offsets Account for tool dimensions Tool length offset
Tool wear offsets Correct small changes in tool condition or size Wear correction
Work offsets Define workpiece coordinate origins G54 work coordinate system
Macro variables Store values used by parametric programs Part count or calculated position
CNC PLC/ladder program Controls machine sequence and interlocks Clamp confirmation before spindle start
Servo-drive parameters Configure drive and motor behavior Motor feedback or drive control settings
Spindle-drive parameters Configure spindle drive behavior Motor control and speed regulation
Compensation tables Correct known machine positioning errors Pitch-error compensation table
Safety configuration Implements validated safety functions Safety-rated stop or safe speed configuration
Firmware and options Define controller software and enabled functions Controller software revision or licensed feature

The exact division depends on the machine architecture. Some settings are managed through CNC parameter screens, others through the PLC, servo drive, spindle drive, or machine-builder service tools.

Important: A parameter, an offset, and a compensation table are not interchangeable. Changing a tool offset cannot correctly repair a machine-axis scaling error, and changing a machine parameter is not an appropriate way to compensate for an incorrectly measured tool.

3. Parameter Organization and Numbering

CNC manufacturers organize parameters differently. The parameter number, name, data type, unit, and permitted range depend on the controller model, software version, machine configuration, and machine-builder implementation.

Common CNC platforms include:

  • FANUC CNC systems.
  • Siemens SINUMERIK systems.
  • Mitsubishi CNC systems.
  • Haas CNC controls.
  • Okuma OSP controls.
  • HEIDENHAIN controls.

Even machines using the same controller family may have different parameter assignments because of differences in axes, motors, feedback devices, options, and machine-builder logic.

Parameters may be presented as:

  • Numbered bit settings.
  • Integer values.
  • Decimal or floating-point values.
  • Axis-specific values.
  • Channel-specific or spindle-specific values.
  • Tables or structured records.
  • Read-only diagnostic values.
  • Protected or password-restricted settings.

A parameter number should never be treated as universal. Always identify the exact CNC model, software version, machine model, and applicable machine-builder documentation before referring to a parameter.

4. Major Categories of CNC Parameters

Category Typical function Example of an incorrect setting
System configuration Defines enabled functions and general control behavior An expected function is unavailable
Axis configuration Defines axis identity, direction, and operating characteristics Wrong axis responds to a command
Scaling and units Converts command units into physical movement Commanded distance differs from actual travel
Servo control Configures feedback and control-loop behavior Oscillation or following-error alarms
Spindle control Defines spindle behavior and operating ranges Incorrect speed or orientation behavior
Reference return Establishes machine reference position Incorrect homing or reference-return failure
Travel limits Defines permissible axis travel Unexpected soft-limit alarm or unsafe travel
Acceleration and deceleration Controls motion transitions Excessive jerk or poor cycle performance
Compensation Corrects characterized machine errors Dimensional inaccuracy
Tool changer Coordinates tool-change functions Tool change stops during sequence
Probing and measurement Configures supported measurement functions Incorrect probing result
Rigid tapping and synchronization Coordinates spindle and axis motion Threading or synchronization error
I/O and communication Configures interfaces and data exchange Missing or incorrect device communication
Display and operation Controls selected operating behavior Unexpected screen or operation behavior
Diagnostic and alarm settings Supports fault reporting and monitoring Fault information is incomplete or misleading

Some settings overlap categories. For example, rigid tapping depends on CNC functionality, spindle feedback, axis control, and machine-builder sequencing.

5. Axis Configuration Parameters

Axis parameters determine how each machine axis is identified and controlled. A typical machining center may have X, Y, and Z linear axes, with additional rotary axes such as A, B, or C.

Important axis-related settings include:

  • Axis assignment and configuration.
  • Command and feedback scaling.
  • Positive and negative direction.
  • Linear or rotary axis characteristics.
  • Permitted travel range.
  • Maximum feed and rapid-traverse limits.
  • Acceleration and deceleration characteristics.
  • Reference-return behavior.
  • Servo feedback configuration.
  • Positioning and following-error monitoring.
  • Backlash or other supported compensation.

5.1 Axis scaling

Axis scaling determines how the controller converts an internal command into physical displacement.

For a linear axis, the relationship can be represented conceptually as:

\[ \text{Actual displacement} = \text{Commanded displacement} \times \text{Scaling ratio} \]

If the machine is configured incorrectly after a motor, encoder, ballscrew, gearbox, or drive replacement, the commanded displacement may no longer match the actual displacement.

For example, if the controller commands 100 mm of travel but the axis moves only 50 mm, possible causes include incorrect scaling, an incorrect electronic gear ratio, feedback configuration, or a mechanical transmission mismatch. The symptom alone does not prove which parameter is wrong.

For a rotary axis, scaling must also account for the relationship between motor rotation, mechanical gearing, and table or workpiece rotation.

5.2 Axis direction

Axis direction settings affect the relationship between positive CNC commands and physical movement.

An incorrect direction can create a dangerous condition because a positive command may move the axis toward an unexpected part of its travel envelope. Direction must be checked against machine coordinates, feedback polarity, drive configuration, and the machine-builder's documented commissioning procedure.

Do not change a direction parameter merely because a displayed coordinate appears unusual. First establish whether the problem is in the coordinate system, feedback polarity, mechanical installation, or parameter configuration.

5.3 Travel limits

CNC systems commonly use software-defined travel limits alongside physical limit switches and other protective devices.

Soft limits restrict commanded movement within a configured range. Hardware limits or safety-related devices may provide separate protection, depending on the machine design.

Travel-limit parameters must not be widened or disabled simply to clear an alarm. An alarm may indicate incorrect machine coordinates, a failed reference return, a feedback problem, or a genuine obstruction.

6. Servo and Motion Parameters

Servo-related settings govern how the CNC and servo drive control motor movement and position.

Relevant settings can include:

  • Motor and feedback-device configuration.
  • Electronic gearing and command scaling.
  • Position-loop and speed-loop behavior.
  • Gain and response settings.
  • Acceleration and deceleration.
  • Torque or current limits.
  • Following-error thresholds.
  • In-position detection.
  • Oscillation suppression or supported filtering.
  • Thermal and overload-related settings.

The exact parameter ownership varies. Some settings are stored in the CNC, while others reside in the servo amplifier.

6.1 Following error

Following error is the difference between commanded position and measured position, subject to the controller's specific definition and filtering.

\[ e(t) = x\_{\text{commanded}}(t) - x\_{\text{measured}}(t) \]

A large or persistent following error may result from mechanical binding, excessive load, a feedback fault, incorrect scaling, a drive fault, unsuitable tuning, or incorrect acceleration demands.

Increasing the permitted following-error threshold without diagnosing the cause can conceal a real motion-control problem. The correct response is to inspect the alarm history, drive diagnostics, feedback signals, mechanics, and relevant configuration.

6.2 Servo tuning

Servo tuning determines the response of the motion-control system. Incorrect settings can produce oscillation, vibration, overshoot, sluggish response, or unstable positioning.

Tuning must follow the controller and drive manufacturer's procedure and the machine builder's requirements. Changes should be made by authorized personnel using appropriate diagnostic tools and controlled test conditions.

A servo parameter is not a universal performance knob. Increasing gain does not automatically make an axis better, just as turning up a radio does not improve a bad signal.

7. Spindle Parameters

Spindle parameters influence rotational control, speed limits, orientation, and synchronization with axis motion.

Common functions include:

  • Spindle motor and feedback configuration.
  • Minimum and maximum spindle speeds.
  • Gear range or transmission selection.
  • Speed command scaling.
  • Spindle acceleration and deceleration.
  • Spindle orientation.
  • Encoder feedback and position detection.
  • Rigid tapping or other synchronized operations.
  • Supported constant-surface-speed functions.
  • Spindle-drive alarms and operating limits.

An incorrect spindle configuration can cause speed discrepancies, orientation faults, synchronization errors, or unexpected behavior during machining.

Do not increase the spindle speed limit simply because a program requests a higher RPM. Confirm the motor rating, spindle assembly rating, tooling limits, gear range, drive limits, machine-builder specifications, and applicable safety requirements.

Spindle parameters may be divided between the CNC and spindle drive. A CNC speed command, drive speed limit, and machine-builder restriction may all affect the final behavior.

8. Reference Return and Position-Related Parameters

Reference return establishes the machine's reference position so the controller can relate its internal coordinate system to the physical machine.

Relevant configuration may include:

  • Reference-return direction and sequence.
  • Reference switch behavior.
  • Encoder index or reference-mark handling.
  • Reference position and associated offsets.
  • Absolute encoder configuration.
  • Axis-specific reference-return logic.

The actual implementation differs between incremental and absolute feedback systems.

After a battery failure, encoder replacement, motor replacement, feedback-system repair, or parameter restoration, the controller may require reference recovery or a manufacturer-defined recovery procedure.

A displayed coordinate is not sufficient proof that the physical axis position is correct. Machine coordinates, work coordinates, tool offsets, and actual mechanical position must be distinguished.

Never force a reference-return operation when the axis position is uncertain or the machine may collide with a fixture, tool, or hard stop. Follow the documented recovery procedure and verify the travel envelope before resuming automatic operation.

9. Compensation Parameters and Tables

Compensation corrects specific, characterized errors in the machine or measurement chain. It should not be used to hide an unresolved mechanical or feedback fault.

Compensation type Purpose Important limitation
Backlash compensation Addresses a measured reversal-related positioning error Cannot repair a worn or damaged transmission
Pitch-error compensation Corrects characterized position-dependent lead-screw or axis errors Requires reliable measurement and correct table data
Thermal compensation Corrects supported temperature-related errors Depends on valid thermal models or measurements
Tool length offset Accounts for tool length Does not correct machine-axis geometry
Tool radius compensation Adjusts tool-path behavior for cutter radius Does not correct a faulty axis scale
Work offset Defines the workpiece coordinate origin Does not establish the machine reference position

Compensation may be implemented through CNC parameters, dedicated tables, tool data, or other controller-specific mechanisms.

Before changing compensation, establish the original measurement, measurement method, environmental conditions, and expected correction. Incorrect compensation can create a machine that appears accurate at one position but produces larger errors elsewhere.

10. Machine-Builder and Sequence Parameters

The machine builder integrates the CNC with the physical machine. This can introduce parameters or configuration data for:

  • Tool changer operation.
  • Pallet changers.
  • Hydraulic and pneumatic systems.
  • Clamping and unclamping sequences.
  • Probe and tool-measurement systems.
  • Coolant and lubrication functions.
  • Door and guard status interfaces.
  • Machine-specific operating modes.
  • Special machining cycles.
  • Auxiliary axes and attachments.

These functions may depend on both CNC parameters and the CNC PLC or ladder program.

For example, a tool change may require the CNC to request a change, the PLC to verify the machine conditions, and the mechanical system to complete the sequence. A failure could result from incorrect configuration, a sensor fault, a missing permissive, a PLC sequence problem, or a mechanical issue.

Changing a parameter without understanding its interaction with the ladder program can create a fault that is difficult to diagnose and may compromise intended machine protection.

11. CNC Parameters and PLC Interlocks

The CNC controller and machine PLC have related but distinct responsibilities.

  • CNC configuration governs controller functions such as motion behavior, coordinate handling, and supported machining operations.
  • PLC logic governs machine sequences, device control, status handling, and permissive conditions.
  • Servo and spindle drives execute motion or rotational control using their own configuration.
  • Safety-related systems implement protective functions according to the machine's safety architecture.

A parameter change can alter the signals, timing, or operating conditions seen by the PLC. Likewise, a PLC modification can change how a parameter-controlled function is initiated or completed.

When troubleshooting, identify which layer owns the behavior. Do not modify CNC parameters to compensate for a failed proximity switch, a defective solenoid valve, or a broken PLC interlock unless the approved engineering analysis specifically identifies a configuration issue.

12. Parameter Backup and Recovery

A parameter backup is a critical part of CNC maintenance, commissioning, retrofit, and controller replacement.

A proper backup process should consider:

  • CNC parameter files.
  • Axis and spindle configuration.
  • Compensation tables.
  • Machine-builder data.
  • CNC PLC or ladder program and associated data, where applicable.
  • Servo and spindle-drive configuration.
  • Tool and work data when required by the recovery plan.
  • Controller firmware and software version.
  • Enabled options, licenses, and machine-specific configuration.
  • Machine identity, controller model, date, and revision.

The required backup scope depends on the controller and machine. A single parameter file may not contain everything required to restore a machine to its previous operating condition.

12.1 Backup procedure

  1. Identify the machine, CNC model, software revision, and machine-builder configuration.
  2. Obtain authorization and follow the manufacturer's backup procedure.
  3. Export the required configuration data using supported tools.
  4. Verify that the files are readable and that the backup operation completed successfully.
  5. Record the date, source machine, software revision, and backup scope.
  6. Store the backup in the approved location with suitable access control.
  7. Maintain a second approved copy according to site policy.
  8. Where practical, validate the recovery process using an approved test or restoration procedure.

A backup should be traceable to a specific machine and configuration state. A file named CNC_BACKUP_FINAL is not an adequate asset-management system.

12.2 Restore precautions

Before restoring parameters:

  • Confirm the target machine and controller identity.
  • Check compatibility with the CNC software and machine configuration.
  • Confirm the backup source and date.
  • Determine whether restoration will overwrite compensation, axis settings, machine-builder data, or other critical information.
  • Follow the manufacturer-defined sequence.
  • Confirm whether reference return or additional commissioning is required afterward.
  • Test the machine under controlled conditions before releasing it for production.

Restoring parameters from a similar machine is not automatically safe. Two machines with the same CNC model may use different motors, encoders, gear ratios, axes, travel ranges, or machine-builder options.

A battery is not a substitute for a backup. Battery-backed memory may retain selected data, but it does not provide a verified recovery copy.

13. Safe Parameter-Change Procedure

Parameter changes should be treated as controlled configuration changes.

  1. Define the symptom. Record the alarm, operating condition, affected axis or function, and recent maintenance history.
  2. Diagnose the cause. Check mechanical condition, wiring, feedback, drive alarms, PLC status, and diagnostic values before assuming a parameter is responsible.
  3. Consult documentation. Use the correct CNC manual, machine-builder documentation, parameter list, and revision.
  4. Obtain authorization. Follow site procedures for safety-critical, motion-related, spindle-related, or protected settings.
  5. Back up the current configuration. Preserve the existing values and required related data.
  6. Record the original value. Include the parameter identity, axis or channel, units, date, reason, and approving person.
  7. Plan a controlled change. Change only the necessary setting or logically related group of settings.
  8. Apply the change using the approved method. Observe whether a restart, power cycle, reference return, or additional setup is required.
  9. Test under controlled conditions. Use the manufacturer's specified test procedure, suitable clearances, and reduced-risk operating conditions.
  10. Verify the result. Check alarms, direction, scaling, travel limits, accuracy, sequence behavior, and required interlocks.
  11. Restore if necessary. If the change does not produce the intended result, use the approved rollback procedure rather than making successive undocumented changes.
  12. Update records. Store the final values, backup reference, test result, and change approval.

Some parameters can only be changed under specific machine states or service modes. Follow the machine's instructions instead of assuming that a setting can be changed safely while the machine is running.

14. Parameter Register and Change Control

A parameter register creates traceability for configuration changes and supports preventive maintenance, troubleshooting, audits, and controller replacement.

A practical register may include these fields:

Field Purpose
Machine ID Identifies the physical machine
CNC model Identifies the controller family and model
Software revision Supports configuration compatibility
Parameter identity Records the number or exact documented name
Axis or channel Identifies where the parameter applies
Description States the function in engineering terms
Unit and data type Prevents incorrect interpretation
Original value Preserves the pre-change setting
Approved value Records the intended setting
Actual final value Records what was confirmed on the controller
Reason for change Connects the change to a fault or engineering requirement
Backup reference Identifies the recoverable configuration
Authorization Records approval according to site procedure
Test result Documents verification after the change
Date and technician Establishes traceability

Not every parameter needs an individual manually maintained row if an approved configuration-management system captures the full parameter set. However, significant changes must remain traceable.

For maintenance teams using SAP PM, relevant records can be linked to the equipment master, functional location, maintenance notification, work order, technical documentation, and backup repository. The exact SAP objects depend on the site's configuration.

15. Common Parameter-Related Faults

Symptom Possible configuration-related causes Other checks required
Axis travels the wrong distance Scaling or electronic gearing mismatch Mechanical transmission, encoder, drive configuration
Axis moves in an unexpected direction Direction or feedback configuration mismatch Wiring, feedback polarity, axis mapping
Following-error alarm Motion-control settings or incorrect scaling Mechanical binding, load, feedback, drive alarms
Reference return fails Reference or encoder configuration issue Switch, cable, encoder, mechanical obstruction
Spindle speed is incorrect Speed scaling, limit, or gear-range configuration Drive state, motor, transmission, command source
Rigid tapping fails Synchronization or spindle feedback configuration Encoder signal, PLC sequence, tool and process conditions
Tool change stops Machine-specific configuration interaction PLC permissives, sensors, valves, mechanical sequence
Positioning accuracy is poor Compensation or scaling issue Ballscrew, coupling, thermal condition, measurement method
Parameters revert or are lost Retention, backup, or restore issue Battery condition, memory fault, correct save procedure
Parameter checksum or configuration alarm Invalid or inconsistent data Restore history, software compatibility, approved recovery procedure

A symptom is evidence, not a diagnosis. Use the alarm history, diagnostic screen, drive status, electrical drawings, and maintenance records to narrow the cause before changing configuration data.
