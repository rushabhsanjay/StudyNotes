1. Definition and Purpose

Batteries in CNC machines provide backup power to specific electronic circuits so that selected data or electrical states can be retained when the main supply is switched off or interrupted.

Depending on the CNC controller, drive, encoder, and machine design, batteries may support:

  • Retention of machine parameters and configuration data.
  • Retention of absolute encoder position information.
  • Preservation of selected memory contents.
  • Maintenance of a real-time clock.
  • Backup of specific data in battery-backed memory.

Important: A CNC machine does not necessarily use one battery for all these functions. The controller, absolute encoder, servo system, and other modules may have separate batteries or may use different retention technologies. Some newer systems use nonvolatile memory and do not require a battery for certain functions.

A battery is not a substitute for a proper backup. If important CNC data exists only in a battery-backed memory area, battery failure or loss of backup power can result in data loss.

2. Main Battery Types and Applications

Battery application Purpose Possible consequence of failure
CNC memory backup Retains selected controller data in battery-backed memory Loss of retained data or configuration
Absolute encoder battery Powers the encoder's backup circuitry or position-retention function Position data may become invalid or require reference recovery
Servo feedback battery Supports battery-dependent absolute feedback arrangements Axis reference may need restoration
Real-time clock battery Maintains clock and date in supported hardware Clock resets or incorrect timestamps
PLC or SRAM backup Retains selected data in supported battery-backed memory Retained values or memory contents may be lost
UPS battery Provides temporary power to supported equipment Reduced backup runtime or unexpected shutdown

These functions may be combined in a particular system or supplied by separate batteries. Confirm the actual arrangement from the machine and component documentation.

3. Battery-Backup Architecture

A typical battery-backed memory arrangement works as follows:

Main Machine Supply Available
    ↓
Controller Operates Normally
    ↓
Data Stored in Memory
    ↓
Main Supply Switched Off
    ↓
Battery Supports Selected Backup Circuit
    ↓
Retained Data Preserved
    ↓
Main Supply Restored
    ↓
Controller Recovers Retained Data

The exact sequence depends on the hardware. Some data is retained in nonvolatile memory without a battery, while battery-backed memory requires a valid backup supply.

An absolute encoder battery may operate independently of the CNC memory battery. Replacing one battery does not necessarily protect the other.

4. Battery Technologies

4.1 Lithium Primary Batteries

Some CNC controllers and absolute encoders use non-rechargeable lithium batteries.

Characteristics include:

  • High energy density.
  • Long shelf life relative to many other primary battery types.
  • Low self-discharge under suitable storage conditions.
  • Availability in manufacturer-specified voltage, capacity, and package formats.

These batteries must not be recharged unless the specific product is explicitly designed for that purpose. A primary lithium battery installed in a charging circuit intended for a rechargeable battery can create a serious safety hazard.

4.2 Rechargeable Backup Batteries

Some equipment uses rechargeable backup batteries, depending on its design and age.

Characteristics include:

  • Charging behavior defined by the equipment.
  • Capacity degradation with age and operating conditions.
  • Potential failure from poor charging conditions or extended storage.
  • Replacement requirements specific to the battery and controller.

Do not assume that a battery is rechargeable based only on its appearance or voltage.

4.3 Battery Packs

Some CNC systems use assembled battery packs with multiple cells, connectors, wiring, and sometimes monitoring circuitry.

When replacing a pack, verify:

  • Exact part number or approved successor.
  • Nominal voltage.
  • Chemistry.
  • Connector and polarity.
  • Capacity and discharge characteristics.
  • Whether the pack contains monitoring or identification circuitry.
  • Whether replacement must be performed with the equipment powered.

A pack that fits physically is not necessarily electrically compatible.

5. CNC Memory Battery Versus Absolute Encoder Battery

These are two different maintenance functions and must not be confused.

Feature CNC memory battery Absolute encoder battery
Primary function Retains selected controller data Supports absolute position retention in battery-dependent feedback systems
Typical location CNC control unit or memory backup compartment Servo motor feedback system, encoder, or specified battery holder
Potential consequence of failure Parameter or retained-memory loss Loss of valid absolute-position data
Recovery after failure Restore or reload data as required Follow the specified reference recovery or absolute-position procedure
Replacement priority Based on retention risk and manufacturer requirements Based on feedback architecture and risk of losing position validity
Universal behavior No, varies by controller No, varies by encoder and servo system

Some CNC architectures retain most configuration data in nonvolatile memory, while others use battery-backed memory for particular functions. Similarly, not all absolute encoders require batteries.

Never assume that replacing the CNC battery also replaces the absolute encoder battery.

6. Battery Failure Symptoms

A weak or failed battery may produce symptoms such as:

  • Battery-low alarm.
  • Battery replacement warning.
  • Absolute encoder battery alarm.
  • Loss of date or time.
  • Memory-retention alarm.
  • Absolute-position data invalid.
  • Requirement to establish machine reference.
  • Retained data missing after power restoration.

The absence of an alarm does not prove that the battery is healthy. Some systems provide limited warning, and the warning period depends on the equipment design.

A battery alarm also does not automatically mean that data has already been lost. The controller's exact alarm description and the manufacturer's procedure determine the required action.

7. Battery Replacement Planning

Battery replacement should be based on the equipment manufacturer's specified interval, battery status, service history, and operational risk.

7.1 Identify the Correct Battery

Record the following before ordering a replacement:

  • CNC manufacturer and controller model.
  • Machine builder and machine model.
  • Relevant module or encoder designation.
  • Existing battery part number.
  • Nominal voltage and chemistry.
  • Connector type and polarity.
  • Approved replacement part number.
  • Battery installation location.
  • Required replacement procedure.

Do not identify a battery only by voltage. Different chemistries, connectors, capacities, and discharge characteristics may make apparently similar batteries unsuitable.

7.2 Review the Retention Risk

Before replacement, establish:

  • Which data the battery supports.
  • Whether the relevant data is already stored in nonvolatile memory.
  • Whether a current backup exists.
  • Whether absolute axis position may be affected.
  • Whether the machine requires a special replacement mode.
  • Whether replacement requires the controller to remain powered.
  • Whether the procedure needs an authorized technician.

This assessment prevents a routine maintenance task from becoming an unexpected CNC recovery job.

8. Replacing a Battery While Power Is Applied

Some CNC manufacturers specify replacement with the control powered so that the backup circuit remains supported by the main supply. Other systems require a different method.

There is no universal rule that all CNC batteries must be replaced with the machine powered or with the machine switched off.

Before replacement:

  1. Identify the exact controller, module, or encoder.
  2. Obtain the machine-builder or manufacturer-approved procedure.
  3. Confirm whether the relevant circuit must remain powered.
  4. Check whether any special operating mode is required.
  5. Verify the correct battery part number and polarity.
  6. Prepare the replacement and tools before beginning.
  7. Follow the specified sequence without improvisation.
  8. Confirm that the warning clears and the retained data remains valid.

If the procedure requires powered replacement, qualified personnel must follow the applicable electrical safety requirements and avoid contact with exposed energized circuits. If the procedure requires isolation, follow the isolation instructions and understand the data-retention consequences before disconnecting power.

Do not remove a battery first and then search for the replacement procedure. That sequence is an excellent way to convert preventive maintenance into data recovery.

9. Absolute Encoder Battery Maintenance

Some absolute encoders maintain position information through a battery-dependent backup arrangement. The details vary significantly by encoder and drive family.

Important concepts

  • Absolute position: A feedback value that identifies position within the encoder's supported measurement range.
  • Incremental position: A position derived from movement relative to a reference or previously established state.
  • Reference return or homing: A procedure that establishes the machine's reference position according to the control architecture.
  • Absolute-position recovery: A manufacturer-specific procedure used when absolute position information is missing or invalid.

An absolute encoder battery alarm does not always mean the axis has physically moved or that the encoder itself is defective.

After replacement

Depending on the system, required checks may include:

  • Confirming that the encoder battery alarm has cleared.
  • Checking whether absolute position remains valid.
  • Confirming the controller's reference status.
  • Following any required reference recovery procedure.
  • Verifying axis movement under approved conditions.
  • Confirming that machine coordinates and travel limits remain correct.

Do not automatically perform reference return or alter absolute-position settings without checking the machine's prescribed procedure. Some systems retain valid position, while others require a controlled recovery.

10. Consequences of CNC Battery Failure

The consequences depend on the battery's function and the hardware architecture.

Retained function Possible result of loss
Battery-backed CNC memory Selected parameters or retained data may be lost
Absolute encoder position retention Position validity may be lost
Real-time clock Date and time may reset
Battery-backed PLC data Selected retained values may be lost
UPS power support Shorter runtime or loss of backup capability

Potential downstream effects include:

  • Longer machine recovery time.
  • Incorrect configuration if data is restored from an unsuitable backup.
  • Need for reference recovery or calibration.
  • Production downtime.
  • Additional commissioning checks.
  • Risk of incorrect machine operation if invalid data is not detected.

A lost absolute reference is not equivalent to a physically damaged axis. Likewise, a machine that powers up normally may still have lost important retained data.

11. CNC Parameter and Data Backup

Battery maintenance must be supported by a reliable backup strategy.

Important backup categories may include:

  • CNC parameters.
  • Machine-builder parameters.
  • Servo and spindle drive parameters.
  • PLC programs and retained data, where supported.
  • Tool offsets.
  • Work offsets.
  • Tool-management data.
  • Macro variables.
  • Pitch-error or other compensation data.
  • Machine configuration files.
  • Relevant software and firmware versions.

Not every item is battery-backed, and not every item is included in a standard CNC backup operation.

Backup practices

  1. Identify which data is critical to machine operation.
  2. Use the manufacturer-supported backup method.
  3. Store backups in an approved location.
  4. Include machine identification, date, and software or parameter revision.
  5. Protect backups from unauthorized changes.
  6. Verify that the backup completed successfully.
  7. Periodically confirm that files are readable and complete.
  8. Document the recovery procedure and any required licenses or access permissions.

A backup file existing on a computer does not prove that it can restore the machine. Recovery requirements should be understood before a failure occurs.

12. Practical Example: CNC Memory Battery Alarm

Situation

A CNC controller displays a low-battery warning during routine operation.

Investigation

  1. Record the exact alarm text and code.
  2. Identify the controller model and the battery it refers to.
  3. Check the manufacturer's specified replacement procedure.
  4. Verify that the correct replacement battery is available.
  5. Confirm the status of the latest CNC and machine configuration backups.
  6. Determine whether the procedure requires powered replacement or isolation.
  7. Perform the replacement according to the approved procedure.
  8. Confirm that the alarm clears and relevant retained data remains available.

Possible causes

  • Battery reaching its specified service-life limit.
  • Elevated temperature or unsuitable storage conditions.
  • Incorrect battery type.
  • Battery connector or contact problem.
  • Fault in the monitoring circuit.

Corrective action

Replace the battery according to the approved procedure and document the replacement date, part number, alarm status, and required verification.

Do not wait for a low-battery warning to become a memory-loss event before planning the replacement.

13. Practical Example: Absolute Encoder Battery Alarm

Situation

A CNC machining centre displays an absolute encoder battery alarm after a period of service.

Investigation

  • Identify the affected axis and feedback system.
  • Confirm whether the battery supports the motor encoder or another absolute-position device.
  • Review the drive and CNC alarm details.
  • Check the specified replacement procedure.
  • Establish whether absolute position remains valid.
  • Confirm whether the system requires reference recovery after replacement.

Possible causes

  • Battery capacity has declined.
  • Battery connection is poor.
  • The wrong battery was installed previously.
  • The monitoring circuit or feedback system has a fault.

Corrective action

Restore the approved battery arrangement and follow the controller's required position-validity checks. If the absolute position is invalid, complete the prescribed recovery and verification process before normal production.

14. Practical Example: Machine Reference Lost After Power Restoration

Situation

After a machine shutdown, the CNC indicates that an axis reference or absolute position is invalid.

Investigation

  1. Record the exact CNC and drive alarms.
  2. Identify the axis feedback architecture.
  3. Check battery condition and replacement history.
  4. Determine whether the system relies on battery-backed absolute position.
  5. Verify the controller's current reference status.
  6. Review the approved reference-recovery procedure.
  7. Check whether machine-specific calibration or compensation data is intact.

Possible causes

  • Battery-backed position data was lost.
  • The encoder or feedback cable was disconnected.
  • An encoder or drive was replaced without the required commissioning.
  • The controller lost reference validity for another supported reason.
  • Configuration or calibration data is incorrect.

Corrective action

Follow the manufacturer's reference-recovery process and verify the machine coordinate system, travel limits, and positioning accuracy before releasing the machine.

Do not assume that an axis is safe to move to its previous coordinate merely because the displayed coordinate value looks familiar.

15. Battery Storage and Handling

Battery storage requirements depend on chemistry and manufacturer specifications.

General precautions include:

  • Store batteries within the specified temperature range.
  • Protect terminals from short circuits.
  • Keep batteries in their original protective packaging where appropriate.
  • Prevent mechanical damage, crushing, or puncture.
  • Avoid exposure to moisture and unsuitable environments.
  • Check shelf life before installation.
  • Keep incompatible battery types clearly identified.
  • Follow applicable procedures for damaged, leaking, or swollen batteries.
  • Dispose of used batteries through the approved collection and recycling process.

Lithium batteries require particular care because short circuits, physical damage, incorrect charging, or unsuitable handling can create fire and injury risks.

Do not mix old and new cells in a battery pack unless the manufacturer explicitly permits that arrangement.

16. Preventive Maintenance Checklist

Routine monitoring

  • Review CNC and absolute encoder battery alarms.
  • Maintain a list of battery locations and supported functions.
  • Record battery installation dates and specified replacement intervals.
  • Verify that the approved replacement batteries are available.
  • Confirm that current CNC and machine configuration backups exist.
  • Check for loose connectors or visible damage where inspection is permitted.
  • Review unresolved reference or memory-retention alarms.

Planned maintenance

  • Verify the exact controller and encoder battery requirements.
  • Replace batteries according to manufacturer instructions.
  • Confirm the required powered or isolated replacement condition.
  • Verify alarm clearance after replacement.
  • Confirm retained data and reference validity where applicable.
  • Complete reference recovery if required.
  • Record the installed battery part number and date.
  • Update maintenance records and the next replacement due date.
  • Confirm that relevant backups remain accessible.

Battery replacement intervals must follow the manufacturer's requirements and account for operating temperature, service conditions, and battery status. A universal replacement interval cannot safely be applied to every CNC controller or encoder.

17. Battery Management in Industrial Maintenance

For a maintenance department, battery control should be treated as a defined preventive-maintenance activity rather than an occasional response to alarms.

A useful battery register contains:

Field Purpose
Machine ID Identifies the machine
Module or axis Identifies the supported device
Battery function Distinguishes memory, encoder, clock, or UPS backup
Battery part number Ensures correct procurement
Chemistry and voltage Supports compatibility verification
Installation date Establishes service history
Replacement interval Supports planned maintenance
Alarm status Records the current condition
Backup status Confirms relevant data protection
Replacement procedure Links to the approved work instruction
Last verification Records post-replacement checks

For SAP PM or another computerized maintenance system, each battery type can be linked to the equipment or functional location, preventive-maintenance task list, spare-part record, and replacement history.

This supports planned procurement and reduces the risk of losing machine data due to a neglected battery.

18. Key Engineering Principles

  • CNC batteries support specific retention functions; they do not necessarily back up the entire machine.
  • CNC memory batteries and absolute encoder batteries may be separate.
  • Some systems use nonvolatile memory and require no battery for particular data.
  • Battery chemistry, voltage, connector, and charging behavior must match the equipment requirements.
  • Powered replacement and isolated replacement are both possible, depending on the hardware.
  • The approved replacement procedure must be identified before removing the battery.
  • Absolute-position validity must be checked after relevant battery or feedback work.
  • CNC backups are essential even when batteries are healthy.
  • Battery failure may cause data loss, reference recovery, or additional commissioning work.
  • Alarm clearance alone does not prove that all retained data and references remain valid.
  • Traceable battery registers and scheduled maintenance reduce avoidable CNC downtime.
