1. Purpose of CNC Testing During FAT

CNC (Computer Numerical Control) testing during Factory Acceptance Testing (FAT) verifies that a CNC machine, its control system, axes, spindle, tooling, workholding, machine PLC, and associated process interfaces perform according to the approved machine specification.

The objective is to demonstrate that the machine can execute its intended machining operations accurately, repeatedly, safely, and within the specified cycle time and quality limits.

A CNC machine completing a program without an alarm does not automatically prove that it is ready for production. The program may execute while producing incorrect dimensions, the tool offsets may be wrong, the spindle may not achieve the commanded speed, or the workholding system may fail to clamp the component correctly.

CNC FAT therefore verifies the complete machining system, from program interpretation and axis movement to tool management, spindle performance, machine interlocks, process quality, fault recovery, and documented acceptance.

2. Scope of CNC FAT

The exact test scope depends on the machine type, builder, control platform, and contract. Typical areas include:

  • CNC model, controller configuration, firmware, and software revisions.
  • Axis movement, reference return, travel limits, and positioning performance.
  • Spindle operation, speed commands, orientation, and relevant feedback.
  • Tool changer, magazine, tool identification, and tool-change sequence.
  • Workpiece clamping, fixture interfaces, and part-presence detection.
  • CNC programs, G-codes, M-codes, work offsets, and tool offsets.
  • Machine PLC logic, auxiliary functions, and CNC-to-PLC communication.
  • Coolant, lubrication, hydraulic, pneumatic, and chip-management systems.
  • Machine alarms, interlocks, emergency stops, and protective functions.
  • Dry-run, single-block, and controlled machining trials.
  • Dimensional inspection, surface quality, repeatability, and cycle time.
  • Recovery after interruptions and required documentation.

CNC FAT may include machining trials on representative workpieces, test bars, or reference artifacts. The chosen method must match the machine specification and intended production process.

A typical CNC machining system contains the following subsystems.

 Additional interfaces:

The CNC controller executes the machining program and coordinates axis and process commands. The machine PLC generally manages auxiliary sequences, sensors, actuators, and machine-specific interlocks. The division of responsibilities varies by builder and control architecture.

A CNC machine can use controllers from Siemens, FANUC, Mitsubishi, Haas, Heidenhain, or other manufacturers. The specific menus, diagnostics, and programming syntax vary, so FAT procedures must follow the installed controller and machine-builder documentation.

Do not change CNC parameters, drive tuning, or machine-builder settings casually during FAT. Incorrect changes can affect machine geometry, servo performance, tool changes, or protective limits.

5. CNC Coordinate Systems and Axis Verification

5.1 Machine coordinates

Machine coordinates are referenced to the machine's defined coordinate system and reference positions.

Verify:

  • Correct axis identification and direction.
  • Reference-return operation.
  • Reference position or reference establishment according to the installed system.
  • Configured travel limits.
  • Correct displayed machine coordinates.
  • No unexpected movement or axis-direction reversal.
  • Correct behavior of approved limit and overtravel functions.

The reference-return method varies by machine and control. Some machines use reference switches, while others use absolute encoders and defined reference procedures.

5.2 Work coordinates

Work coordinates define the machining reference relative to the workpiece or fixture.

Common CNC milling work coordinate systems include G54 through G59, with additional offsets available on many controls. The exact supported commands depend on the controller.

Verify that:

  • The correct work offset is selected.
  • The work origin matches the fixture or part datum.
  • Offset values are entered in the correct fields.
  • The correct coordinate system is active for the program.
  • Changes to the work offset produce the expected coordinate shift.

An incorrect work offset can shift the entire machining path even when the program and machine axes are otherwise correct.

5.3 Axis and travel checks

Test Verification
Positive-direction jog Axis moves in the defined positive direction
Negative-direction jog Axis moves in the defined negative direction
Position display Coordinates change consistently with movement
Reference return Reference position is established correctly
Travel range Motion remains within the approved operating envelope
Axis limit response Specified limit or overtravel behavior occurs
Simultaneous movement Coordinated motion follows the intended path
Rotary axis Direction, angular reference, and limits are correct where fitted

Never test physical overtravel by deliberately driving an axis into a mechanical stop. Use the approved procedure and diagnostic method.

6. CNC Program and G-Code Verification

CNC programs define tool paths and machining operations through motion commands, coordinate settings, tool selections, and auxiliary functions.

6.1 Program structure

Review the program for:

  • Correct program identifier and revision.
  • Correct units and coordinate conventions.
  • Correct plane selection.
  • Correct absolute or incremental positioning mode.
  • Correct work coordinate system.
  • Correct tool selection and compensation.
  • Safe approach and retract positions.
  • Correct spindle, coolant, and auxiliary commands.
  • Correct machining sequence.
  • Correct end-of-program behavior.

Modal commands remain active until changed or canceled. An incorrect active mode can affect subsequent blocks, so program verification must consider the controller's modal state.

6.2 Common G-code concepts

Code or concept Common purpose FAT verification
G00 Rapid positioning Verify intended rapid path and clearance
G01 Linear interpolation Verify feed movement and endpoint
G02 / G03 Circular interpolation Verify arc direction, geometry, and endpoint
G17 / G18 / G19 Select machining plane Verify correct plane for interpolation
G20 / G21 Select inch or metric units on controls that support them Verify program and machine units agree
G40 Cancel cutter-radius compensation on many controls Verify compensation state where applicable
G41 / G42 Cutter-radius compensation on supported controls Verify direction and offset configuration
G43 Tool-length compensation on many milling controls Verify correct tool-length offset
G54 to G59 Common work coordinate systems Verify correct work offset
G90 / G91 Absolute or incremental programming on common controls Verify positioning mode
M03 / M04 Common spindle rotation commands Verify direction and spindle response
M05 Stop spindle on common controls Verify spindle stops as specified
M06 Common tool-change command on many milling controls Verify correct tool-change sequence
M08 / M09 Common coolant on/off commands Verify actual coolant response
M30 Common program-end and reset command Verify program termination and reset behavior

Important: G-code and M-code meanings are controller- and machine-dependent. The table shows common conventions, not a universal command standard. Machine-builder M-codes may operate specific hydraulic, clamping, probing, or auxiliary functions.

6.3 Program verification procedure

  1. Confirm the approved program revision and the intended machine.
  2. Check units, work offset, tool numbers, and compensation settings.
  3. Review tool paths and approach/retract moves using the approved simulation or verification method.
  4. Check the first tool call, initial spindle state, and machine setup conditions.
  5. Review all auxiliary commands and required machine interlocks.
  6. Conduct the approved dry-run or controlled first-run procedure.
  7. Compare commanded positions and operations with the intended machining sequence.
  8. Inspect the resulting component or reference test result.
  9. Record deviations and retest after controlled correction.

A program simulation cannot fully represent every physical condition. Actual tool geometry, fixture tolerances, machine condition, and controller configuration must also be verified.

7. Spindle Testing

The spindle provides rotational motion for machining or other operations such as drilling, tapping, or grinding, depending on the machine.

Typical spindle FAT checks include:

  • Start and stop commands.
  • Correct direction of rotation.
  • Commanded versus displayed or measured speed.
  • Acceleration and deceleration behavior.
  • Spindle orientation where required.
  • Spindle-ready and spindle-fault feedback.
  • Speed-control response at specified operating points.
  • Relevant vibration, noise, temperature, or bearing-condition checks.
  • Tool retention and clamping where applicable.
  • Response to spindle overload or other approved fault tests.

For a commanded speed \(N_c\) and measured speed \(N_m\), percentage speed error can be calculated as:

\[ E_N = \frac{|N_m-N_c|}{N_c}\times 100\\% \]

This calculation is valid when \(N_c\) is nonzero. Compare the result against the specified acceptance tolerance and use an appropriate measurement method.

Do not assume that a displayed speed value is an independent measurement. It may be derived from the drive's feedback or command data. Where the specification requires independent verification, use an approved calibrated instrument or test method.

8. Servo Axes, Positioning, and Accuracy

Axis testing verifies that the CNC system commands and achieves the intended machine movement.

8.1 Positioning checks

Verify:

  • Commanded and actual position.
  • Axis following error within specified limits.
  • Repeatability at defined reference positions.
  • Positioning in both travel directions where required.
  • Behavior at different approved speeds.
  • Coordinated multi-axis movement.
  • Rotary-axis accuracy where applicable.
  • Compensation settings and their approved configuration.

8.2 Position error

For commanded position \(X_c\) and measured position \(X_m\):

\[ E_X = X_m-X_c \]

The absolute error is:

\[ |E_X| = |X_m-X_c| \]

Use consistent units and a defined measurement reference. Acceptance criteria must specify whether the requirement applies to absolute positioning accuracy, bidirectional accuracy, repeatability, or another performance measure.

8.3 Backlash and compensation

Backlash is lost motion or positional difference associated with direction reversal in a mechanical transmission. Its observed effects can involve ballscrews, bearings, couplings, gearboxes, and other mechanical elements.

Test for direction-dependent positioning deviations using the approved measurement procedure. Do not immediately adjust electronic compensation to conceal a mechanical problem.

A valid diagnosis should distinguish mechanical wear or looseness from encoder issues, alignment problems, incorrect compensation data, and measurement error.

9. Tool Changer and Tool Management

Automatic tool changers and tool magazines must operate correctly because tool-selection errors can damage the workpiece, tool, spindle, or machine.

Verify:

  • Correct tool number and magazine pocket.
  • Correct tool-change sequence.
  • Correct spindle and tool-clamp states.
  • Correct unclamping and clamping feedback.
  • Correct arm or magazine movement where fitted.
  • Correct empty-pocket and occupied-pocket recognition.
  • Correct recovery from an interrupted tool change.
  • Correct tool-length and radius data association.
  • Correct response to an invalid or unavailable tool number.
  • Correct tool-breakage or tool-life monitoring where provided.

A typical tool-change sequence is:

CNC requests tool change
          |
          v
Machine checks required conditions
          |
          v
Spindle reaches the required state
          |
          v
Tool unclamps and changer mechanism operates
          |
          v
Requested tool is transferred
          |
          v
Tool clamps and required feedback is confirmed
          |
          v
CNC verifies completion and resumes the program

The actual sequence varies by machine builder. Verify the approved sequence and interlocks rather than assuming that every tool changer uses the same mechanism.

10. Workholding, Clamping, and Fixture Verification

The workholding system must secure the workpiece in the correct position throughout the machining process.

Typical checks include:

  • Fixture identification and orientation.
  • Workpiece seating and datum location.
  • Clamp and unclamp commands.
  • Clamp-position or pressure feedback.
  • Part-presence sensing.
  • Correct response to an absent or incorrectly seated workpiece.
  • Correct interlocking of spindle or axis operation with required clamping.
  • Correct behavior during permitted pressure-loss or sensor-fault tests.
  • Correct unclamping and part-removal sequence.

For hydraulic or pneumatic workholding, verify that pressure values, switches, regulators, and actuators match the specification.

Do not assume that a clamp command proves the part is securely held. Verify the required feedback and, where specified, the actual clamping force or pressure.

11. Coolant, Lubrication, Hydraulics, and Pneumatics

CNC auxiliary systems are essential to machine reliability and process quality.

System FAT checks
Coolant Pump operation, flow where specified, level, filtration, and feedback
Lubrication Pump operation, cycle timing, pressure or flow monitoring, low-level alarm
Hydraulic system Pressure, actuator response, leaks, temperature where specified
Pneumatic system Supply pressure, valve operation, actuator response, pressure-loss detection
Chip conveyor Direction, operation, interlocks, overload response
Mist extraction Operation, required status feedback, fault indication
Tool cooling Flow and pressure where required by the process
Through-spindle coolant Correct activation, pressure, and interlocks where fitted

Check that auxiliary-system faults generate the specified alarms and inhibit affected operations when required.

A machine may complete a short dry-run while concealing a lubrication or coolant problem. FAT must verify these systems according to their operating requirements rather than relying only on successful program execution.

12. CNC-to-PLC and External Equipment Communication

The CNC control and machine PLC exchange commands, status information, alarms, and auxiliary-function requests. External systems may include robots, loaders, conveyors, measuring stations, and supervisory systems.

Typical interface signals include:

Signal Typical meaning
CNC_Ready CNC is available under defined conditions
CNC_Cycle_Start Cycle-start request or status according to the interface definition
CNC_Cycle_Active Machining cycle is active
CNC_Cycle_Complete Required cycle has completed
CNC_Alarm CNC reports an alarm condition
Spindle_Ready Spindle meets the defined readiness conditions
Tool_Change_Complete Tool change is complete
Clamp_Confirmed Required clamping condition is confirmed
Part_Loaded Part-loading operation is confirmed
Machine_Available Machine is available for the next production operation

Signal names and directions are application-specific. Confirm them against the approved interface specification.

Test normal exchanges and defined failure conditions, including:

  • Incorrect or missing start requests.
  • Missing readiness conditions.
  • External equipment not available.
  • Communication timeout.
  • Stale status signals.
  • Loss of required part or clamp confirmation.
  • Recovery after communication returns.

Verify that the machine does not advance based on a stale completion bit or invalid equipment status.

13. Dry-Run and Controlled Machining Trials

13.1 Dry-run testing

A dry-run verifies program execution and machine sequence without performing the intended material-removal process, according to the installed control and approved procedure.

Checks may include:

  • Program syntax and sequence.
  • Axis path and clearance.
  • Tool selection and auxiliary commands.
  • Work offset and tool compensation selection.
  • Machine interlocks.
  • Expected stops and operator prompts.
  • Program-end behavior.

A dry-run does not prove machining accuracy, surface quality, cutting stability, or tool life.

13.2 Controlled first machining trial

Before machining:

  1. Confirm the correct workpiece, fixture, tool, offsets, and program revision.
  2. Verify the workpiece is seated and clamped according to the approved procedure.
  3. Check tool condition and required coolant or process supplies.
  4. Review the program's initial moves and potential interference points.
  5. Establish the authorized initial-run conditions.
  6. Execute the approved trial while monitoring the machine.
  7. Inspect the finished part using the defined measurement plan.
  8. Record machine conditions, offsets, tool information, results, and deviations.

Single-block execution, feed override, and other verification features may be used where supported and permitted. Their use must follow the machine-builder procedure and site controls.

14. Dimensional Inspection and Machining Quality

Machining quality must be verified against the drawing, geometric tolerances, process specification, and inspection plan.

Typical checks include:

  • Linear dimensions.
  • Hole diameter and location.
  • Bore diameter and roundness where specified.
  • Flatness, parallelism, perpendicularity, or other geometric tolerances.
  • Surface finish.
  • Thread size and quality.
  • Feature position relative to the specified datum.
  • Burrs, tool marks, chatter, and visible surface defects.
  • Repeatability across the specified sample size.

14.1 Measurement control

Use the specified calibrated measuring equipment, such as micrometers, bore gauges, dial indicators, coordinate measuring machines, or surface-finish instruments.

The inspection method must match the tolerance and characteristic being measured. A general-purpose caliper may not be suitable for a tight tolerance or a geometric characteristic requiring datum-based measurement.

Record:

  • Part and feature identification.
  • Nominal dimension and tolerance.
  • Actual measured value.
  • Measurement instrument and calibration status.
  • Sample identification.
  • Relevant tool, offset, and program revision.
  • Pass/fail decision.

14.2 Process capability

Where required, FAT may include statistical process evaluation using representative samples. Do not infer production capability from a single good part.

Capability measures such as \(C_p\) and \(C\_{pk}\) require an appropriate dataset and justified statistical assumptions. Their acceptance criteria must be defined by the quality plan, including sample size and process conditions.

15. Cycle-Time Verification

CNC cycle-time testing verifies that the complete machining sequence meets the required production target.

The measurement definition must establish:

  • Start and end events.
  • Whether loading and unloading are included.
  • Whether tool changes are included.
  • Whether inspection or probing time is included.
  • The required machine operating state.
  • Number of repeated cycles.
  • Treatment of operator delays and planned pauses.
  • Acceptance limit and measurement method.

For a defined cycle:

\[ T\_{cycle}=t\_{end}-t\_{start} \]

For \(N\) measured cycles, the average is:

\[ T\_{avg}=\frac{\sum\_{i=1}^{N}T_i}{N} \]

Where required, also record the maximum cycle time and cycle-to-cycle variation.

If the machine misses its target, break the cycle into segments such as cutting time, rapid movement, tool changes, probing, auxiliary operations, and waiting for external equipment. This identifies the actual bottleneck instead of encouraging indiscriminate speed increases.

16. Alarms, Interlocks, and Fault Recovery

CNC FAT must verify that machine faults are detected, communicated, and handled as specified.

Fault condition Expected verification
Servo or axis fault Correct alarm and defined motion response
Spindle fault Correct status, alarm, and permitted recovery
Tool-change failure Sequence stops in the defined state and reports the fault
Clamp confirmation failure Machining is inhibited where required
Low lubrication condition Alarm and required protective response
Coolant failure Correct diagnostic and process response
Hydraulic or pneumatic pressure fault Required warning, interlock, or stop
CNC program error Execution is prevented or stopped as specified
Communication loss Required timeout and interface response occur
Power interruption Machine returns to the defined recovery state
Protective-device activation Approved protective response and reset behavior occur

16.1 Fault recovery testing

For each approved fault test:

  1. Establish the fault under the authorized test conditions.
  2. Record the CNC alarm, machine PLC status, and relevant feedback.
  3. Verify the expected interlock or stop response.
  4. Correct the underlying cause.
  5. Follow the documented reset and recovery procedure.
  6. Confirm that axes, spindle, tools, and workholding remain in a valid state.
  7. Verify that the machine does not unexpectedly restart or resume an unsafe operation.
  8. Repeat the affected test and record the result.

Do not deliberately generate uncontrolled servo, spindle, hydraulic, or mechanical faults. Use approved diagnostic methods and test procedures.

17. Safety and Protective-Function Verification

CNC machine safety must be verified against the approved risk assessment and safety requirements. Applicable standards may include ISO 16090-1 for machine tools, ISO 13849-1 for safety-related control systems, and IEC 60204-1 for electrical equipment of machinery. Confirm the relevant standard editions and requirements for the project.

Depending on the machine design, verification may cover:

  • Emergency-stop functions.
  • Door and guard interlocks.
  • Protective stops.
  • Safe speed or safe motion functions where provided.
  • Spindle and axis protective functions.
  • Tool-changer guarding and interlocking.
  • Enabling devices and setup modes.
  • Reset and restart conditions.
  • Safety-related communication and control functions.

Verify each function using the approved validation procedure, with the required test conditions and evidence.

Do not bypass safety interlocks, defeat guards, or test protective functions through improvised methods. Normal CNC program execution is not proof that the machine's safety functions are valid.

19. CNC FAT Acceptance Criteria

The machine should pass the agreed FAT only when all required tests have been completed and the evidence meets the approved criteria.

Typical acceptance conditions include:

  • Machine and controller configuration match the approved specification.
  • Axis motion, reference return, and travel limits behave correctly.
  • Positioning and relevant performance tests meet specified tolerances.
  • Spindle and tool changer operate as intended.
  • Workholding and auxiliary systems function correctly.
  • CNC programs execute the approved machining sequence.
  • Work offsets, tool offsets, and compensation behave correctly.
  • PLC interfaces and external-equipment handshakes work as specified.
  • Required alarms, interlocks, and fault responses are demonstrated.
  • Dimensional and process-quality results meet the inspection plan.
  • Cycle time meets the specified target.
  • Recovery behavior is controlled and documented.
  • Safety validation is completed for the functions within the approved scope.
  • Critical defects are closed and remaining deviations are formally dispositioned.
  • Configuration backups and test records are archived.

Do not invent numerical acceptance limits when they are absent from the specification. Record the missing requirement and obtain approval from the responsible engineering or quality authority.

20. CNC FAT Documentation

Maintain the following records as applicable:

  • Machine and CNC controller identification.
  • Software, firmware, parameter, and program revisions.
  • Axis and spindle test results.
  • Positioning and accuracy measurement records.
  • Tool-changer and workholding test results.
  • Auxiliary-system test records.
  • CNC program verification results.
  • PLC interface and communication test evidence.
  • Alarm, interlock, and fault-recovery records.
  • Dimensional inspection reports.
  • Cycle-time measurements.
  • Safety validation records.
  • Defect reports, root-cause analysis, corrective actions, and retests.
  • Approved configuration changes and backups.
  • Final FAT acceptance record and outstanding deviations.

Each record should identify the test condition, expected result, actual result, pass/fail status, relevant configuration revision, and supporting evidence.

21. Common CNC FAT Mistakes

  • Running a program without verifying the work offset and tool compensation.
  • Assuming that a successful dry-run proves machining quality.
  • Treating controller-displayed values as independent measurement evidence.
  • Ignoring tool-changer recovery and interrupted-sequence behavior.
  • Testing spindle rotation without verifying the specified speed performance.
  • Checking clamp commands without confirming actual feedback.
  • Measuring cycle time without defining the measurement boundaries.
  • Accepting one good component as proof of repeatable production quality.
  • Changing machine parameters without a controlled backup and revision record.
  • Resetting faults without investigating the cause.
  • Treating ordinary machine operation as proof of functional safety.
  • Closing FAT without documenting deviations and retest evidence.

22. Interview Questions and Answers

Q1. What is the purpose of CNC FAT?

To verify the machine configuration, axis and spindle performance, program execution, tooling, workholding, auxiliary systems, interfaces, process quality, safety-related functions, and cycle time against the approved specification.

Q2. What is the difference between machine coordinates and work coordinates?

Machine coordinates refer to the machine's defined reference system. Work coordinates define the machining reference relative to the workpiece or fixture. Incorrect work offsets can shift the programmed machining path.

Q3. Why are tool offsets important?

Tool offsets account for tool geometry and, where applicable, tool radius or length compensation. Incorrect values can produce dimensional errors or unintended tool movement.

Q4. What is the difference between G00 and G01?

G00 commonly commands rapid positioning, while G01 commonly commands linear interpolation at a programmed feed rate. Actual behavior and restrictions must be confirmed for the installed control.

Q5. Why must the tool changer be tested during FAT?

Tool-change errors can cause incorrect tooling, incomplete clamping, program interruption, or equipment damage. The complete sequence and fault recovery must be verified.

Q6. What causes CNC dimensional errors?

Possible causes include incorrect work offsets, tool geometry or wear, compensation settings, thermal effects, fixture variation, machine geometry, backlash, calibration issues, and measurement error.

Q7. How would you troubleshoot an axis-positioning problem?

Compare commanded and actual positions, inspect alarms and following-error diagnostics, verify reference and offset data, and evaluate mechanical condition and feedback integrity using the approved diagnostic procedure.

Q8. Why is dry-run testing insufficient?

Dry-run testing checks program execution and motion behavior but does not establish actual material-removal quality, dimensional accuracy, cutting stability, or tool life.

Q9. How should CNC cycle time be measured?

Define the start and end events, establish whether loading, tool changes, probing, and other operations are included, then record repeated cycles under specified operating conditions.

Q10. Why must clamp confirmation be interlocked with machining?

Where required by the machine design, it prevents machining from proceeding without confirmation of the necessary workholding condition. The actual interlock must be verified against the approved design.

Q11. What is the difference between an alarm and an interlock?

An alarm communicates a detected condition. An interlock prevents or restricts an operation until defined conditions are satisfied. A machine may require both for the same fault.

Q12. What should be verified after changing a CNC parameter?

Verify the change against the approved baseline, assess its effects on motion or process behavior, repeat the affected tests, retain the revised backup, and document the change and approval.

23. Practical CNC FAT Checklist

  • Machine, CNC, firmware, and parameter revisions verified.
  • Approved CNC and PLC backups completed.
  • Axis direction, reference return, and travel limits tested.
  • Positioning performance checked against specified criteria.
  • Spindle direction, speed, and required feedback verified.
  • Tool changer and tool identification tested.
  • Tool offsets, work offsets, and compensation verified.
  • Workholding and clamp confirmation tested.
  • Coolant, lubrication, hydraulics, and pneumatics verified.
  • CNC-to-PLC and external-equipment interfaces tested.
  • Dry-run and controlled machining trials completed.
  • Dimensional and process-quality inspections passed.
  • Cycle time measured against the approved requirement.
  • Required alarms, interlocks, and recovery procedures tested.
  • Safety validation completed according to the approved procedure.
  • Defects corrected or formally dispositioned.
  • Retest evidence and final configuration records archived.
