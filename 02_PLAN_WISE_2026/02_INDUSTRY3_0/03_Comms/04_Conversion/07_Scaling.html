1. Definition and purpose

Scaling is the mathematical conversion of a raw numerical value into a value that represents the intended measurement or engineering quantity.

Industrial devices often transmit integer counts instead of directly transmitting values in engineering units. A PLC analog input module, VFD, pressure transmitter, temperature controller, energy meter, or communication gateway may provide a raw value that must be converted before it can be used meaningfully in a control system.

For example, a pressure transmitter may represent a pressure range of 0 to 10 bar using a raw range of 0 to 27648. The raw value 13824 corresponds to 5 bar when the input range is configured and behaving as specified.

Scaling allows the automation system to convert that raw count into a useful measurement.

Physical measurement
    ↓
Sensor or instrument
    ↓
Electrical signal or digital value
    ↓
Raw numerical value
    ↓
Scaling calculation
    ↓
Engineering value
    ↓
HMI / SCADA / control logic / historian

Key distinction: Scaling does not fix an incorrect data type, byte order, word order, register address, or communication mapping. The raw value must first be interpreted correctly.

2. Why scaling is needed

Common industrial signals and devices use different numerical ranges for the same physical measurement.

Source or representation Raw range or format Possible engineering representation
Analog input module 0 to 27648 counts 0 to 10 bar
Analog input module 5530 to 27648 counts 4 to 20 mA converted to pressure
VFD parameter Integer 125 with a factor of 0.1 12.5 Hz
Modbus instrument Integer 253 with a factor of 0.1 25.3 °C
ADC 0 to 4095 counts 0 to 100%
Digital encoder 0 to 10000 counts 0 to 360°, depending on the configured range

These are examples, not universal device conventions. Actual raw ranges, signal characteristics, and scaling rules must come from the hardware configuration or device manual.

Scaling is used for:

  • Converting analog input counts to voltage, current, pressure, temperature, level, or flow.
  • Converting integer communication values into physical measurements.
  • Converting machine feedback into engineering units.
  • Normalizing values into percentages.
  • Displaying readable measurements on HMI and SCADA screens.
  • Producing meaningful trends, alarms, calculations, and database records.

3. Linear scaling

Linear scaling is one of the most common techniques in industrial automation.

It maps a raw input range to an engineering output range using a straight-line relationship.

The general formula is:

\[ Y = Y\_{\min} + \frac{X-X\_{\min}}{X\_{\max}-X\_{\min}} (Y\_{\max}-Y\_{\min}) \]

Where:

  • \(X\) is the measured raw value.
  • \(X\_{\min}\) is the minimum raw value.
  • \(X\_{\max}\) is the maximum raw value.
  • \(Y\) is the engineering value.
  • \(Y\_{\min}\) is the engineering value corresponding to the minimum raw value.
  • \(Y\_{\max}\) is the engineering value corresponding to the maximum raw value.

The formula calculates the raw value's relative position within its range, then applies that proportion to the engineering range.

3.1 Worked example: Pressure transmitter

Assume the configured raw input range is 0 to 27648, representing 0 to 10 bar.

Given:

  • Raw value: 13824
  • Raw minimum: 0
  • Raw maximum: 27648
  • Engineering minimum: 0 bar
  • Engineering maximum: 10 bar

Substitute the values:

\[ Y = 0 + \frac{13824-0}{27648-0}(10-0) \]
\[ Y = 5\text{ bar} \]

The raw input is halfway through its configured range, so the engineering value is halfway through the pressure range.

3.2 Another example: Tank level

Suppose a level transmitter uses a raw range of 4000 to 20000 to represent 0 to 5 m.

If the raw input is 12000:

\[ Y = 0 + \frac{12000-4000}{20000-4000}(5-0) \]
\[ Y = 2.5\text{ m} \]

Notice that the raw minimum is not zero. This is common with live-zero signals such as 4–20 mA. Scaling must use the actual configured endpoints.

4. Scaling 4–20 mA and 0–10 V signals

4.1 Current signal: 4–20 mA

A 4–20 mA signal commonly represents a measurement range in which:

  • 4 mA represents the lower range limit.
  • 20 mA represents the upper range limit.
  • Values between them represent proportional measurements, assuming linear configuration.

The relationship is:

\[ Y = Y\_{\min} + \frac{I-4}{20-4}(Y\_{\max}-Y\_{\min}) \]

Here, \(I\) is the measured current in milliamperes.

Example: A pressure transmitter measures 0 to 16 bar. The measured signal is 12 mA.

\[ Y = 0 + \frac{12-4}{20-4}(16-0) \]
\[ Y = 8\text{ bar} \]

The current is halfway between 4 mA and 20 mA, so the measured pressure is halfway between 0 bar and 16 bar.

4.2 Voltage signal: 0–10 V

Suppose an analog input measures 0 to 10 V, representing 0 to 100% valve position.

At an input voltage of 6.5 V:

\[ Y = \frac{6.5-0}{10-0}(100-0) \]
\[ Y = 65\\% \]

4.3 Comparing the two signals

Property 4–20 mA 0–10 V
Electrical quantity Current Voltage
Lower nominal signal 4 mA 0 V
Upper nominal signal 20 mA 10 V
Common application Transmitters and long industrial runs Analog references and suitable sensor interfaces
Important checks Loop supply, current, wiring, input mode Voltage reference, common, wiring, input mode
Fault interpretation Current below the valid range may indicate a fault, depending on device configuration Zero volts may be a valid measurement or a wiring fault

Do not assume that every signal outside its nominal range has the same meaning. Transmitters and input modules may use configured fault-current thresholds, under-range or over-range diagnostics, and channel-specific status bits.

5. Scaling PLC analog input counts

PLC analog modules frequently convert electrical signals into digital counts. The count range depends on the manufacturer, module, selected input range, and configuration.

For example, a Siemens or Allen-Bradley analog module may use a different raw-value representation from another module. Some ranges include signed values, underrange or overrange regions, or diagnostic values that should not be treated as ordinary measurements.

Never assume that 0 to 27648 is universal. Use the actual module manual and configured range.

5.1 Example: Raw counts to pressure

Assume the module documentation and configuration confirm:

  • Raw minimum: 0
  • Raw maximum: 27648
  • Pressure range: 0 to 10 bar
  • Current raw input: 20736

Then:

\[ Y = \frac{20736}{27648}\times10 \]
\[ Y = 7.5\text{ bar} \]

5.2 When the raw minimum is nonzero

Suppose a module is configured to produce raw values from 5530 to 27648 for a 0 to 10 bar measurement.

At a raw input of 16589, the scaled value is approximately:

\[ Y = \frac{16589-5530}{27648-5530}\times10 \]
\[ Y \approx 5.0\text{ bar} \]

The subtraction of the raw minimum is essential. Dividing the raw value directly by the maximum would produce an incorrect result.

5.3 PLC scaling implementation

A typical implementation has these stages:

  1. Read the analog input channel.
  2. Validate channel diagnostics and signal status.
  3. Convert the raw value to a suitable numerical type.
  4. Apply the scaling formula using the configured raw and engineering limits.
  5. Apply any required filtering or rate-of-change checks.
  6. Publish the engineering value to HMI, SCADA, alarms, and control logic.

Keep raw values available during commissioning and troubleshooting. Showing only the final engineering value makes it harder to distinguish sensor faults from scaling faults.

6. Scaling integer values received over communication protocols

Devices often transmit integers rather than floating-point values to reduce data size or simplify their register maps. The scaling factor may be specified in the manual or provided through a separate register.

Common representations include:

  • A fixed decimal factor such as 0.1.
  • A multiplier such as 100.
  • An integer representing a value in tenths or hundredths.
  • A value that requires an offset as well as a multiplier.
  • A raw value accompanied by a separate exponent or scale register.

6.1 Fixed scale factor

Suppose a VFD transmits a frequency value of 487, where the manual defines each count as 0.01 Hz.

\[ Y = 487 \times 0.01 \]
\[ Y = 4.87\text{ Hz} \]

The raw integer is not itself the frequency in hertz. Its meaning depends on the manufacturer's documented scale factor.

6.2 Multiplier versus divisor

Suppose a temperature value is transmitted as 253 and represents 25.3 °C.

Two equivalent descriptions are possible:

\[ Y = 253 \times 0.1 = 25.3 \]

or

\[ Y = \frac{253}{10} = 25.3 \]

A manual might describe the parameter as a factor of 0.1, a resolution of 0.1 °C, or a decimal position of one digit. Confirm the exact meaning rather than interpreting the wording loosely.

6.3 Offset scaling

Some devices use a relationship of the form:

\[ Y = aX+b \]

Where:

  • \(X\) is the raw value.
  • \(a\) is the multiplier.
  • \(b\) is the offset.

For example, a raw value of 150 may be defined as a temperature of 50 °C by:

\[ Y = 150 \times 1 - 100 \]
\[ Y = 50^\circ\text{C} \]

This is a simple mathematical example. Real devices may define offsets differently, and the documented encoding must be followed.

7. Scaling percentages and normalized values

Automation systems sometimes normalize values to a 0 to 1 range or a 0 to 100% range.

For a raw value \(X\) between \(X\_{\min}\) and \(X\_{\max}\), the normalized fraction is:

\[ N = \frac{X-X\_{\min}}{X\_{\max}-X\_{\min}} \]

The percentage is:

\[ P = 100N \]

For a raw range of 200 to 1200, a value of 700 gives:

\[ P = \frac{700-200}{1200-200}\times100 = 50\\% \]

This can be useful for valve position, tank level, speed references, process completion, and other proportional values.

However, a percentage is not automatically the same as a physical measurement. A valve command of 50% does not guarantee that the valve is physically 50% open, and 50% pump speed does not necessarily mean 50% flow. The process relationship may be nonlinear.

8. Reverse scaling: Engineering value to raw value

Some systems need the inverse conversion. For example, a PLC may calculate a desired pressure and convert it into a raw output count for an analog output module.

Starting from the linear scaling formula:

\[ X = X\_{\min} + \frac{Y-Y\_{\min}}{Y\_{\max}-Y\_{\min}} (X\_{\max}-X\_{\min}) \]

Where \(Y\) is the requested engineering value and \(X\) is the corresponding raw value.

8.1 Example: Pressure setpoint to output counts

Assume:

  • Pressure range: 0 to 10 bar
  • Output raw range: 0 to 27648
  • Requested pressure: 6 bar
\[ X = 0 + \frac{6-0}{10-0}(27648-0) \]
\[ X = 16588.8 \]

If the output module requires an integer count, the implementation must round or truncate according to the application's requirements. Rounding to the nearest count gives approximately 16589.

Control-system caution: Validate output limits, interlocks, operating mode, and safe states before writing scaled values to physical outputs. A mathematically correct conversion does not make an unsafe command safe.

9. Clamping, saturation, and out-of-range values

Linear scaling can produce an engineering value outside the expected range if the raw input exceeds its configured endpoints.

For example, a raw input configured for 0 to 1000 might unexpectedly reach 1100.

Without range handling, the scaled result for a 0 to 100% measurement would be 110%.

A system may need to:

  • Clamp: Limit the displayed or commanded value to the configured engineering range.
  • Flag an overrange: Preserve the raw input and indicate that it exceeds the normal range.
  • Flag an underrange: Indicate that the raw input is below the normal operating range.
  • Mark the value invalid: Prevent the value from being used in control logic when diagnostics indicate a fault.
  • Preserve the raw value: Retain evidence for troubleshooting and fault analysis.

Clamping should not silently hide faults. If a failed sensor produces an excessive input, displaying 100% without a fault status may mislead the operator.

The appropriate response depends on the sensor, input module, process, and safety requirements.

10. Scaling, resolution, accuracy, and precision

These terms are related but different.

Term Meaning Example
Scaling Maps one numerical range to another 0 to 27648 counts into 0 to 10 bar
Resolution Smallest distinguishable increment of the measurement representation 0.01 bar per count
Accuracy How close the measurement is to the true value Actual pressure is 5.00 bar, display reads 5.08 bar
Precision How closely repeated readings agree with one another Repeated readings remain near 5.08 bar
Repeatability Ability to reproduce the same result under the same conditions Repeated test at the same pressure
Linearity How closely the relationship follows a straight line Input-to-output deviation across the measurement range

Scaling cannot improve the actual resolution or accuracy of the sensor. It can produce more decimal places on the display, but additional digits do not create additional measurement information.

For instance, displaying 5.0000 bar from a coarse analog input does not prove that the system measures pressure to four decimal places.

11. Filtering and scaling

Filtering and scaling solve different problems.

  • Scaling converts the numerical representation.
  • Filtering reduces fluctuations or noise in the signal.
  • Validation determines whether the input is plausible and usable.
  • Calibration checks and, where appropriate, adjusts measurement performance against a reference.

A typical processing sequence is:

Raw input
    ↓
Input diagnostics
    ↓
Raw-range and plausibility checks
    ↓
Scaling
    ↓
Optional engineering-value filtering
    ↓
Engineering-value validation
    ↓
HMI / SCADA / control logic

The exact order of filtering and scaling depends on the application. For a linear transformation, ideal mathematical scaling and linear filtering can often be rearranged without changing the steady-state relationship. In real PLC applications, integer arithmetic, saturation, filtering algorithms, and diagnostic handling can make the implementation order significant.

Use filtering only when justified by the measurement and process response. Excessive filtering can delay fault detection or make a fast process appear slower than it really is.

Mistake Result Corrective action
Using the wrong raw maximum Measurement has incorrect magnitude Verify module configuration and device manual
Ignoring a nonzero raw minimum Zero and intermediate readings are incorrect Use both raw endpoints in the formula
Treating a scaled integer as a direct engineering value Incorrect decimal placement Apply the documented scale factor
Applying scaling twice Value is too large or too small Identify which component owns the conversion
Mixing Celsius and Fahrenheit Incorrect temperature interpretation Define the source unit and target unit explicitly
Ignoring signedness Negative or unexpected values Confirm the data type and encoding
Incorrect byte or word order Raw number is reconstructed incorrectly Verify the bit pattern before scaling
Integer division Fractional information is lost Use suitable floating-point or higher-precision arithmetic
Ignoring underrange and overrange Invalid sensor values appear valid Handle diagnostic and range status explicitly
Clamping without a fault indication A failed input appears to be a normal endpoint Preserve diagnostics and raw values

Using the wrong engineering endpoints Displayed value is consistently biased Confirm zero, span, and calibration configuration

13. PLC implementation considerations

13.1 Numerical data types

Choose a numerical type that can safely represent the intermediate calculation. If integer arithmetic is used for a linear scaling formula, multiplication can overflow and division can truncate fractional results.

For example, calculate the difference between raw and minimum values using a sufficiently wide type before multiplication. Convert to floating point when the application requires fractional engineering values and the platform supports it.

Do not assume that every PLC's INT, DINT, REAL, or equivalent type has the same range or behavior. Confirm the target platform's data-type definitions.

13.2 Zero-span protection

The scaling formula divides by:

\[ X\_{\max}-X\_{\min} \]

If \(X\_{\max}=X\_{\min}\), the denominator is zero. The configuration must be rejected or the calculation disabled, with a suitable diagnostic.

Also validate that the engineering range is configured correctly. A reversed range can be legitimate in some applications, but it should be deliberate and documented.

13.3 Separate raw and engineering tags

For maintainability, use separate variables or tags where practical:

  • Pressure_Raw: raw input count.
  • Pressure_EU: scaled engineering value.
  • Pressure_Quality: validity or diagnostic status.
  • Pressure_RawMin and Pressure_RawMax: configured input endpoints.
  • Pressure_EUMin and Pressure_EUMax: engineering endpoints.

The exact naming convention can follow the plant standard. The important point is to keep the raw measurement, converted value, and quality status distinguishable.

14. Commissioning and calibration workflow

A reliable commissioning procedure verifies the complete measurement chain rather than merely checking that a number appears on the HMI.

  1. Confirm the sensor configuration: Verify signal type, measurement range, wiring, and device configuration.
  2. Confirm the input channel: Check the module type, selected range, diagnostics, and raw-count representation.
  3. Record the raw value: Capture counts or communication registers at known input conditions.
  4. Verify the scaling formula: Confirm both endpoints, data type, and calculation.
  5. Test multiple points: Check low, intermediate, and high values within the operating range.
  6. Verify fault behavior: Check the configured handling of open circuits, underrange, overrange, and invalid data where safe and appropriate.
  7. Compare against a reference: Use a suitable calibrated source or reference instrument.
  8. Verify downstream use: Confirm HMI displays, alarms, trends, control logic, and database records.
  9. Document the result: Record the configuration, test values, deviations, and approval.

For a 4–20 mA input, a suitable signal calibrator can be used to inject known currents under an approved procedure. For voltage inputs, use an appropriate calibrated voltage source. Follow the equipment manufacturer's instructions and the plant's electrical safety procedures.

15. Practical examples from industrial maintenance

Example A: Pressure transmitter

A pressure transmitter measures 0 to 16 bar using 4 to 20 mA. The PLC input is configured to measure current.

At 16 mA:

\[ Y = \frac{16-4}{20-4}\times16 \]
\[ Y = 12\text{ bar} \]

If the PLC displays 16 bar instead, check whether the raw input range or the scaling endpoints have been configured incorrectly.

Example B: VFD frequency feedback

A VFD sends the integer 487 over Modbus. Its parameter documentation specifies a resolution of 0.01 Hz.

\[ Y = 487\times0.01 = 4.87\text{ Hz} \]

If SCADA shows 487 Hz, the likely issue is that the scale factor has not been applied. If it shows an implausible value unrelated to 487, verify the register mapping and data representation first.

Example C: Tank level

A level instrument represents 0 to 100% using raw values from 0 to 4095.

For a raw value of 3071:

\[ Y = \frac{3071}{4095}\times100 \]
\[ Y \approx 75.0\\% \]

This is approximately 75% of the configured measurement span. Whether that corresponds to 75% of the tank's physical volume depends on the tank geometry and the relationship between level and volume.

16. Interview questions and answers

Q1. What is scaling in industrial automation?

Scaling converts a raw numerical representation into a meaningful engineering value using a defined relationship between raw and engineering ranges.

Q2. What is the linear scaling formula?

\[ Y = Y\_{\min} + \frac{X-X\_{\min}}{X\_{\max}-X\_{\min}} (Y\_{\max}-Y\_{\min}) \]

Q3. Why does a 4–20 mA signal use a nonzero minimum?

The 4 mA live zero allows a valid lower-range measurement to be distinguished from a zero-current condition, although actual fault detection depends on the transmitter and input configuration.

Q4. What is the difference between scaling and calibration?

Scaling performs a numerical conversion. Calibration compares an instrument's response with a reference and determines its measurement error; adjustment may be performed where appropriate.

Q5. Why should the raw value be retained?

It helps distinguish faults in the sensor, wiring, input module, communication mapping, scaling calculation, and display layer.

Q6. What happens if the raw minimum is ignored?

Measurements will be incorrect whenever the configured raw minimum is nonzero, as is common with a 4–20 mA live-zero signal.

Q7. What is the difference between scaling and filtering?

Scaling converts the numerical range. Filtering reduces variations in the signal over time.

Q8. Can scaling correct a byte-order fault?

No. Byte and word order must be corrected before the reconstructed numerical value can be scaled reliably.

Q9. Why can integer arithmetic cause scaling errors?

Integer arithmetic can truncate fractions or overflow intermediate calculations, depending on the data types and implementation.

Q10. Why is testing only the minimum and maximum sometimes insufficient?

Intermediate tests can reveal nonlinearity, incorrect configuration, signal problems, and implementation errors that endpoint checks alone may miss.

18. Final mental model

Correct sensor signal or register data
    ↓
Correct data type and representation
    ↓
Correct raw minimum and maximum
    ↓
Correct engineering minimum and maximum
    ↓
Scaling calculation
    ↓
Range and quality validation
    ↓
Engineering value with units
    ↓
HMI / SCADA / control / historian

The central rule is: first establish that the raw value is valid and correctly interpreted, then scale it using the documented endpoints or factor. A plausible display is not proof of a correct measurement. Verify the raw input, conversion, engineering range, quality status, and downstream use.
