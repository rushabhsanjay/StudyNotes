1. What is Batch Automation?

Batch automation is the automatic production of a finite quantity of material or product according to a defined recipe, procedure, sequence, and set of process conditions.

The important word is finite.

A batch has:

Start → Processing → Completion

For example:

1,000 kg of Paint-A is produced according to Recipe-PA-01.

The system starts the batch, verifies the required conditions, adds the required materials, controls temperature/flow/pressure/agitation, completes the required sequence, records the results, and finally declares the batch complete.

So:

Batch Automation = Recipe + Sequence + Process Control + Material/Equipment Management + Traceability

2. Why Batch Automation is Different

There are three important automation categories you are studying:

Type Basic idea Typical example
Discrete Automation Individual items/events Assembly line
Process Automation Continuous physical process Continuous water flow
Batch Automation Finite quantity made according to recipe 5,000 L chemical batch

The distinction is not always about the equipment.

The same tank could participate in process automation or batch automation depending on how it is operated.

For example:

Continuous process

Raw material continuously enters:

Feed → Tank/Process → Product

There may be no meaningful "Batch #125" boundary.

Batch process

A defined quantity is produced:

Batch #125 → Charge → Mix → Heat → Hold → Cool → Discharge

Then the equipment becomes available for another batch.

The simplest mental model is:

RECIPE
   ↓
BATCH ID
   ↓
MATERIAL / EQUIPMENT CHECK
   ↓
CHARGE / LOAD
   ↓
EXECUTE SEQUENCE
   ↓
CONTROL PROCESS VARIABLES
   ↓
MONITOR
   ↓
HOLD / INTERVENTION IF REQUIRED
   ↓
COMPLETE
   ↓
DISCHARGE / TRANSFER
   ↓
RECORD BATCH DATA
   ↓
CLEAN / CHANGEOVER
   ↓

This is the fundamental structure you should remember.

4. What is a Batch?

A batch is a distinct quantity of product produced or processed under defined conditions.

Example:

Batch ID      : PAINT-2026-00125
Product       : Red Industrial Paint
Quantity      : 2,000 kg
Recipe        : RED_PAINT_R03
Equipment     : MIX-TANK-05
Start Time    : 08:30
End Time      : 11:45
Operator      : Operator-07
Status        : COMPLETE

The Batch ID is extremely important because it provides traceability.

If a quality problem appears later, the manufacturer should be able to determine:

  • which materials were used
  • which equipment was used
  • which recipe/version was used
  • who operated it
  • when it was produced
  • what process values occurred
  • whether alarms occurred
  • whether the batch was held
  • whether parameters were changed
  • what the final quality result was

5. Recipe

The recipe is one of the most important concepts in batch automation.

A recipe defines how a particular product should be produced.

For example:

Chocolate batch recipe

Product       : Chocolate-A
Batch Size    : 500 kg

Ingredient A  : 250 kg
Ingredient B  : 150 kg
Ingredient C  : 100 kg

Mix Speed     : 80 RPM
Heating SP    : 65 °C
Hold Time     : 20 min
Cooling SP    : 30 °C

The automation system uses this information to execute the batch.

A recipe can contain:

  • material quantities
  • process setpoints
  • temperatures
  • pressures
  • flow rates
  • mixing speeds
  • timing
  • sequence
  • limits
  • equipment requirements
  • operating parameters
  • product-specific instructions

6. Recipe vs Batch

These are not the same thing.

Recipe

Defines what should be done.

Batch

Represents one actual execution of that recipe.

Example:

Recipe:
PAINT_RED_R03

Batch:
PAINT_RED_2026_001

Batch:
PAINT_RED_2026_002

Batch:
PAINT_RED_2026_003

One recipe can therefore produce many batches.

Think:

Recipe = instruction/template

Batch = actual production instance

This distinction becomes very important in MES, DCS and batch-management systems.

7. Batch Sequence

A batch is normally executed through a sequence of operations.

Example:

START
  ↓
Check equipment
  ↓
Check raw materials
  ↓
Charge Material A
  ↓
Charge Material B
  ↓
Start Agitator
  ↓
Heat to 70°C
  ↓
Hold 30 min
  ↓
Add Material C
  ↓
Mix 15 min
  ↓
Cool to 35°C
  ↓
Quality Check
  ↓
Discharge
  ↓
COMPLETE

This is where discrete automation and process automation meet.

8. Batch Automation Combines Discrete + Process Automation

This is one of the most important concepts.

A batch system can contain both.

For example:

Discrete control

Open Valve V101
↓
Wait for open feedback
↓
Start Pump P101
↓
Wait for running feedback
↓
Close Valve V102

These are discrete events.

But simultaneously:

Process control

Temperature SP = 70°C
Pressure SP = 4 bar
Flow SP = 100 L/min

The controller continuously regulates these variables.

Therefore:

Batch automation is often a combination of sequence control and process control.

9. Example: Automated Mixing Tank

Consider an industrial mixing tank.

Equipment:

  • Tank
  • Agitator
  • Heating system
  • Cooling system
  • Temperature transmitter
  • Level transmitter
  • Flowmeter
  • Control valves
  • Pump
  • PLC/DCS
  • HMI

Batch sequence:

1. Verify tank empty
2. Verify valves in correct state
3. Add Material A
4. Verify required quantity
5. Add Material B
6. Start agitator
7. Heat to 80°C
8. Maintain 80°C for 30 min
9. Add Material C
10. Mix for 15 min
11. Cool to 40°C
12. Transfer product
13. Record batch completion
14. Clean tank

Notice what is happening.

The sequence determines what happens next.

The process controller determines how the physical variables are controlled.

10. Batch Phases

A large batch process is usually broken into smaller executable sections called phases.

For example:

Batch
│
├── Charge Raw Material
├── Heating
├── Mixing
├── Reaction
├── Cooling
├── Quality Check
└── Discharge

Each phase may have:

  • starting conditions
  • commands
  • setpoints
  • feedback
  • completion conditions
  • timeout
  • alarm conditions
  • abort conditions

Example:

Heating phase

START HEATING
      ↓
Check Level OK
      ↓
Open Heating Valve
      ↓
Control Temperature
      ↓
Temperature reaches 80°C
      ↓
Hold 30 minutes
      ↓
PHASE COMPLETE

11. Equipment Conditions

Before executing a batch, the automation system may verify that equipment is ready.

For example:

Tank available = TRUE
Agitator healthy = TRUE
Temperature sensor healthy = TRUE
Level sensor healthy = TRUE
Required valves available = TRUE
No active critical alarm
Emergency stop healthy

Only then:

BATCH START PERMITTED

  • permissive
  • interlock

12. Material Verification

Suppose the recipe requires:

The system may verify:

A batch system needs to know its current state.

Typical states include:

IDLE

For example:

A batch may be placed on HOLD because:

15. Hold vs Abort

These are conceptually different.

Hold

The batch temporarily stops progressing.

Example:

Temperature not reaching required value
        ↓
HOLD
        ↓
Maintenance investigates heater
        ↓
Problem corrected
        ↓
RESUME

Abort

The batch is terminated rather than normally completed.

Example:

Major equipment failure
        ↓
ABORT
        ↓
Batch terminated

The material may then require:

  • disposal
  • reprocessing
  • investigation
  • deviation handling

19. PLC in Batch Automation

A PLC can execute:

  • sequence logic
  • equipment control
  • valve control
  • motor control
  • interlocks
  • permissives
  • phase execution
  • analog control
  • PID
  • equipment status
  • communication

For example:

IF Phase = HEATING
AND Tank_Level_OK
AND Heater_Available
THEN
    Enable_Heating

Then:

IF Temperature >= 80°C
THEN
    Heating_Phase_Complete

This is basic batch sequence logic.

20. DCS in Batch Automation

DCS is common in process-oriented industries and can provide:

  • continuous control
  • PID loops

  • batch management capabilities

But remember:

Batch automation does not mean "DCS automation."

A batch system can be implemented using:

  • PLC
  • DCS
  • industrial PC
  • dedicated batch-control software
  • combinations of these

The architecture depends on the application.

23. Campaign Production

A campaign means producing multiple batches of the same or related product before changing the setup.

Example:

Campaign: RED PAINT

Batch 001
Batch 002
Batch 003
Batch 004
Batch 005
       ↓
Changeover
       ↓
BLUE PAINT

Why?

Because changing products may require:

  • cleaning
  • flushing
  • tool/setup change
  • recipe change
  • material change
  • quality verification

Reducing unnecessary changeovers improves production efficiency.

24. Changeover

After a batch finishes, the equipment may need to be prepared for another product.

Typical sequence:

      ↓

      ↓
Clean
      ↓
Flush
      ↓
Inspect
      ↓
Configure
      ↓
Load New Recipe
      ↓
Verify
      ↓
Next Batch

For some industries, cleaning itself is an automated sequence.

This is particularly important when contamination between products is unacceptable.

29. Maintenance Perspective

For your maintenance work, batch automation is particularly important because a batch failure can originate from either sequence logic or physical process control.

Suppose:

Batch stops during heating.

Do not immediately blame the PLC, because humans have historically enjoyed replacing expensive electronics when a temperature transmitter was simply lying.

Trace the chain:

Batch Phase
     ↓
Heating command?
     ↓
Controller output?
     ↓
Heating valve/heater command?
     ↓
Final element actually operating?
     ↓
Temperature changing?
     ↓
Temperature sensor correct?
     ↓
Transmitter signal correct?
     ↓
PLC/DCS PV correct?
     ↓
Recipe setpoint correct?
     ↓
Sequence completion condition satisfied?

Possible faults:

Sensor fault
Transmitter fault
Analog input fault
Scaling error
PLC logic problem
Recipe parameter error
Valve fault
Heater fault
VFD fault
Pump fault
Communication failure
Permissive not satisfied
Interlock active
Sequence timeout

33. Important Batch Terms

You should become comfortable with these terms:

Batch A finite quantity processed under defined conditions.

Recipe Instructions and parameters required to produce a product.

Batch ID Unique identifier for a production batch.

Phase A defined executable portion of a batch procedure.

Operation A logical group of activities within the production procedure.

Equipment Physical production equipment used by the batch.

Batch record Historical record of what occurred during the batch.

Traceability Ability to determine what materials, equipment, parameters and events were associated with a batch.

Hold Temporary suspension of batch progression.

Abort Termination of the batch.

Campaign Production of multiple related batches before changeover.

Changeover Preparation of equipment from one product/process to another.

Recipe version Specific revision of the recipe used for a batch.

34. ISA-88 / S88 Connection

As you progress into advanced industrial automation, you will encounter ISA-88, commonly called S88, which provides a structured approach to batch control.

A simplified conceptual hierarchy is:

PROCESS CELL
     ↓
UNIT
     ↓
EQUIPMENT MODULE
     ↓
CONTROL MODULE

And on the procedural side:

PROCEDURE
     ↓
UNIT PROCEDURE
     ↓
OPERATION
     ↓
PHASE

You do not need to memorize the complete S88 standard at this stage.

The important idea is:

Separate the production procedure from the physical equipment so that recipes and automation can be structured and reused.

This becomes increasingly important in large batch systems.

37. Interview-Level Questions

Q1. What is batch automation?

Answer:

Batch automation automatically produces a finite quantity of product according to a defined recipe, sequence, process parameters and equipment conditions, while maintaining batch status and traceability.

Q2. What is the difference between recipe and batch?

Answer:

A recipe defines how a product should be produced. A batch is one actual production execution of that recipe.

Q3. Can batch automation use PLCs?

Yes. PLCs are widely used for sequence control, equipment control, analog control, interlocks, permissives and phase execution.

Q4. Can batch automation use DCS?

Yes. DCS platforms are commonly used in process-oriented batch applications and can provide continuous control, sequence control, operator interfaces, alarms, history and batch functionality.

Q5. Does batch automation mean only sequence control?

No.

Batch automation commonly combines:

Sequence control + continuous/process control + recipe management + batch tracking.

Q6. What is a batch record?

A historical record containing information about a particular batch, such as recipe, materials, equipment, process values, events, alarms, operator actions and completion information.

Q7. Why is Batch ID important?

It provides unique identification and traceability for a specific production execution.

Q8. What happens when a batch is put on hold?

The batch temporarily stops progressing until the required condition or intervention is resolved and the batch is allowed to resume.

Q9. What is campaign production?

Producing multiple batches of the same or related product before performing a major changeover.
