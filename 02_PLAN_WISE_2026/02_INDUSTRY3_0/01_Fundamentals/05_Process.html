1. What is Process Automation?

Process automation is the use of automatic control systems to monitor, control, and regulate a physical process, particularly processes involving continuously or semi-continuously varying physical quantities.

The important idea is not individual parts.

Instead, the system is concerned with process variables such as:

  • Temperature
  • Pressure
  • Flow
  • Level
  • Speed
  • pH
  • Density
  • Composition
  • Humidity
  • Concentration

The automation system continuously measures these variables and adjusts the process to achieve the desired operating condition.

A simplified model is:

Process
   ↓
Measurement
   ↓
Controller
   ↓
Control action
   ↓
Process
   ↑
Feedback

This is the fundamental idea behind process automation.

2. The Core Difference from Discrete Automation

You just studied:

Discrete Automation

The main question is often:

What operation should happen next?

Process automation is more concerned with:

What value should the process variable be maintained at?

For example:

Discrete

Part detected?
    ↓ YES
Clamp
    ↓
Machine
    ↓
Unclamp

Process

Temperature = 85°C
       ↓
Compare with setpoint
       ↓
Temperature too low?
       ↓
Increase heating
       ↓
Temperature rises
       ↓
Approaches 85°C
       ↓
Reduce heating

So the emphasis changes from sequence to regulation/control of process variables.

3. The Basic Process-Control Loop

The most important diagram in this topic is:

             SETPOINT
                 │
                 ↓
          ┌─────────────┐
          │             │
          │ Controller  │
          │             │
          └──────┬──────┘
                 │
                 ↓
              Output
                 │
                 ↓
             Actuator
                 │
                 ↓
              PROCESS
                 │
                 ↓
              Sensor
                 │
                 ↓
           Measurement
                 │

This is a closed-loop control system.

The controller continuously receives information about the actual process condition and adjusts the output.

4. Setpoint

The setpoint, usually abbreviated SP, is the desired value of a process variable.

Example:

Temperature SP = 80°C

The controller's job is to maintain the actual temperature near 80°C.

Other examples:

Pressure SP = 5 bar

Flow SP = 100 L/min

Level SP = 70%

Speed SP = 1500 RPM

5. Process Variable

The process variable, or PV, is the actual measured value.

Example:

SP = 80°C
PV = 74°C

The controller sees that the actual temperature is below the desired temperature.

Therefore, it may increase the heating output.

Another example:

SP = 80°C
PV = 84°C

Now the actual temperature is above the desired value.

The controller may reduce heating or increase cooling.

6. Error

The controller generally considers the difference between the desired and actual values.

A simplified representation is:

Error = Setpoint - Process Variable

Example:

SP = 80°C
PV = 74°C

Error = 80 - 74
      = +6°C

The controller uses this error to determine an appropriate control action.

This concept is fundamental to closed-loop control.

7. Manipulated Variable

The manipulated variable, often called MV, is the variable the controller changes to influence the process.

For example:

Temperature control

PV = Temperature

MV = Heater output

Flow control

PV = Flow rate

MV = Control valve position

Pressure control

PV = Pressure

MV = Valve position / compressor output

Level control

PV = Tank level

MV = Inlet or outlet flow

So:

SP
 ↓
Controller
 ↓
MV
 ↓
Process
 ↓
PV
 ↓
Feedback

8. Sensor / Transmitter

The process variable has to be measured.

Typical measurement devices include:

Temperature

  • RTD
  • Thermocouple
  • Temperature transmitter

Pressure

  • Pressure transmitter
  • Pressure switch

Flow

  • Magnetic flowmeter
  • Coriolis flowmeter
  • Vortex flowmeter
  • Differential-pressure flow measurement

Level

  • Ultrasonic level transmitter
  • Radar level transmitter
  • Differential-pressure level measurement
  • Float-based measurement

Composition

  • pH analyzer
  • conductivity analyzer
  • gas analyzer
  • concentration analyzer

The measurement device converts a physical condition into a usable signal.

9. Transmitter

A transmitter is commonly used to convert a measured physical quantity into a standardized industrial signal.

For example:

Temperature
   ↓
Temperature transmitter
   ↓
4–20 mA
   ↓
Controller

Similarly:

Pressure
   ↓
Pressure transmitter
   ↓
4–20 mA
   ↓
Controller

This is why 4–20 mA is so important in traditional industrial process automation.

10. Why 4–20 mA?

A common analog instrumentation signal is:

4–20 mA

For example:

4 mA  →  0 bar
12 mA →  5 bar
20 mA → 10 bar

The controller can determine the process value from the current.

An important advantage is that 4 mA represents the lower end rather than 0 mA.

Therefore:

0 mA

can potentially indicate:

  • broken wire
  • loss of power
  • transmitter failure
  • disconnected circuit

while:

4 mA

can represent a legitimate measured zero.

This is called live zero.

11. Controller

The controller receives the measurement and determines the required control action.

Controllers may include:

  • PLC
  • dedicated PID controller
  • DCS controller
  • industrial PC
  • process controller

The exact architecture depends on the application.

In many modern plants, PLCs are absolutely capable of process control.

Therefore:

Process automation does not automatically mean DCS.

DCS is strongly associated with process industries, but PLC-based process control is also common.

12. PID Control

One of the most important concepts in process automation is PID control.

PID means:

P = Proportional

I = Integral

D = Derivative

A PID controller calculates a control output based on the behavior of the error.

Conceptually:

Error
  │
  ├── P
  ├── I
  └── D
       ↓
Controller output

The purpose is to make the process variable follow the desired setpoint.

13. Proportional Control

The proportional component reacts to the current error.

If the error becomes larger, the controller generally produces a larger corrective action.

Example:

SP = 100°C

PV = 80°C
Error = 20°C
→ larger correction

PV = 95°C
Error = 5°C
→ smaller correction

Conceptually:

P responds to how far away the process currently is from the setpoint.

14. Integral Control

The integral component responds to the accumulated error over time.

This is important when a system has a persistent offset.

Example:

SP = 100°C

PV remains around 97°C

There is a persistent 3°C error.

The integral action accumulates that error and increases the control effort until the steady-state error is reduced.

Conceptually:

I responds to how long and how much error has accumulated.

15. Derivative Control

The derivative component responds to the rate of change of error.

It attempts to anticipate where the process is heading.

For example, if temperature is rising very rapidly toward the setpoint, derivative action can help reduce excessive overshoot.

Conceptually:

D responds to how quickly the error is changing.

16. PID Mental Model

A useful memory aid:

P = Present error

I = Past accumulated error

D = Future tendency / rate of change

More precisely:

P → current error

I → accumulated error

D → rate of change of error

This is one of the most useful interview-level concepts in process automation.

17. Example: Temperature Control

Consider an industrial oven.

Required temperature:

SP = 200°C

Actual temperature:

PV = 180°C

The controller detects:

Error = +20°C

It increases heater output.

Then:

PV = 190°C

The error decreases.

Then:

PV = 198°C

The controller reduces the heating demand.

Eventually:

SP ≈ PV

200°C ≈ 200°C

The controller continuously adjusts the output to maintain the desired temperature.

18. Open-Loop vs Closed-Loop

This distinction is important.

Open-loop control

The controller does not use feedback from the process to correct the output.

Example:

Turn heater ON for 10 minutes

The system does not care whether the actual temperature reaches 100°C.

Timer
 ↓
Heater
 ↓
Process

Closed-loop control

The system measures the actual process condition.

Setpoint
   ↓
Controller
   ↓
Heater
   ↓
Process
   ↓
Temperature sensor
   ↓
Controller

Now the system can continuously correct the process.

Most important process control applications use closed-loop control.

19. Feedback

Feedback is the information returned from the process to the controller.

Example:

Setpoint = 100°C

Controller
    ↓
Heater
    ↓
Oven
    ↓
Temperature
    ↓
RTD
    ↓
Temperature transmitter
    ↓
PLC/PID

The controller knows what actually happened because of feedback.

Without measurement, meaningful closed-loop regulation is impossible.

It sends a command to a final control element.

  • actuator

26. Control Valve

Control valves are extremely common in process automation.

A simplified system:

Flow transmitter
      ↓
Flow controller
      ↓
Valve command
      ↓
Control valve
      ↓
Process flow
      ↓
Flow transmitter

Suppose:

SP = 100 L/min
PV = 80 L/min

The controller may increase valve opening.

If:

PV = 105 L/min

the controller may reduce the valve opening.

This continuous correction is characteristic of process control.

Increase pump speed

If pressure is too high:

Reduce pump speed

This is process automation combined with variable-speed motor control.

31. Process Trips

A trip is generally associated with automatically taking equipment/process action when a dangerous or unacceptable condition occurs.

Example:

High pressure
      ↓
Trip condition
      ↓
Pump shutdown

or:

Very high temperature
      ↓
Safety action
      ↓
Heater shutdown

The exact behavior depends on the process and safety design.

This is different from simply displaying an alarm.

32. Process Automation and Safety

Process plants can contain hazardous conditions involving:

  • high pressure
  • high temperature
  • combustible materials
  • toxic chemicals
  • flammable gases
  • high energy
  • rotating machinery

Therefore process automation can interact closely with:

  • safety instrumented systems
  • emergency shutdown systems
  • interlocks
  • trips
  • pressure protection
  • fire and gas systems

But process control and process safety should not be treated as the same thing.

The basic control system regulates the process.

Safety systems are designed to protect people, equipment and the environment when hazardous conditions occur.

33. Cascade Control

A more advanced process-control structure is cascade control.

Instead of one controller directly controlling the final element:

Main controller
      ↓
Valve
      ↓
Process

you can have:

Primary controller
       ↓
Secondary controller
       ↓
Valve
       ↓
Process

For example, temperature control may manipulate a secondary flow loop.

Conceptually:

Temperature SP
      ↓
Temperature Controller
      ↓
Steam Flow SP
      ↓
Flow Controller
      ↓
Steam Valve
      ↓
Heater
      ↓
Temperature

This allows the system to respond more effectively to disturbances.

For your current Fundamentals topic, understand the concept. Detailed cascade tuning belongs to more advanced control study.

34. Feedforward Control

Another advanced concept is feedforward control.

Instead of waiting for the process variable to change, the controller responds to a measured disturbance.

Example:

Disturbance detected
       ↓
Feedforward calculation
       ↓
Control action
       ↓
Process

This can be combined with feedback control.

Conceptually:

Disturbance
    ↓
Feedforward ──────┐
                  ↓
Process ←──── Controller
   ↓
Feedback ────────┘

The important idea:

Feedback reacts after observing the result.

Feedforward attempts to compensate for a disturbance before its full effect appears.

35. Process Dynamics

A process does not necessarily respond instantly to an input.

For example:

Heater output increases
       ↓
Heat transfer occurs
       ↓
Material temperature slowly increases
       ↓
Temperature reaches new condition

There may be:

  • delay
  • lag
  • inertia
  • dead time
  • time constant

Therefore process automation must account for process behavior over time.

This is one major reason process control differs from simple ON/OFF sequence control.

36. ON/OFF Control vs Continuous Control

Not every process controller must use PID.

A simple temperature controller could operate:

Temperature < 90°C
→ Heater ON

Temperature > 100°C
→ Heater OFF

This is ON/OFF control.

It is simple but can produce cycling around the desired range.

A more precise system may use proportional/PID control:

Temperature slightly low
→ Small heating output

Temperature significantly low
→ Large heating output

This gives finer control.

37. Analog vs Digital Control

Process automation traditionally makes extensive use of analog measurements.

For example:

Temperature = 173.6°C
Pressure = 5.72 bar
Flow = 84.3 L/min

The controller needs more information than simply:

ON
OFF

But modern digital systems process these analog measurements numerically.

So:

Physical variable → analog/digital measurement → digital controller → analog/digital output → physical process

39. Example: Pressure Control

Suppose a compressed-air system requires:

SP = 7 bar

Actual:

PV = 6.5 bar

The controller may increase compressor output.

As pressure approaches 7 bar:

PV = 6.9 bar

The controller reduces the required output.

This is closed-loop process control.

40. Example: Flow Control

Suppose:

SP = 500 L/min
PV = 450 L/min

The flow controller may increase the control valve opening.

As flow approaches:

500 L/min

the control action is adjusted.

The same control philosophy applies to many process variables.

41. Process Automation Troubleshooting

For maintenance, the following chain is extremely useful:

Process variable wrong
        ↓
Is the process actually wrong?
        ↓
Is the sensor measuring correctly?
        ↓
Is the transmitter healthy?
        ↓
Is the signal reaching the controller?
        ↓
Is the scaling correct?
        ↓
Is the controller receiving correct PV?
        ↓
Is the setpoint correct?
        ↓
Is the controller output correct?
        ↓
Is the final control element responding?
        ↓
Is the process responding?

This prevents the classic maintenance mistake of replacing the transmitter because the HMI value looks wrong, only to discover that someone entered incorrect scaling three years ago and humanity collectively decided it was tomorrow's problem.

50. Interview-Level Questions

Q1. What is process automation?

Process automation is the automatic monitoring and control of physical processes using measurements, controllers and final control elements to maintain desired operating conditions.

Q2. What are common process variables?

Temperature, pressure, flow, level, speed, pH, composition and humidity.

Q3. What is the difference between SP and PV?

SP is the desired value.

PV is the actual measured value.

Q4. What is MV?

The manipulated variable is the quantity adjusted by the controller to influence the process.

Q5. What is feedback control?

A control method in which the actual process output is measured and returned to the controller so corrective action can be applied.

Q6. What is PID?

PID stands for Proportional, Integral and Derivative control.

Q7. What does P do?

Responds primarily to the current error.

Q8. What does I do?

Responds to accumulated error over time and helps eliminate persistent offset.

Q9. What does D do?

Responds to the rate of change of error and can help anticipate rapid changes.

Q10. Is DCS required for process automation?

No. Process automation can use PLCs, PID controllers, DCS and other control architectures.

Q11. What is a control valve?

A final control element that regulates process flow, pressure, temperature or another process condition by changing fluid flow.

Q12. What is a 4–20 mA signal?

A common industrial analog instrumentation signal used to represent a measured value or control command.

Q13. Why is 4 mA used instead of 0 mA as the lower value?

It provides a live zero, allowing 0 mA to potentially indicate a fault such as loss of signal or wiring.

Q14. Can a manufacturing plant contain both discrete and process automation?

Yes. For example, production machines may use discrete automation while furnaces, paint systems, utilities and HVAC use process automation.

Q15. Is process automation only for chemical plants?

No. It is used across many industries wherever physical process variables need automatic monitoring and control.
