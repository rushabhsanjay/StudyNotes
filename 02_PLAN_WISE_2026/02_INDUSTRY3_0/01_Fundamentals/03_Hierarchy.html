The purpose of this topic is to understand how a manufacturing system is organized from the smallest operational unit to the complete manufacturing facility.

The hierarchy is:

Machine → Cell → Line → Shop → Plant

Think of it as increasing scope of operation, coordination, material flow, production responsibility, and management visibility.

It is not simply a hierarchy of physical size. A larger physical object is not automatically a higher hierarchy level. The important question is:

What operational scope does this level control or coordinate?

1. Machine

A machine is the basic individual production or processing unit.

It performs a defined manufacturing operation on a workpiece, component, material, or product.

Examples:

  • CNC machining center
  • CNC lathe
  • Press
  • Welding machine
  • Assembly machine
  • Robot
  • Conveyor machine
  • Testing machine
  • Heat-treatment equipment
  • Packaging machine

A machine normally contains several subsystems:

Machine → mechanical system → electrical system → sensors → actuators → controller → HMI/operator interface → safety system → communication/networking → process tooling

Example

Consider a CNC machining center.

It may contain:

  • CNC controller
  • Servo drives
  • Servo motors
  • Spindle drive
  • Spindle motor
  • Tool changer
  • Coolant system
  • Hydraulic/pneumatic system
  • Limit/proximity sensors
  • Safety door
  • PLC logic
  • HMI/CNC display

All of these together form one production machine.

Automation perspective

At the machine level, automation is primarily concerned with:

  • sensing
  • decision-making
  • sequencing
  • motion
  • actuation
  • interlocking
  • safety
  • operator interaction
  • machine diagnostics

A simplified flow is:

Sensor → Controller → Logic → Actuator → Physical operation

For example:

Part present sensor → PLC detects part → PLC checks permissives → clamp command → clamp cylinder operates → clamp confirmation → machining cycle starts

That entire sequence belongs primarily to the machine level.

2. Cell

A cell is a group of machines/equipment arranged to perform a related manufacturing operation or a sequence of operations.

So:

Machine = individual production unit

Cell = coordinated group of production units

A cell may contain:

  • multiple machines
  • robots
  • conveyors
  • fixtures
  • inspection equipment
  • loading/unloading systems
  • material handling equipment
  • safety systems
  • cell controller/network

Example

Imagine an automated machining cell:

Part loading ↓ Robot ↓ CNC Machine 1 ↓ Robot ↓ CNC Machine 2 ↓ Inspection station ↓ Unloading

Here, CNC 1, CNC 2, robot, inspection station and material handling are not independent from the production point of view.

They operate together as a manufacturing cell.

Why a cell exists

The purpose is generally to coordinate several machines/equipment around a related manufacturing process.

Instead of thinking:

"Machine 1 is doing something."

you start thinking:

"This group of machines is producing a particular operation or product flow."

3. Machine vs Cell

This distinction is extremely important.

Machine Cell
Individual production unit Group of coordinated equipment
Performs a specific operation Coordinates multiple operations/equipment
Local machine control Cell-level coordination
PLC/CNC/HMI may control it Cell controller/network may coordinate machines
One machine failure affects that machine One cell problem may affect several machines

Example:

Machine:

CNC-01

Cell:

CNC-01 + CNC-02 + Robot-01 + Inspection-01 + conveyors + fixtures

The robot may load CNC-01 and CNC-02, while the inspection station verifies the completed component.

That entire coordinated area is the cell.

4. Line

A production line consists of multiple machines and/or cells arranged in a defined production sequence to manufacture or process a product.

The key idea is:

Material/product flows through a sequence of operations.

For example:

Raw component ↓ Operation 1 ↓ Operation 2 ↓ Operation 3 ↓ Inspection ↓ Operation 4 ↓ Finished component

Each operation may itself be a machine or an entire cell.

Therefore:

Line = coordinated production flow consisting of multiple operations/cells/machines.

Example

An automotive component production line could contain:

Cell 1 → machining

Cell 2 → drilling

Cell 3 → washing

Cell 4 → inspection

Cell 5 → assembly

Together they form a production line.

5. Cell vs Line

The distinction is mainly about scope and production flow.

Cell

Focus:

"How do these machines work together?"

Line

Focus:

"How does the product move through these operations?"

Example:

Cell

Robot + CNC1 + CNC2 + inspection

↓

Line

Cell A → Cell B → Cell C → Cell D

The cell is a coordinated local manufacturing group.

The line represents the broader sequence of production operations.

6. Shop

A shop is a larger manufacturing area containing multiple production lines, cells, machines, support systems, and associated activities for a particular manufacturing function or product family.

This is where the scope becomes significantly larger.

A shop might be organized around activities such as:

  • machining
  • body manufacturing
  • paint
  • assembly
  • forging
  • stamping
  • engine manufacturing
  • transmission manufacturing
  • welding

For example:

Machining Shop

may contain:

  • Line 1
  • Line 2
  • Line 3
  • Line 4
  • inspection areas
  • material handling
  • tool management
  • maintenance facilities
  • utilities
  • production support

So:

Machine

↓

Cell

↓

Line

↓

Shop

The shop is therefore a larger production organization containing multiple production systems.

7. Plant

A plant is the complete manufacturing facility.

It may contain multiple shops and all the infrastructure required to operate the manufacturing facility.

A simplified structure could be:

Plant

├── Machining Shop ├── Assembly Shop ├── Paint Shop ├── Welding Shop ├── Quality ├── Maintenance ├── Utilities ├── Stores ├── Material Handling └── Other support functions

Therefore:

Plant = overall manufacturing facility

It represents the highest level in this particular hierarchy.

The entire concept can now be visualized as:

PLANT
│
├── SHOP
│   │
│   ├── LINE
│   │   │
│   │   ├── CELL
│   │   │   │
│   │   │   ├── MACHINE
│   │   │   ├── MACHINE
│   │   │   └── MACHINE
│   │   │
│   │   ├── CELL
│   │   └── CELL
│   │
│   ├── LINE
│   └── LINE
│
├── SHOP
│   ├── LINE
│   └── LINE

└── SHOP
    ├── LINE
    └── LINE

The important relationship is:

Many machines → form a cell

Many cells/machines → form a line

Many lines/cells → form a shop

Many shops → form a plant

This is the conceptual structure, not a rigid rule that every factory must physically implement exactly this way.

Consider a hypothetical automotive component plant.

One CNC machine:

Its job:

A machining cell:

Robot → CNC-101 → CNC-102 → Inspection

The robot transfers components between machines.

Now several machines cooperate.

      ↓

      ↓

      ↓

      ↓

      ↓

The product progresses through multiple manufacturing stages.

Shop level

The machining shop contains:

Machining Line 2
Machining Line 3
Machining Line 4
Tool management
Inspection

Now the scope is the complete machining production area.

Plant level

The complete plant may contain:

├── Paint Shop
├── Machining Shop
├── Assembly Shop

Now we are looking at the complete manufacturing facility.

10. What Happens When You Move Up the Hierarchy?

As we move upward:

Machine → Cell → Line → Shop → Plant

the scope increases.

Level Primary focus
Machine Individual operation
Cell Coordinated equipment
Line Product/process flow
Shop Production area
Plant Complete manufacturing facility

Another way to remember it:

Machine = Do

Cell = Coordinate

Line = Flow

Shop = Organize production area

Plant = Integrate the factory

These are conceptual memory aids, not formal definitions.

11. Control and Coordination

The hierarchy also matters from an automation perspective.

At the machine level, you may have:

  • sensors
  • actuators
  • PLC
  • CNC
  • VFD
  • servo
  • HMI
  • safety controller

At the cell level, you may additionally have:

  • robot controller
  • machine-to-machine communication
  • cell PLC
  • conveyors
  • inspection systems
  • handshake signals

At the line level:

  • line coordination
  • production sequencing
  • line status
  • material flow
  • production monitoring
  • line-level data collection

At the shop level:

  • multiple production lines
  • production monitoring
  • maintenance coordination
  • quality coordination
  • material coordination

At the plant level:

  • multiple shops
  • plant-wide production
  • quality
  • maintenance
  • logistics
  • utilities
  • management systems
  • enterprise integration

This is where the hierarchy begins connecting naturally with the industrial automation architecture you already studied.

12. Important: Hierarchy Is NOT the Same as Automation Architecture

This distinction should be kept very clear.

You previously studied:

Industrial Automation Architecture

Now you are studying:

Machine → Cell → Line → Shop → Plant

These are related, but they answer different questions.

Hierarchy asks:

Where does the manufacturing activity belong?

Machine → Cell → Line → Shop → Plant

Automation architecture asks:

How are sensing, control, supervision, communication and higher-level systems organized?

For example:

Field → Control → Supervisory

These two concepts can exist simultaneously.

A machine can have:

  • field devices
  • PLC/control system
  • HMI/supervisory interface

while that machine itself belongs to:

Cell → Line → Shop → Plant

Do not merge these two hierarchies into one giant conceptual soup. Humanity already has enough badly labelled architecture diagrams.

13. Physical Hierarchy vs Control Hierarchy

A useful mental model is:

Manufacturing hierarchy

Machine
   ↓
Cell
   ↓
Line
   ↓
Shop
   ↓
Plant

This describes manufacturing organization/scope.

Automation/control hierarchy

Field
   ↓
Control
   ↓
Supervisory
   ↓
Higher-level systems

This describes automation/control organization.

They overlap, but they are not identical.

For example:

A machine can contain field devices and a PLC.

A cell can coordinate several PLC-controlled machines.

A line can coordinate several cells.

A plant can collect information from many lines and shops.

14. Why This Hierarchy Matters to Maintenance

For an automation/maintenance engineer, the hierarchy is extremely useful for troubleshooting.

Suppose production has stopped.

The first question should not always be:

"Which PLC has the fault?"

Instead determine the affected scope.

Machine problem

One machine stopped.

Example:

CNC-03 fault

Other machines continue operating.

Likely scope:

Machine

Cell problem

Several machines/equipment cannot operate because the cell coordination is unavailable.

Example:

Robot communication failure prevents loading/unloading of multiple CNCs.

Likely scope:

Cell

Line problem

Several cells are affected because the line-level flow or coordination has stopped.

Example:

A major conveyor or line-control issue stops material flow between multiple cells.

Likely scope:

Line

Shop problem

Multiple production lines are affected.

Possible causes:

  • shop-level power problem
  • utility failure
  • network infrastructure failure
  • material issue
  • common automation infrastructure
  • safety-related shutdown

Likely scope:

Shop

Plant problem

Multiple shops or the entire facility are affected.

Possible causes include:

  • plant-wide electrical failure
  • major utility failure
  • network infrastructure failure
  • plant-wide emergency shutdown
  • major common infrastructure failure

Likely scope:

Plant

This gives maintenance personnel a very useful principle:

Identify the smallest level that explains the observed failure, then move upward only when evidence requires it.

15. Fault Propagation

A lower-level failure can propagate upward.

Example:

Machine failure
      ↓
Cell cannot complete operation
      ↓
Line production stops
      ↓
Shop production affected
      ↓
Plant production impact

But the reverse is also possible:

Plant utility/network failure
      ↓
Shop affected
      ↓
Multiple lines affected
      ↓
Multiple cells affected
      ↓
Machines stop

Therefore, seeing a machine stopped does not automatically mean the machine itself is faulty.

This is a very important maintenance concept.

A machine may be healthy but stopped because:

upstream → cell → line → shop → plant

something outside the machine is preventing operation.

18. A Very Important Nuance

The hierarchy is not universally rigid.

A real factory may use different organizational terminology.

For example:

Plant
 └── Area
      └── Line
           └── Cell
                └── Machine

Another factory might use:

Plant
 └── Shop
      └── Area
           └── Line
                └── Station

Another may call a group of machines an island, work center, production unit, or something else.

Therefore, the exact names can vary.

The fundamental idea remains:

Group smaller production units into progressively larger operational scopes.

For your study reference, however, the terminology to retain is specifically:

Machine → Cell → Line → Shop → Plant. Pasted markdown(1)

19. Machine, Cell, Line, Shop, Plant: One-Line Definitions

These are the definitions worth memorizing.

Machine An individual production or processing unit performing a defined operation.

Cell A coordinated group of machines/equipment performing related manufacturing operations.

Line A sequence of machines/cells through which material or product progresses through multiple manufacturing operations.

Shop A larger manufacturing area containing multiple production lines/cells and associated production/support activities.

Plant The complete manufacturing facility containing multiple shops and the infrastructure required for production.

21. Interview-Level Questions

Q1. What is a manufacturing hierarchy?

A manufacturing hierarchy organizes production from individual machines to larger coordinated production units, typically:

Machine → Cell → Line → Shop → Plant.

Q2. What is the difference between a machine and a cell?

A machine is an individual production unit. A cell is a coordinated group of machines/equipment performing related operations.

Q3. What is the difference between a cell and a line?

A cell focuses on coordinated local equipment, while a line represents a broader sequence of production operations and product flow.

Q4. What is a shop?

A shop is a larger manufacturing area containing multiple production lines/cells and associated production activities.

Q5. What is a plant?

A plant is the complete manufacturing facility containing multiple shops and supporting infrastructure.

Q6. Does every factory strictly follow Machine → Cell → Line → Shop → Plant?

No. Terminology and physical organization vary between factories. The hierarchy is a conceptual way to represent increasing manufacturing scope.

Q7. Is machine → cell → line → shop → plant the same as field → control → supervisory?

No.

Machine → Cell → Line → Shop → Plant represents manufacturing/operational hierarchy.

Field → Control → Supervisory represents automation/control architecture.

The complete concept can be reduced to:

        ↓
CELL

        ↓
LINE
Sequence of manufacturing operations
        ↓
SHOP
Group of production lines/areas
        ↓

The critical idea is scope.

A machine answers:

What operation is being performed?

A cell answers:

How are several machines/equipment coordinated?

A line answers:

How does the product move through multiple operations?

A shop answers:

How is a broader production area organized?

A plant answers:

How does the complete manufacturing facility operate?
