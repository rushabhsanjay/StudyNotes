DMG MORI

1. What DMG MORI is

DMG MORI is a machine-tool manufacturer and industrial manufacturing-systems provider. Its equipment covers CNC turning, milling, five-axis machining, multitasking, and integrated automation. The exact configuration depends on the machine model, generation, installed options, and customer application.

The key maintenance principle is this: DMG MORI is the machine builder, not one universal CNC control system. Two machines from the same builder can have different CNC controls, operator interfaces, PLC/PMC programs, drives, and diagnostic procedures.

What you must distinguish

Term Meaning Maintenance relevance
Machine builder DMG MORI or the relevant legacy brand Defines the machine's mechanical design and integrated functions
CNC controller Executes the machining program and coordinates motion Controls axes, interpolation, machining cycles, and supported CNC functions
HMI / operator interface Presents machine operation, status, alarms, and setup screens Helps operators and maintenance personnel interact with the machine
CELOS DMG MORI operating interface and digital manufacturing environment, depending on generation Provides a user-facing environment and application functions; it is not itself synonymous with the CNC controller
MAPPS Machine interface/control environment associated with Mori Seiki and DMG MORI platforms Integrates machine operation and functions; the underlying CNC architecture varies by model
PLC / PMC Executes auxiliary machine sequences and interlocks Controls tool changes, chuck operations, coolant, doors, hydraulics, and other sequences
Servo drive Converts motion commands into motor action Relevant to axis readiness, following errors, and motion faults
Spindle drive Controls spindle motor operation Relevant to speed, orientation, and spindle-related faults
Feedback devices Encoders, linear scales, switches, and sensors Confirm position and machine state
Machine mechanics Guides, ballscrews, bearings, spindle, turret, chuck, and tooling Determine physical accuracy, repeatability, and machining quality

2. DMG MORI machine families

Machine family Main purpose Typical maintenance focus
CNC turning centres Turning cylindrical components Chuck, turret, spindle, tailstock, tool offsets, and axis alignment
Vertical machining centres Milling with a vertically oriented spindle ATC, spindle, axis motion, tool clamping, and workholding
Horizontal machining centres Milling with a horizontal spindle Pallet handling, tool changing, rotary tables, and chip evacuation
Five-axis machines Machine complex surfaces using coordinated linear and rotary axes Rotary-axis calibration, kinematics, tool-centre-point functions, and collision prevention
Multitasking machines Combine turning and milling operations Spindle synchronization, tool management, live tooling, and coordinated operations
Mill-turn machines Combine milling and turning capabilities Turret or tool-head functions, spindle orientation, and coordinated machining

Not every machine has every function in the table. Never assume a pallet changer, probing system, live tooling, or five-axis package is installed just because the machine carries the DMG MORI name.

3. Machine architecture

A typical integrated CNC machine can be understood as a set of cooperating control layers.

Operator
   ↓
Machine HMI / CELOS / MAPPS, as fitted
   ↓
CNC controller
   ├── Axis motion commands → Servo drives → Motors → Machine axes
   ├── Spindle commands → Spindle drive → Spindle motor
   └── Auxiliary commands → PLC / PMC → Machine actuators
                                      ├── Tool changer / turret
                                      ├── Chuck / clamping system
                                      ├── Coolant / chip conveyor
                                      ├── Doors / hydraulic systems
                                      └── Pallet / automation interface

Feedback devices → CNC / PLC / PMC
Machine state and alarms → Operator interface

The diagram represents functional relationships, not a guaranteed wiring topology. Actual signal paths, networks, and controller integration vary by machine.

How the layers cooperate

  1. The operator selects a program, tool, work offset, and operating mode.
  2. The CNC interprets the program and generates coordinated motion commands.
  3. Servo and spindle drives execute the required motion.
  4. The PLC/PMC performs auxiliary sequences and checks their interlocks.
  5. Sensors and feedback devices report position and physical state.
  6. The controller evaluates completion conditions and reports faults or status to the operator.

A machine can display an alarm on the HMI even when the underlying fault is mechanical, electrical, pneumatic, hydraulic, or communication-related. The displayed alarm is evidence, not automatically the root cause.

4. CNC control and interface differences

DMG MORI machines may use different control platforms and interface generations. Siemens and FANUC are examples of CNC platforms encountered in industrial machine tools. MAPPS and CELOS refer to machine operating environments or interfaces whose capabilities depend on the particular implementation.

Component Primary responsibility What to verify
CNC hardware and software Program execution and motion coordination Control model, software version, machine data, configured options
HMI / MAPPS / CELOS Operator interaction and machine information Interface generation, installed applications, user permissions
PLC / PMC Auxiliary logic and machine sequences I/O status, sequence state, interlocks, timers, and diagnostic information
Servo system Axis movement and position control Drive-ready state, feedback, following error, motor and cable condition
Spindle system Spindle speed, orientation, and related control Drive state, speed feedback, orientation completion, and clamping conditions
Machine-builder integration Coordinates control, mechanics, tooling, and options Electrical drawings, hydraulic/pneumatic diagrams, manuals, and machine-specific documentation

Practical rule: Identify the exact machine and installed control before following a troubleshooting procedure. A generic FANUC or Siemens procedure may explain the principle but can still be wrong for the machine's configured interface, options, or machine-builder logic.

5. Axes, motion, and machining accuracy

CNC axes provide controlled movement between the cutting tool and workpiece.

  • Linear axes: Commonly designated X, Y, and Z, depending on the machine's configuration.
  • Rotary axes: Often designated A, B, or C according to the axis convention and rotation direction.
  • Spindle: Rotates the cutting tool or workpiece, depending on the machine type.
  • Feedback: Encoders or linear scales report position or movement to the control system.
  • Kinematics: Describe the relationship between the machine axes and the tool or workpiece coordinate systems.

Five-axis and multitasking considerations

Five-axis machining may coordinate three linear axes with two rotary axes. Advanced functions such as tool-centre-point control depend on the CNC platform, installed options, machine configuration, and calibration.

Important maintenance distinctions:

  • A commanded axis position is not necessarily the actual physical position.
  • A servo following error indicates a mismatch between commanded and measured position, but the cause may be mechanical, electrical, feedback-related, or control-related.
  • Rotary-axis calibration errors can create geometric errors even when individual axes appear to move normally.
  • Thermal growth, backlash, wear, tool condition, workholding, and incorrect compensation can all affect dimensional accuracy.
  • A machine can complete a program without an alarm and still produce an out-of-tolerance component.

Do not change axis parameters or compensation values merely to make a fault disappear. Record the original values, understand the machine's calibration method, and follow approved recovery procedures.

6. Tool systems and automatic tool changing

The machine may use an automatic tool changer (ATC), tool magazine, turret, or another tool-handling arrangement.

A typical tool-change operation requires coordination among the CNC, PLC/PMC, drives, sensors, and mechanical clamping devices.

Tool-change request
   ↓
Check operating mode and interlocks
   ↓
Move axes to the required tool-change position
   ↓
Verify spindle or turret conditions
   ↓
Release and transfer the tool, where applicable
   ↓
Index magazine or turret
   ↓
Clamp the selected tool
   ↓
Confirm completion using feedback signals
   ↓
Update tool state and resume machining

This is a conceptual sequence. The real order, sensors, and permitted states depend on the machine design.

Common tool-system fault categories

Symptom Possible causes First checks
Tool change does not start Missing interlock, wrong operating mode, axes not at required position Read alarm history and check sequence conditions
Tool change starts but does not finish Missing sensor confirmation, actuator problem, timeout Identify the exact step that stopped and inspect the associated feedback
Tool fails to clamp Toolholder issue, clamping mechanism fault, pressure or sensor problem Follow the machine's approved clamping checks
Magazine does not index Drive or motor issue, position feedback problem, mechanical obstruction Check drive status, index command, position confirmation, and mechanical condition
Turret does not index correctly Indexing mechanism, clamp/unclamp state, feedback, or sequence issue Check the requested station, actual station, and confirmation signals
Tool number appears incorrect Tool data mismatch, tool-management issue, incomplete recovery Verify magazine pocket, spindle tool, tool table, and recovery state

Never force an ATC or turret through a sequence simply because the machine is taking too long. Tool-handling mechanisms store energy and can create serious crush or impact hazards.

7. Spindle, chuck, and workholding systems

The spindle and workholding arrangement differs between turning and milling machines.

Turning machine

A turning centre commonly rotates the workpiece in a chuck while the tool moves along configured axes. Depending on the model, the machine may also include a sub-spindle, tailstock, steady rest, or driven tooling.

Important checks include:

  • Chuck clamping and unclamping confirmation.
  • Spindle orientation and speed feedback.
  • Hydraulic or pneumatic supply condition, where applicable.
  • Chuck pressure, clamping force, and workpiece seating.
  • Turret position and tool clearance.
  • Interlocks that prevent spindle operation under unsafe conditions.

Milling machine

A milling centre commonly rotates the cutting tool while the workpiece remains clamped to a table, fixture, or pallet.

Important checks include:

  • Toolholder seating and spindle clamping.
  • Spindle orientation during tool changes.
  • Workpiece clamping and fixture condition.
  • Pallet position and clamping confirmation, if fitted.
  • Coolant delivery and chip evacuation.
  • Work-offset and tool-length data.

Diagnostic distinction: A spindle that refuses to start may have a drive fault, but it may also be waiting for a valid operating mode, door condition, chuck confirmation, spindle orientation, or another interlock. Check the machine's sequence and alarm information before replacing a component.

8. PLC/PMC, interlocks, and machine sequences

The PLC or PMC manages much of the machine's auxiliary logic. Its role is especially important when the CNC requests an operation that requires multiple physical actions.

Examples include:

  • Tool changes and turret indexing.
  • Chuck clamping and unclamping.
  • Hydraulic and pneumatic functions.
  • Coolant and chip conveyor operation.
  • Machine doors and access interlocks.
  • Pallet changers and workpiece transfer.
  • Lubrication and auxiliary equipment monitoring.

A useful troubleshooting method is to trace each operation through five stages:

  1. Request: Did the CNC or operator issue the command?
  2. Permission: Are all required interlocks satisfied?
  3. Action: Did the PLC/PMC energize the intended output or command the actuator?
  4. Feedback: Did the expected sensor or drive status change?
  5. Completion: Did the sequence receive the confirmation needed to proceed?
Command issued
   ↓
Interlocks satisfied?
   ├── No → Identify the missing condition
   └── Yes
        ↓
Output or drive command present?
   ├── No → Investigate logic, mode, or command conditions
   └── Yes
        ↓
Physical movement occurred?
   ├── No → Investigate power, actuator, utilities, or mechanics
   └── Yes
        ↓
Feedback confirmed?
   ├── No → Investigate sensor, wiring, adjustment, or feedback
   └── Yes
        ↓
Sequence completes

This method is useful because it separates a control problem from a physical movement problem. It also prevents the classic maintenance ritual of replacing a perfectly healthy sensor because the alarm happened to mention it.

9. Probing, tool measurement, and compensation

Some machines have tool setters, workpiece probes, automatic tool measurement, or in-process measurement options.

These systems may help determine tool dimensions, workpiece position, tool wear, or geometric deviations. Availability and supported functions depend on the installed hardware and software.

Function Purpose Common failure categories
Tool measurement Establish or verify tool dimensions Probe contamination, calibration error, incorrect tool data
Workpiece probing Determine workpiece location or geometry Incorrect probe setup, signal failure, collision, wrong coordinate assumptions
Tool-breakage detection Detect a broken or missing tool, if fitted Detection threshold, sensor failure, incorrect configuration
Tool compensation Correct measured tool geometry or wear Incorrect offset, wrong tool assignment, stale measurement
Thermal compensation Reduce selected temperature-related errors, if configured Incorrect model or calibration, sensor fault, changed thermal conditions

A measurement result is only useful if the correct tool, coordinate system, calibration, and measurement procedure are in place.

When a component is out of tolerance, separate these possibilities:

  • The program or machining strategy is incorrect.
  • The tool geometry or wear offset is incorrect.
  • The work coordinate system is incorrect.
  • The fixture or workpiece is incorrectly located.
  • The machine has a mechanical or geometric error.
  • The measurement system or inspection method is inaccurate.

Do not use compensation changes to conceal a mechanical problem without an approved diagnostic basis.

10. Common faults and troubleshooting approach

Symptom Potential fault areas Diagnostic direction
Axis not ready Servo drive, feedback, enable conditions, interlocks Check drive status, alarm history, feedback, and axis-specific conditions
Axis following error Mechanical resistance, coupling, feedback, drive, tuning Compare commanded and actual motion; inspect mechanical condition safely
Spindle will not start Drive state, mode, interlock, spindle configuration Check spindle alarms, command conditions, and required permissives
Spindle will not orient Orientation feedback, drive, encoder, mechanical load Determine whether the orientation command was issued and what completion condition is missing
ATC timeout Sequence interruption, actuator, sensor, utility supply Identify the exact sequence step and missing confirmation
Turret indexing fault Indexing drive, position feedback, clamping mechanism Compare commanded station with confirmed station and inspect the relevant sequence
Chuck will not clamp Pressure, actuator, sensor, workholding mechanism Check the permitted operating conditions and approved pressure and clamping diagnostics
Pallet change fails Transfer sequence, position feedback, clamps, communication Determine which transfer stage failed and whether the pallet is in a known safe state
Probe measurement fails Probe signal, calibration, tool data, program sequence Verify setup, probe status, calibration, and the measurement cycle
Dimensional accuracy drifts Tool wear, thermal effects, mechanics, offsets, fixture Compare trends, measurements, offsets, and machine condition
Coolant or chip conveyor fails Motor, overload, blockage, sensor, supply Check the applicable electrical and mechanical conditions
Interface or communication fault Network, device power, controller state, configuration Identify the affected connection and check device and network diagnostics

These are fault categories, not a list of guaranteed DMG MORI alarm messages. Exact alarm numbers, descriptions, and recovery steps must come from the machine-specific documentation.

11. A disciplined diagnostic workflow

Use the following sequence for an unfamiliar machine fault.

Step 1: Identify the machine

Record:

  • Machine model and serial number.
  • CNC manufacturer, control model, and software version.
  • HMI, MAPPS, or CELOS generation, where applicable.
  • Installed options, such as a pallet changer, probing system, or additional spindle.
  • Relevant electrical, hydraulic, pneumatic, and mechanical documentation.

Step 2: Capture the fault before resetting

Record the alarm text, alarm history, operating mode, active program block, machine state, and the operation being attempted.

Where permitted, capture relevant diagnostic screens and status values. Avoid clearing evidence before recording it.

Step 3: Determine the failed control layer

Ask which part of the operation failed:

  • Did the CNC generate the request?
  • Did the PLC/PMC permit the operation?
  • Did the drive accept the command?
  • Did the actuator move?
  • Did the sensor confirm the result?
  • Did the sequence logic recognize completion?

Step 4: Inspect the relevant physical system

Use the machine's approved safety and isolation procedure. Check the relevant electrical supply, actuator, feedback device, cable, connector, mechanical movement, lubrication, and utility supply as appropriate.

Step 5: Verify the correction

Confirm that the original fault condition has been removed. Perform the prescribed recovery and functional test, then verify that the machine returns to a known state before production resumes.

Step 6: Record the result

Document the symptom, root cause, corrective action, replaced parts, parameter changes if authorized, and verification result. Track repeat faults rather than treating every recurrence as a new mystery.

12. Backups and configuration control

A CNC machine's backup is not necessarily one file. A complete recovery may require several independently stored datasets.

Backup item Why it matters
NC programs Preserves machining programs and revisions
CNC parameters or machine data Preserves control configuration and machine-specific settings
PLC/PMC program and data Preserves auxiliary logic and machine sequence configuration
Tool and work offsets Preserves machining setup information
Tool-management data Preserves tool assignments and related configuration, where supported
Drive parameters Preserves servo and spindle drive configuration, where applicable
HMI / MAPPS / CELOS configuration Preserves relevant interface settings and applications, where supported
Probe and calibration data Preserves measurement setup and calibration information
Network configuration Helps restore approved machine communication settings
Manuals and software versions Supports accurate recovery and compatibility checks

The exact backup scope depends on the machine and control platform. A backup of NC programs alone is not a full machine recovery backup.

Good practice:

  • Maintain a dated backup inventory.
  • Record the machine identity and control software version.
  • Store backups in an approved location with appropriate access controls.
  • Keep a known-good version separate from experimental changes.
  • Verify that the backup can be read and that the restoration procedure is documented.
  • Never restore parameters or PLC data from a different machine merely because the model looks similar.

13. Preventive maintenance

Preventive maintenance should cover the machine's mechanical systems, electrical systems, control configuration, and production process.

System Inspection focus Evidence to record
Electrical cabinet Cooling, filters, fans, connectors, visible damage Inspection results and temperature or cooling issues
Axes Lubrication, unusual noise, movement quality, feedback-related alarms Lubrication records, fault trends, inspection findings
Spindle Abnormal noise, temperature, vibration, drive alarms Trends and observations under approved conditions
ATC / turret Wear, clamping, indexing, sensor confirmation Cycle faults, inspection results, repeat failures
Chuck / workholding Clamping function, condition, pressure where applicable Inspection and approved test results
Coolant and chip systems Fluid condition, blockages, conveyor operation Cleaning, fluid checks, recurring faults
Pneumatic and hydraulic systems Leaks, supply condition, filters, pressure where applicable Findings and corrective actions
Probing and measurement Cleanliness, calibration status, repeatability Calibration and verification records
Control and network Alarm history, communications, approved configuration Fault log and backup status
Safety systems Guarding, interlocks, emergency-stop functions, safety devices Required inspection and functional-test records

Use the manufacturer's prescribed maintenance intervals and procedures. A checklist does not authorize changing a maintenance interval or testing a safety function by an improvised method.

14. Safety and recovery

CNC machines combine rotating equipment, sharp tools, high forces, automated movement, and potentially stored hydraulic or pneumatic energy.

  • Follow lockout/tagout and site isolation procedures before maintenance involving hazardous energy.
  • Verify the required safe state before entering the machine envelope.
  • Treat the spindle, chuck, turret, ATC, pallet changer, and robot interface as potential sources of hazardous movement.
  • Never bypass safety interlocks to force a production cycle to complete.
  • Use the approved recovery procedure when a tool, pallet, turret, or workpiece is left in an abnormal position.
  • Confirm the machine's state after recovery before returning it to automatic operation.
  • Use approved diagnostic and test methods for electrical, hydraulic, and pneumatic systems.

Important: An alarm reset is not proof that the underlying hazard or fault has been removed.

15. Interview questions and answers

Q1. What is DMG MORI?

DMG MORI is a machine-tool manufacturer and industrial manufacturing-systems provider offering CNC machining equipment and related automation solutions.

Q2. Is DMG MORI a CNC control manufacturer?

The name primarily identifies the machine builder and manufacturing group. Its machines can use different CNC platforms and interface configurations depending on model and generation.

Q3. What is the difference between CELOS and a CNC controller?

CELOS is an operating interface and digital manufacturing environment on supported machines. The CNC controller performs CNC-specific functions such as program execution and coordinated motion. Their exact integration depends on the machine generation.

Q4. What is MAPPS?

MAPPS is a machine operating and interface environment associated with Mori Seiki and DMG MORI equipment. Its implementation and underlying CNC platform vary across machines.

Q5. What is the role of the PLC/PMC in a CNC machine?

It manages auxiliary machine logic and sequences, including interlocks, tool changing, clamping, coolant, and other machine functions.

Q6. Why can a tool change fail even when the CNC is healthy?

The tool-change sequence may be blocked by an interlock, actuator fault, missing sensor confirmation, utility problem, mechanical obstruction, or PLC/PMC sequence condition.

Q7. What is an axis following error?

It is a difference between commanded and measured axis position beyond the applicable tolerance or threshold. Causes can include mechanical resistance, feedback problems, drive faults, or control issues.

Q8. Why might the spindle fail to start?

Possible causes include drive faults, missing enable conditions, operating-mode restrictions, safety conditions, or machine-specific interlocks.

Q9. What is spindle orientation?

It is the controlled positioning of the spindle at a specified angular position, often required for operations such as tool changing or other machine functions.

Q10. What is the difference between an ATC and a turret?

An ATC transfers tools between a magazine and spindle or another tool position. A turret indexes between tool stations and is commonly used on turning machines. Some machine designs use different tool-handling arrangements.

Q11. What causes CNC dimensional accuracy problems?

Potential causes include incorrect offsets, tool wear, thermal effects, workholding errors, mechanical wear, calibration errors, program issues, and measurement-system problems.

Q12. What is five-axis machining?

It coordinates motion across three linear and two rotary axes to machine complex geometry. Supported functions and kinematic arrangements depend on the machine and CNC configuration.

Q13. What is tool-centre-point control?

It is a CNC function that maintains the intended tool-tip or tool-centre-point relationship during coordinated axis movement, where supported and correctly configured.

Q14. Why should parameters not be changed casually?

Parameters can affect machine motion, calibration, limits, compensation, and safety-related behaviour. An incorrect change can cause accuracy problems, faults, or hazardous movement.

Q15. What information should be collected before diagnosing an alarm?

Machine identity, CNC model and version, alarm text and history, operating mode, active program state, the attempted operation, and relevant diagnostic values.

Q16. How would you diagnose a turret indexing fault?

Identify the requested station and actual confirmed position, inspect the relevant sequence and interlocks, check drive and sensor states, and investigate the mechanical indexing and clamping system using approved procedures.

Q17. What should a CNC backup include?

The applicable NC programs, CNC parameters or machine data, PLC/PMC, offsets, tool-management data, drive configuration, interface settings, probing/calibration information, and other machine-specific recovery data.

Q18. Why is a machine-specific backup important?

Similar machine models may differ in options, axis configuration, control generation, and machine-builder integration. Restoring the wrong configuration can cause faults or unsafe behaviour.

Q19. How can recurring CNC faults be reduced?

Record the fault conditions, identify the root cause, verify the corrective action, monitor recurrence, maintain approved backups, and use fault trends to improve preventive maintenance.

Q20. What is the most useful troubleshooting principle for a CNC machine?

Trace the operation from command to interlocks, actuator or drive response, feedback confirmation, and sequence completion. This narrows the fault to the layer that actually failed.

16. Practical exercises

Complete these exercises using a machine's approved documentation and, where appropriate, a training environment.

  • Create a machine configuration record containing the model, serial number, CNC platform, software versions, installed options, and manual locations.
  • Draw the actual machine architecture, showing the CNC, PLC/PMC, drives, HMI, feedback devices, and auxiliary systems.
  • Select a documented tool-change operation and identify its request, interlocks, outputs, feedback signals, and completion condition.
  • Build a troubleshooting record for one spindle, axis, turret, or pallet fault. Separate symptoms, evidence, root cause, correction, and verification.
  • Prepare a machine-specific backup checklist and record which datasets are available and when they were last verified.
  • Review a dimensional-quality problem and distinguish tool offset, work offset, tool wear, fixture, measurement, and machine-geometry possibilities.
  • Build a recurring-fault tracker that records frequency, downtime, root cause, corrective action, and recurrence after repair.
  • Review the applicable safety and recovery procedures for abnormal tool, turret, chuck, and pallet conditions.

17. Final mental model

DMG MORI supplies an integrated machine platform, but its exact control and interface configuration depends on the machine. The CNC interprets machining programs and coordinates motion. The PLC/PMC manages auxiliary sequences and interlocks. Drives operate the motors, feedback devices report machine state, and the mechanical system converts controlled movement into a machined component.

For maintenance, the most valuable skill is not memorizing a particular interface. It is identifying the installed architecture, tracing the failed operation through command, logic, actuation, and feedback, then correcting and verifying the actual cause.
