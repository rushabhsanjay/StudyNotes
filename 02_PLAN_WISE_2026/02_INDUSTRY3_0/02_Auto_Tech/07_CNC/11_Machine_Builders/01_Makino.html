01_Makino - Makino

1. What Is Makino?

Makino is a machine-tool manufacturer that develops and builds machining systems for precision metal cutting, high-speed machining, die and mould production, graphite and electrode machining, and electrical discharge machining (EDM).

The key distinction is that Makino is a machine builder, not a CNC control family. A Makino machine is an integrated industrial system containing mechanical assemblies, CNC controls, machine sequencing logic, drives, feedback devices, tooling systems, sensors, and auxiliary equipment.

The exact architecture depends on the machine model, manufacturing generation, application, and installed options.

Machine builder vs. CNC controller vs. component supplier

Category Examples Primary responsibility
Machine builder Makino Machine design, mechanical integration, machine-specific sequences, OEM configuration
CNC controller supplier FANUC, Siemens NC program execution, axis coordination, spindle commands, CNC diagnostics
PLC/PMC logic Machine-specific PMC or PLC Tool-change sequences, interlocks, hydraulic and pneumatic coordination, auxiliary functions
Drive supplier FANUC, Siemens and others Axis servo control, spindle control, motor feedback and drive diagnostics
Component supplier Encoder, probe, sensor, lubrication and cooling manufacturers Individual sensing, measurement, actuation or support functions

A machine may have a FANUC control and still behave differently from another FANUC-controlled machine because the machine builder's electrical design, PMC logic, options, and mechanics are different.

Maintenance principle: Knowing the CNC brand is not enough to diagnose the complete machine.

2. Makino Machine Types and Applications

Makino offers different machine platforms for different machining requirements. The following are broad application categories, not a claim that every model has identical features.

Machine category Typical application Important maintenance concerns
Horizontal machining centre (HMC) Multi-face machining, production machining, palletized manufacturing Pallet changer, rotary axes, tool changer, chip evacuation
Vertical machining centre (VMC) General precision machining, dies, moulds, components Spindle, axis accuracy, tool changer, coolant and chip removal
High-speed machining centre High-speed finishing and precision contouring Spindle condition, thermal stability, acceleration, vibration
Graphite/electrode machining Electrode production for EDM applications Dust extraction, spindle, precision, contamination control
Die and mould machining Complex 3D surfaces, precision finishing Thermal drift, tool condition, interpolation accuracy, probing
EDM machine Electrical discharge machining of conductive materials Dielectric system, electrodes, servo gap control, filtration and discharge monitoring

2.1 Horizontal machining centres

Horizontal machining centres are commonly selected when several faces of a component must be machined efficiently. Many configurations use rotary tables, pallet systems, or automatic pallet changers.

Maintenance priorities include:

  • Confirming pallet clamping and unclamping.
  • Checking pallet-position and clamp-confirmation sensors.
  • Inspecting rotary-axis feedback and clamping mechanisms.
  • Maintaining chip evacuation around the work zone.
  • Verifying tool-change and spindle-orientation sequences.

2.2 Vertical machining centres

Vertical machining centres commonly handle drilling, milling, boring, and precision contouring. Depending on the model, they may include automatic tool changers, probing systems, and advanced thermal compensation.

Maintenance priorities include spindle condition, axis positioning, tool clamping, lubrication, coolant management, and repeatability.

2.3 High-speed and precision machining

High-speed machining requires more than a spindle capable of reaching a high RPM. The complete system must coordinate spindle dynamics, axis acceleration, feedback resolution, thermal behaviour, tool balance, and machining strategy.

A machine can run without alarms and still produce defective components because of thermal drift, tool wear, vibration, backlash, or incorrect compensation.

2.4 EDM systems

EDM is a different machining process from conventional milling. Material is removed through controlled electrical discharges rather than a rotating cutting tool.

Depending on the EDM type, the system may use electrode or wire positioning, gap-control servo systems, dielectric circulation, filtration, and discharge monitoring. Do not assume an EDM machine shares the same spindle, ATC, or axis architecture as a milling centre.

3.1 CNC control

The CNC typically manages:

  • NC program interpretation.
  • Linear and rotary axis interpolation.
  • Feed-rate and spindle commands.
  • Tool and work coordinate compensation.
  • Program execution, overrides, and machining-related alarms.
  • Communication with the machine's sequence controller.

The CNC may be from FANUC, Siemens, or another supported platform depending on the machine. Confirm the actual installed control instead of inferring it from the Makino nameplate.

3.2 PMC or PLC

The machine's PMC/PLC logic coordinates functions such as:

  • Tool-change sequences.
  • Spindle orientation and readiness.
  • Tool clamp and unclamp commands.
  • Pallet-change sequences, where fitted.
  • Hydraulic and pneumatic operations.
  • Coolant and chip-conveyor commands.
  • Guard, pressure, position, and other permissive checks.
  • Alarm generation when expected feedback does not arrive.

The exact logic and signal names are machine-specific.

3.3 Servo and spindle systems

Axis servo systems position the machine's linear and rotary axes. The spindle drive controls spindle acceleration, speed, torque, and related functions.

Depending on the configuration, feedback may come from rotary encoders, linear scales, or other measurement devices.

Important diagnostic distinctions:

  • A CNC alarm may identify a program, motion, or control condition.
  • A servo alarm may indicate a drive, motor, feedback, or motion-control problem.
  • A PMC/PLC interlock may prevent movement because a required condition is not satisfied.
  • A mechanical fault may cause poor motion or accuracy even when the control reports no alarm.

3.4 Machine mechanics and auxiliary systems

The physical machine may include:

  • Spindle and spindle bearings.
  • Ball screws, linear guides, and axis couplings.
  • Rotary tables and rotary-axis clamps.
  • Automatic tool changer and tool magazine.
  • Pallet changer and workholding.
  • Lubrication and spindle-cooling systems.
  • Hydraulic and pneumatic circuits.
  • Coolant, filtration, and chip-conveyor systems.
  • Tool and workpiece probing.
  • Cabinet cooling, network devices, and remote I/O.

Not every machine has every subsystem. The machine configuration determines what is actually installed.

4. How CNC and Machine Logic Work Together

A CNC program may request a machine function using an M-code. The CNC does not necessarily operate the physical actuator directly. Instead, the request may be passed to the PMC/PLC, which runs the machine-specific sequence.

NC program requests a function
              |
              v
CNC sends M-function request
              |
              v
PMC/PLC checks permissives
              |
              v
Outputs command the mechanism
              |
              v
Actuator moves physically
              |
              v
Sensor confirms final position
              |
              v
PMC/PLC verifies sequence completion
              |
              v
Completion signal returns to CNC
              |
              v
CNC continues program execution

If the mechanism fails to reach its expected state, the sequence may time out and stop the machine.

For example, a tool-change command may be valid, but the sequence may remain incomplete because the spindle is not oriented, a tool is not confirmed clamped, or an arm-position sensor has not changed state.

Critical distinction: An M-code requests a function. The actual machine-specific sequence and its interlocks determine whether the function can safely complete.

5. Automatic Tool Changer (ATC)

An ATC transfers tools between the spindle and tool magazine. Its construction may use an exchange arm, magazine indexing, a carousel, or another design depending on the machine.

5.1 Typical tool-change sequence

An illustrative sequence is:

  1. CNC requests a tool change.
  2. The machine checks relevant safety and operating conditions.
  3. The spindle stops and reaches the required orientation.
  4. The tool-release mechanism operates when permitted.
  5. The magazine presents the required tool.
  6. The exchange mechanism transfers the tools.
  7. The new tool is clamped.
  8. Position and clamp sensors confirm the expected states.
  9. The PMC/PLC reports completion to the CNC.

This sequence is illustrative only. The actual order, actuator arrangement, and sensor logic must be obtained from the specific machine documentation.

5.2 Common ATC fault conditions

Symptom Possible fault layer Initial checks
Tool change will not start CNC/PMC permissive Read the active alarm and sequence status; check spindle, axis, and safety conditions
Spindle orientation fails Spindle drive, encoder, orientation logic Check spindle alarms, orientation command, feedback, and machine-specific conditions
Magazine does not index Drive, motor, sensor, mechanical obstruction Check indexing command, drive status, position feedback, and mechanical condition
Exchange arm stops midway PMC sequence, actuator, sensor, mechanical problem Identify the exact sequence step and expected sensor state
Tool is not confirmed clamped Clamp mechanism, pressure, sensor, feedback Check the permitted diagnostic indications for clamp state and supply pressure
Tool-change timeout Sequence completion not achieved Identify the missing transition rather than repeatedly resetting the alarm

5.3 ATC troubleshooting method

  1. Record the complete alarm text and the state of the machine.
  2. Determine the current sequence step from the appropriate diagnostic pages or approved service documentation.
  3. Identify the expected input or confirmation for that step.
  4. Check whether the command was issued and whether the physical mechanism responded.
  5. Compare the actual sensor state with the expected state.
  6. Check the actuator, air or hydraulic supply, drive status, wiring, and mechanical condition as applicable.
  7. Restore the system using the machine-approved recovery procedure.
  8. Validate tool-change operation before releasing the machine to production.

Do not force outputs or manually move a tool-change mechanism merely to make an alarm disappear. A machine that appears recovered but has an incorrectly positioned tool or arm is a more expensive problem waiting to happen.

6. Automatic Pallet Changer (APC)

An automatic pallet changer is used on machines equipped with palletized workholding. It allows one pallet to be machined while another can be prepared for the next operation, depending on the system design.

The APC may include pallet-transfer mechanisms, hydraulic or pneumatic clamps, locating devices, position sensors, and safety interlocks.

6.1 Typical pallet-change sequence

Pallet-change request
        |

        |

        |

Clamp pallet
        |

The actual sequence depends on the APC design and machine configuration.

6.2 Pallet-change troubleshooting

Symptom Possible cause Initial diagnostic check
Pallet change will not start Missing permissive Check active interlocks and machine-position requirements
Pallet unclamps but does not move Transfer mechanism, supply pressure, drive, or sequence fault Verify the expected movement command and actuator response
Pallet stops between positions Position feedback, obstruction, actuator or drive issue Identify the commanded and actual position
Pallet reaches position but will not clamp Clamp mechanism, pressure, seating, or sensor issue Check clamp command and approved clamp-confirmation diagnostics
APC reports timeout A required sequence transition was not confirmed Identify the first expected input that failed to change
Alarm returns after reset Underlying fault remains Record the sequence state and missing feedback before attempting recovery

Important: Pallet position confirmation and pallet clamping confirmation are different conditions. A pallet can appear to be in position without being securely clamped.

Never enter the pallet-transfer area or attempt manual recovery without the machine-specific safety procedure, isolation requirements, and control of stored energy.

7. Spindle System and Spindle Orientation

The spindle provides the rotational motion used by the machining process. Depending on the machine, its system may include a spindle motor, drive, encoder, bearings, cooling circuit, lubrication, tool-clamping mechanism, and orientation function.

7.1 Spindle functions

  • Start and stop.
  • Speed control.
  • Direction control where supported.
  • Acceleration and deceleration.
  • Orientation to a specified angular position.
  • Tool clamping and unclamping coordination.
  • Load and fault monitoring.

Spindle orientation is particularly important for operations such as tool changing and certain machining cycles.

7.2 Spindle will not start

Check the following in order:

  1. Record the alarm and identify whether it originates from the CNC, spindle drive, or machine sequence.
  2. Verify that the spindle-start command is being issued.
  3. Check the relevant machine permissives, such as tool-clamp status, safety conditions, and operating mode.
  4. Inspect spindle-drive readiness and alarm history.
  5. Compare commanded speed with actual spindle feedback.
  6. Check relevant motor, encoder, cooling, and lubrication indications.
  7. Inspect the spindle mechanically only according to the approved isolation and service procedure.

7.3 Spindle will not orient

Possible causes include:

  • Spindle-drive alarm or failure to become ready.
  • Incorrect or missing orientation command.
  • Encoder or orientation feedback issue.
  • A mechanical condition preventing rotation.
  • Missing machine-sequence permissive.
  • Configuration or parameter problems following maintenance.

Do not immediately change spindle parameters. First establish whether the command is issued, the drive responds, the spindle moves, and the expected orientation confirmation arrives.

8. Axis Positioning and Machining Accuracy

Makino precision machining systems depend on the combined performance of the machine structure, axis drives, feedback devices, spindle, tooling, workholding, and thermal-control strategy.

A machine can be operational but produce parts outside tolerance.

8.1 Important terms

Term Meaning Example of relevance
Accuracy Closeness of a measured position to the target A commanded 100 mm movement ends at 100.03 mm
Repeatability Ability to return to the same position consistently Repeated positioning gives different results
Resolution Smallest position increment represented by the measurement or control system Affects the granularity of position measurement
Backlash Lost motion associated with a mechanical transmission when direction reverses Can affect positioning in reversing movements
Thermal drift Position or geometry changes caused by temperature variation Dimensions change as the machine warms up
Servo following error Difference between commanded and actual motion position, as defined by the control May indicate overload, mechanical resistance, or a feedback/control problem

These are distinct concepts. Improving one does not automatically solve the others.

8.2 Causes of dimensional variation

  • Worn cutting tools or inconsistent tool setup.
  • Incorrect tool or work offsets.
  • Thermal expansion of the spindle, structure, or axis components.
  • Workholding movement or incorrect clamping.
  • Ball-screw, coupling, guideway, or bearing wear.
  • Feedback-device or encoder issues.
  • Excessive cutting forces, vibration, or chatter.
  • Incorrect compensation data or machine configuration.
  • Coolant-temperature variation or unstable process conditions.

8.3 Accuracy troubleshooting

First determine whether the error is repeatable, direction-dependent, time-dependent, or associated with a particular tool or machining operation.

Observation Investigation priority
Error occurs immediately after setup Tool/work offsets, workholding, program and setup
Error increases as the machine warms up Thermal behaviour, cooling, compensation, process stability
Error changes with axis direction Backlash, mechanical transmission, feedback, compensation
Error varies with tool or cutting conditions Tool wear, runout, toolholding, cutting forces
Positioning alarms accompany the defect Servo load, following error, feedback and mechanical resistance
Positioning appears correct but parts remain inaccurate Workpiece setup, spindle geometry, tool condition, process and measurement system

Use approved measurement procedures and qualified metrology equipment before changing compensation values. Uncontrolled compensation changes can make one component pass while introducing errors elsewhere.

9. Tool and Workpiece Probing

Depending on the installed options, a machine may use probes to measure tools, locate workpieces, verify features, or support automatic compensation.

9.1 Tool measurement

A tool-setting system may detect tool length, diameter, breakage, or other configured properties.

Potential failure points include:

  • Dirty or damaged measurement surfaces.
  • Incorrect tool identification or measurement sequence.
  • Electrical or optical signal problems.
  • Incorrect calibration or configuration.
  • Tool movement that does not follow the expected cycle.
  • Incorrect compensation handling.

9.2 Workpiece probing

A workpiece probe may be used to locate datums, measure features, or calculate work-coordinate adjustments.

If probing fails, distinguish among:

  1. The probe did not activate.
  2. The probe activated but the signal was not received correctly.
  3. The probe signal was received but the cycle did not accept it.
  4. The measurement completed but the resulting offset or value was incorrect.

These failures require different checks.

9.3 Probe fault checklist

  • Confirm the correct probe and measurement cycle are selected.
  • Check probe battery or power supply, communication, and signal status as applicable.
  • Inspect the stylus, mounting, and cleanliness.
  • Verify calibration and approved test procedures.
  • Review the CNC program and the relevant work or tool offset.
  • Check probe interface diagnostics and machine-specific interlocks.
  • Validate the result with an independent measurement where appropriate.

Never assume a probe is accurate merely because it triggers. A functioning trigger with incorrect calibration can produce consistently wrong measurements, which is arguably the more irritating failure mode.

10. Coolant, Lubrication, Chip Removal, and Utilities

These systems may look secondary to the CNC, but their failure can stop production or damage expensive equipment.

10.1 Coolant system

Common elements include a tank, pump, filters, pipes, nozzles, flow or level sensors, and optional temperature-control equipment.

Typical problems:

  • Low coolant level.
  • Blocked filters or nozzles.
  • Pump failure or overload.
  • Leakage or damaged pipework.
  • Flow or pressure feedback failure.
  • Contamination or incorrect coolant condition.

Check actual fluid level, pump command, pump status, filter condition, flow path, and relevant feedback before replacing components.

10.2 Lubrication system

Lubrication supports components such as guideways, ball screws, and other designated mechanical assemblies.

Potential issues include low lubricant level, blocked lines, pump faults, pressure or cycle-monitoring alarms, and incorrect lubricant.

Follow the specific Makino maintenance instructions. Never assume all machines use the same lubricant or lubrication interval.

10.3 Chip conveyor and chip management

Chip conveyors and chip-removal systems prevent accumulation around the work zone and support stable production.

Typical issues include jams, motor overload, failed sensors, damaged chains or belts, and blocked discharge points.

Before clearing a jam, isolate the relevant equipment and control stored energy. Never reach into a conveyor simply because it has stopped moving. Stopped is not the same as safely isolated.

10.4 Hydraulic and pneumatic systems

Depending on the configuration, these systems may operate tool clamps, pallet clamps, fixtures, doors, or other mechanisms.

Check:

  • Supply pressure and pressure stability.
  • Leakage and damaged hoses.
  • Valve command and response.
  • Cylinder movement.
  • Pressure-switch and position-sensor feedback.
  • Filter and regulator condition.
  • Whether the control sequence is waiting for a confirmation signal.

A pressure switch reporting a healthy state does not prove that every downstream actuator is mechanically functioning correctly.

11. CNC Alarms, PMC Diagnostics, and Electrical Troubleshooting

A disciplined technician identifies the layer in which the failure occurs rather than treating every machine alarm as a CNC problem.

11.1 Diagnostic layers

Layer Typical evidence Diagnostic direction
NC program Program alarm, invalid command, incorrect sequence Inspect the block, modal state, tool data, and program logic
CNC control CNC alarm or motion-control condition Review CNC diagnostics, status, and approved control documentation
PMC/PLC sequence Function requested but sequence does not progress Inspect sequence status, permissives, and expected feedback
Servo or spindle drive Drive alarm, not-ready condition, abnormal load Review drive status, fault history, motor and feedback diagnostics
Sensor and I/O Command issued but input remains unchanged Verify sensor state, wiring, supply, I/O channel, and target
Mechanical system Motion is obstructed, abnormal, or inaccurate Inspect the mechanism under approved isolation
Utilities Low pressure, insufficient flow, temperature or lubrication alarm Check the relevant utility and feedback
Network or communication Device unavailable or communication alarm Verify power, cabling, network configuration, and device status

11.2 Command-to-feedback tracing

For a machine function that will not complete, use this sequence:

1. Was the request issued?
          |
          v
2. Did the sequence controller accept it?
          |
          v
3. Were all permissives satisfied?
          |
          v
4. Was the output command generated?
          |
          v
5. Did the physical mechanism respond?
          |
          v
6. Did the expected sensor change state?
          |
          v
7. Did the sequence confirm completion?

The first point at which the expected behaviour stops is usually the most useful diagnostic boundary.

For example, if the sequence controller never issues an output, replacing the actuator is premature. If the output is issued but the mechanism does not move, the investigation shifts toward the output circuit, actuator, supply, and mechanical condition.

11.3 Safe diagnostic discipline

  • Record the alarm text, timestamp, machine mode, program block, and sequence state.
  • Preserve useful diagnostic evidence before resetting the machine.
  • Compare commanded and actual states.
  • Follow the approved electrical drawings and service documentation.
  • Use the machine's documented recovery procedure.
  • Do not bypass guards, defeat interlocks, or force outputs without an authorized, controlled commissioning procedure.
  • Validate the repaired function and related safety conditions before releasing the machine.

Do not invent universal alarm numbers or assume that a diagnostic page has the same name across Makino models and control generations.

12. Backup, Restoration, and Configuration Management

A CNC backup is not automatically a complete machine backup. The CNC may contain part of the configuration, while machine-specific logic, drive data, HMI files, and option-related information may require separate backup procedures.

12.1 Backup checklist

Data category Examples
NC programs Production programs, subprograms, approved revisions
CNC configuration Parameters, machine data, approved control settings
Tool data Tool geometry, wear offsets, tool-management records
Work data Work-coordinate offsets and approved setup information
PMC/PLC Ladder or project files, sequence data, relevant configuration
Servo and spindle Drive configuration and approved commissioning data
HMI and OEM data Machine-specific screens, configuration files, supported option data
Probing and compensation Calibration, measurement configuration, thermal or geometric compensation data
Communication Network settings, device addressing, interface configuration
Documentation Electrical diagrams, machine manuals, parameter lists, software versions

The availability and export method for each item depend on the installed control and machine configuration.

12.2 Before controller or drive replacement

  1. Identify the exact machine model, serial number, control model, and software versions.
  2. Preserve the approved pre-maintenance configuration wherever possible.
  3. Confirm compatibility of replacement hardware, firmware, options, and configuration.
  4. Obtain authorized backup and restoration procedures.
  5. Restore only the data appropriate for the replacement and approved machine configuration.
  6. Perform required commissioning, reference-return, safety, spindle, and axis checks under the prescribed procedure.
  7. Validate tool-change and pallet-change functions where fitted.
  8. Verify machining accuracy and production readiness before release.

Never copy parameters from a superficially similar machine and assume they are interchangeable. Different axis arrangements, spindle configurations, options, and mechanical systems can make that shortcut expensive.

13. Preventive Maintenance Strategy

Preventive maintenance should follow the machine-specific maintenance schedule and operating conditions. Universal intervals cannot safely be assigned to every Makino model.

Subsystem Maintenance focus Useful evidence to record
CNC and electrical cabinet Cooling, filters, fans, connections, cabinet condition Temperature alarms, fan condition, cabinet inspection
Servo and spindle Drive alarms, feedback, abnormal loads, cooling Alarm trends, load trends, temperature, vibration
Axes and mechanics Lubrication, unusual noise, leakage, guideway condition Repeatability results, lubrication alarms, inspection findings
ATC Tool-change operation, magazine condition, sensors, clamping Failed changes, sequence timeouts, recurring alarms
APC Pallet seating, clamping, transfer mechanism, sensors Clamp confirmation, transfer faults, repeatability
Probing Cleanliness, calibration, signal reliability Calibration records, measurement variation
Coolant Level, filtration, pump operation, flow Pump faults, level alarms, coolant condition
Lubrication Level, supply, pressure and distribution Low-level or pressure alarms, inspection findings

Pneumatic/hydraulic Pressure, leakage, valves, cylinders Pressure-related alarms, leakage, response problems
Backup and documentation Backup completeness, revisions, restore readiness Backup date, revision, location, verification status

13.1 Trend data instead of merely collecting it

Repeated faults often provide more useful information than a single alarm.

Track, where available:

  • Frequency and timing of spindle-drive alarms.
  • Servo load and following-error trends.
  • Spindle temperature or vibration indicators.
  • ATC and APC timeout frequency.
  • Probe measurement variation.
  • Coolant, lubrication, and pressure-related alarms.
  • Recurring faults by tool, program, shift, machine state, or operating condition.

A rising trend can justify investigation before the machine reaches a production-stopping failure.

These are starting points, not guaranteed diagnoses. The exact alarm, machine state, and model-specific service documentation determine the next check.

15. Machine Configuration Register

16. Interview Questions and Answers

Q1. What is Makino?

Makino is a machine-tool manufacturer that builds machining and EDM systems for precision manufacturing applications.

Q2. Is Makino a CNC controller brand?

No. Makino is the machine builder. The installed CNC controller depends on the particular machine model and configuration.

Q3. Why is knowing the CNC brand insufficient for machine troubleshooting?

Because machine-specific PMC/PLC logic, interlocks, sensors, mechanical assemblies, auxiliary systems, and OEM options affect how the machine operates.

Q4. What is the difference between CNC and PMC?

The CNC executes machining programs and coordinates motion. The PMC typically handles machine sequencing, auxiliary functions, interlocks, and feedback confirmation.

Q5. How does an M-code operate an auxiliary mechanism?

The CNC requests a machine function. The machine's sequence logic checks permissives, operates the required outputs, verifies feedback, and reports completion according to the configured sequence.

Q6. Why can a tool-change command fail even when the NC program is correct?

The required machine conditions may not be satisfied, or the sequence may fail because of a drive, actuator, sensor, pneumatic, hydraulic, or mechanical issue.

Q7. How would you diagnose an ATC timeout?

Record the alarm and sequence state, identify the expected next transition, verify the relevant command and feedback, then inspect the corresponding electrical, actuator, supply, or mechanical subsystem.

Q8. What is the difference between a pallet-position sensor and a clamp-confirmation sensor?

The position sensor indicates that the pallet has reached a defined location. The clamp-confirmation sensor indicates that the specified clamping condition has been achieved. One does not prove the other.

Q9. Why is spindle orientation important?

It places the spindle at a required angular position for operations such as tool changing and other orientation-dependent functions.

Q10. What causes axis following errors?

Potential causes include excessive load, mechanical obstruction, drive faults, feedback problems, motor or transmission issues, and incorrect configuration.

Q11. Why can a machine produce inaccurate parts without generating an alarm?

Thermal drift, tool wear, incorrect offsets, workholding problems, vibration, and gradual mechanical degradation may affect part dimensions without crossing an alarm threshold.

Q12. What is thermal drift?

Thermal drift is a change in machine geometry or measured position caused by temperature variation in the spindle, axes, structure, or surrounding environment.

Q13. Why must probing systems be calibrated?

Calibration establishes the relationship between probe measurements and the machine's coordinate system. An incorrectly calibrated probe can provide repeatable but inaccurate measurements.

Q14. Why is a CNC backup not necessarily a complete machine backup?

Machine-specific PMC/PLC data, drive configuration, OEM HMI files, compensation data, and option settings may be stored or exported separately.

Q15. What should be recorded before replacing a CNC or drive?

Machine and control identification, software versions, alarm history, approved parameters, configuration data, backup status, and relevant commissioning information.

Q16. How would you distinguish an electrical fault from a mechanical fault?

Compare the command, output, physical response, feedback, and mechanical condition. Use the evidence to locate the first failed transition rather than assuming the alarm identifies the failed component.

Q17. How would you investigate repeated spindle alarms?

Review the exact alarm and history, drive readiness, load, feedback, cooling, supply conditions, and mechanical indicators. Correlate events with operating conditions before selecting corrective action.

Q18. What information should be available before diagnosing a Makino machine?

The exact model and serial number, control type and version, installed options, axis and spindle configuration, active alarm, sequence state, and the relevant OEM manuals and drawings.

Q19. Why should technicians avoid copying parameters from another machine?

Machines may differ in mechanical configuration, feedback devices, drives, spindle arrangements, options, and commissioning values. Incorrect data can compromise motion, accuracy, or safe operation.

Q20. What is the most useful general troubleshooting principle?

Trace the request from the controller through the sequence logic and output to the physical mechanism, then verify that the expected feedback returns. The first missing transition narrows the investigation.

17. Practical Exercises

Exercise 1: Map a Makino machine

Using the actual machine documentation, identify:

  • CNC controller and software version.
  • PMC/PLC or sequence-control arrangement.
  • Axis and spindle drives.
  • Feedback devices.
  • ATC and pallet system, if fitted.
  • Probes, coolant, lubrication, and chip-removal systems.
  • Electrical, hydraulic, and pneumatic documentation.

Draw the machine's architecture using the actual installed components. Mark any functions whose implementation is not yet confirmed.

Exercise 2: Trace a tool-change request

Using approved diagnostic pages and documentation:

  1. Identify the tool-change request.
  2. Record the relevant sequence steps.
  3. Identify the permissives for each step.
  4. Identify the output and feedback associated with each transition.
  5. Document the expected completion condition.
  6. Record the diagnostic procedure for a timeout.

Do not deliberately create a fault on a production machine. Use existing records, a training machine, or an approved test procedure.

Exercise 3: Diagnose a hypothetical pallet-change timeout

Scenario: The pallet-transfer command is issued, but the sequence never reports completion.

Prepare a diagnostic worksheet containing:

  • Active alarm and machine state.
  • Expected pallet position.
  • Actual position feedback.
  • Clamp and unclamp status.
  • Transfer actuator or drive status.
  • Supply-pressure status, where applicable.
  • Relevant sequence permissives.
  • Corrective action and validation evidence.

The objective is to identify the failed transition, not to replace the first component that looks suspicious.

Exercise 4: Build a backup checklist

Create a controlled record covering NC programs, CNC parameters, PMC/PLC data, drive configurations, offsets, tool-management data, probing and compensation data, network configuration, software versions, and documentation.

For each category, record the backup method, revision, storage location, date, responsible person, and verification status.

Exercise 5: Build a recurring-fault tracker

Record each fault with:

  • Date and time.
  • Machine asset and operating mode.
  • Alarm text and code, exactly as displayed.
  • Program block or active machine sequence.
  • Initial diagnostic findings.
  • Root cause supported by evidence.
  • Corrective action.
  • Post-repair validation.
  • Whether the fault recurred.

Separate the observed symptom, confirmed root cause, and corrective action. Those are three different things, despite maintenance records frequently treating them as one.

18. Final Mental Model

Makino supplies the machine platform and its OEM integration. The CNC interprets the machining program and coordinates motion. The PMC/PLC manages machine-specific sequences and interlocks. Drives operate the axes and spindle. Sensors and feedback devices confirm what the machine has actually done. The mechanical system, tooling, workholding, and process determine the final machining result.

When troubleshooting a Makino machine:

  1. Identify the exact machine and installed configuration.
  2. Determine what the CNC or operator requested.
  3. Find the machine-sequence step that should execute.
  4. Verify the output command and physical response.
  5. Check whether the expected feedback arrived.
  6. Diagnose the failed layer using the correct OEM documentation.
  7. Validate the repair and preserve the updated configuration and maintenance record.

The core principle is simple: diagnose the integrated machine, not just the controller.
