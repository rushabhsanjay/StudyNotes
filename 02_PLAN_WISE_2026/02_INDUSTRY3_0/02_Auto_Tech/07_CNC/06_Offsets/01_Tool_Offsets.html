01_Tool_Offsets - Tool offsets: Length and radius

1. Definition of tool offsets

A tool offset is a stored correction or geometric value used by a CNC controller to account for the dimensions and geometry of a cutting tool.

The CNC machine must position the tool's cutting edge correctly relative to the workpiece. However, different tools have different lengths, diameters and cutting-edge geometries. Even tools of the same nominal type can differ slightly because of manufacturing tolerances, regrinding and tool wear.

Tool offsets allow the CNC program to use programmed coordinates while the controller accounts for the actual tool geometry.

The two principal categories are:

  1. Tool length offset: Compensates for the tool's length relative to a defined reference.
  2. Tool radius or cutter radius compensation: Compensates for the cutter's radius so that the cutting edge follows the intended contour.

Related values can include tool wear corrections, nose-radius compensation for turning tools, and tool-specific geometry data.

Why tool offsets are necessary

Consider a machining centre using three tools:

  • Tool 1: 100 mm gauge length.
  • Tool 2: 145 mm gauge length.
  • Tool 3: 180 mm gauge length.

If the CNC ignored tool length differences, using the same programmed Z coordinate could place the different cutting edges at different physical heights.

Similarly, if a 10 mm diameter cutter is used to machine a part contour, the cutter's centre cannot generally follow the contour directly. Its centre must be offset from the desired finished surface by the cutter radius.

Tool offsets address these geometric differences without requiring the programmer to rewrite every coordinate for every tool.

The controller applies the relevant corrections before generating the axis commands. The exact internal calculation and offset activation syntax depend on the CNC control and programming mode.

Tool offsets do not physically change the tool's dimensions. They change how the controller interprets and executes the programmed coordinates.

3. Tool length offset

3.1 What is tool length?

In a CNC machining centre, tool length is commonly measured from a defined spindle or tool-holder reference point to the tool tip.

The exact measurement convention depends on the tool measurement system and controller.

             Spindle
          +-----------+
          |           |
          +-----------+
                |
                |  Tool holder
                |
                |
                |  Tool length
                |
                v
             Tool tip

A tool length offset allows the CNC to account for the distance between the reference point and the tool tip.

Tool length data is typically stored in a tool offset table and associated with a particular tool or offset number.

3.2 Why tool length compensation is required

Suppose two tools are installed in a machining centre.

Parameter Tool T01 Tool T02
Measured gauge length 100 mm 150 mm
Length difference 50 mm

The tool tips are separated by 50 mm when measured from the same reference under the same convention.

Without correct length compensation, a programmed Z movement could result in an incorrect tool-tip position. This can cause:

  • Incorrect hole depth.
  • Incorrect pocket depth.
  • Tool collision with the workpiece or fixture.
  • Tool breakage.
  • Damage to the spindle or machine.
  • Scrap parts.

3.3 How tool length compensation works

A common Fanuc-style programming convention uses:

  • G43: Positive tool length compensation.
  • G44: Negative tool length compensation on controls that support it.
  • G49: Cancel tool length compensation.
  • H: Select a tool length offset register.

A typical example is:

T01 M06
G90 G54
G00 G43 H01 Z100.0

Interpretation:

  • T01 M06: Request a tool change to tool 1, where supported.
  • G90: Select absolute programming.
  • G54: Select a work coordinate system.
  • G00: Rapid positioning.
  • G43: Activate the controller's positive tool length compensation mode.
  • H01: Select tool length offset register 1.
  • Z100.0: Command a Z-axis position under the active coordinate and compensation conventions.

Important: This is an illustrative example, not a universally safe executable program. Exact tool-change syntax, offset conventions, axis behaviour and required safety positions must be verified for the machine and controller.

3.4 The H offset register

The H address commonly selects a tool length offset register.

For example:

G43 H01 Z100.0

The controller reads the value stored in offset register H01 and applies it according to its configured compensation convention.

The H number does not universally have to match the T number. Some shops deliberately use matching numbers, while others use separate tool and offset numbering schemes.

Always verify the tool table and setup sheet.

3.5 Measuring tool length

Common methods include:

  • Presetter measurement outside the machine.
  • Automatic tool measurement probe.
  • Manual tool setter.
  • Touch-off against a known reference surface.
  • Machine-specific calibration procedures.

A measurement system must use the correct reference and convention. A perfectly accurate measurement entered into the wrong offset register can still produce a very expensive mistake.

4. Tool radius and cutter radius compensation

4.1 Why cutter radius compensation is needed

For milling operations, the programmed part contour often represents the finished boundary, not the path of the cutter's centre.

Consider a straight finished wall. If the cutter has a diameter of 10 mm, its radius is 5 mm. The cutter centre must remain approximately 5 mm away from the wall during side milling, subject to the selected side and geometry.

Desired finished wall
|
|
|      Cutter centre path
|             o
|          (     )
|          (tool )
|          (     )
|
<--- 5 mm --->

Without compensation, the cutter centre could follow the programmed contour directly and remove too much material or cut the part to the wrong dimensions.

4.2 Common cutter radius compensation commands

In many Fanuc-style milling systems:

  • G41: Cutter radius compensation left of the programmed path.
  • G42: Cutter radius compensation right of the programmed path.
  • G40: Cancel cutter radius compensation.
  • D: Select a cutter compensation register.

A simplified example:

G17 G90
G01 X0 Y0 F200
G41 D01 X20 Y0

This illustrates the activation of left cutter compensation using register D01. A valid real program needs an appropriate lead-in move, correct geometry, safe clearance and controller-specific syntax.

4.3 What do left and right mean?

Left and right are determined relative to the direction of travel along the programmed contour, not simply from the operator's viewpoint.

Imagine moving along a contour in the direction of the programmed path:

  • G41 places the cutter centre to the left of that path.
  • G42 places the cutter centre to the right of that path.

Which one is correct depends on the direction of travel, the side of the part being machined and the desired finished geometry.

Reversing the direction of travel can change which compensation side is required.

4.4 The D offset register

The D address commonly selects a cutter compensation register containing the radius-related compensation value.

Example:

G41 D01

The controller uses D01 to obtain the applicable compensation data. Depending on the control and tool table, this may be stored as a radius, diameter-related value or another defined compensation quantity.

Never assume that every controller stores the same quantity in its D register. Check the control manual and the machine's offset table conventions.

5. Tool geometry versus wear offsets

Tool offset tables often separate nominal tool geometry from small corrections.

Geometry offset

Represents the measured tool dimensions or the primary compensation value.

Examples:

  • Tool length.
  • Cutter radius.
  • Turning tool nose radius.
  • Tool geometry data.

Wear offset

Represents a small adjustment used to correct dimensional drift during production.

Examples:

  • A hole is consistently 0.02 mm undersize.
  • A milled wall is 0.03 mm away from its target dimension.
  • A turning diameter gradually drifts due to tool wear.

A controlled wear correction may help bring the process back into tolerance without replacing the entire measured geometry value.

Characteristic Geometry offset Wear offset
Primary purpose Represent tool geometry Apply a small dimensional correction
Typical update Tool setup or replacement Process correction during production
Typical magnitude Depends on tool dimensions Usually small relative to geometry
Main risk Wrong base measurement Excessive or incorrect adjustment

The actual structure depends on the controller. Some systems use separate geometry and wear columns; others use different data models.

Wear offsets should be changed only through the approved process, with dimensional verification and traceability where required.

6. Tool length versus cutter radius compensation

Typical commands G43, H, G49 G41, G42, G40, D

The exact commands and conventions vary across CNC families and machine configurations.

7. Tool offsets on milling machines versus turning machines

Milling machines

Typical offset functions include:

  • Tool length compensation.
  • Cutter radius compensation.
  • Tool geometry and wear correction.
  • Tool-specific measurement data.

Tool length compensation is commonly associated with the Z direction on vertical machining centres, while cutter radius compensation commonly acts in the selected machining plane.

Turning machines

Turning centres have different geometry and compensation requirements.

Typical data includes:

  • Tool nose radius.
  • Tool orientation or tool-tip direction.
  • X and Z geometry offsets.
  • Tool wear values.
  • Cutter compensation for complex turning contours.

On many turning controls, nose-radius compensation uses a control-specific form of tool-nose compensation, often programmed with commands such as G41 and G42, but the interpretation depends on the control and tool orientation.

Do not directly transfer a milling offset procedure to a turning centre without checking the relevant machine documentation.

8. Relationship between tool offsets and work offsets

Tool offsets and work offsets solve different coordinate problems.

Tool offset: Where is the cutting edge relative to the tool or machine reference?

Work offset: Where is the part's programmed zero relative to the machine coordinate system?

Consider a milling operation:

  • The work offset defines the part origin.
  • The tool length offset accounts for the tool tip's position relative to the spindle or tool reference.
  • Cutter radius compensation adjusts the cutter centre relative to the intended part contour.

These functions work together to achieve the required tool-tip trajectory.

A useful conceptual relationship is:

Machine reference
       |
       +---- Work offset ----> Programmed part coordinate system
       |
       +---- Tool geometry --> Cutting-edge position
                              relative to tool reference

The controller combines coordinate transformations and compensation according to its configured conventions. This is why an incorrect work offset and an incorrect tool offset can produce superficially similar dimensional errors but require different corrections.

9. Tool offset errors and their symptoms

Symptom Possible cause Initial diagnostic check
Incorrect hole depth Wrong tool length value or wrong H register Verify measured length and active H register
Tool crashes into workpiece Incorrect offset, coordinate system or program setup Stop operation and verify setup before restart
Part profile is oversized Wrong D register or compensation side Check programmed contour, D data and G41/G42
Part profile is undersized Incorrect radius value or compensation direction Compare actual cutter diameter and compensation setup
Tool changes but wrong offset is used Tool and offset register mismatch Verify T/H/D mapping
Gradual dimensional drift Tool wear, cutting conditions or thermal effects Measure the part and review approved wear-correction process
Compensation alarm on activation Invalid lead-in geometry or controller restriction Review lead-in length and controller-specific rules
Incorrect depth after tool replacement New tool length not measured or loaded correctly Verify presetter/probe data and tool table

Do not diagnose solely from the symptom. A work-zero error, fixture problem, incorrect tool selection, mechanical backlash or thermal drift can create similar results.

10. Common causes of tool offset mistakes

Wrong register selected

The program calls H02, but the actual tool is associated with another length register.

Result: The controller applies the wrong correction.

Incorrect measurement reference

A tool is measured from a different datum than the controller's offset convention expects.

Result: The stored value is internally consistent but geometrically wrong.

Radius versus diameter confusion

A diameter-related value is entered where the control expects a radius, or vice versa.

For a 10 mm diameter cutter:

\[ R = \frac{D}{2} = \frac{10}{2} = 5\text{ mm} \]

If a controller expects a radius and the operator enters 10 mm instead of 5 mm, the compensation may be wrong by a factor of two, depending on the control's data convention.

Wrong compensation direction

G41 is used where G42 is required, or the contour direction changes without updating the compensation logic.

Result: The cutter may move to the wrong side of the programmed path.

Incorrect wear correction

An excessive correction is entered to compensate for a problem caused by something else.

Result: One dimension may improve while another becomes incorrect, or the tool may cut outside the intended contour.

11. Practical troubleshooting procedure

When a machined dimension is incorrect, use a controlled sequence.

  1. Stop and assess the condition. If a collision or unsafe movement is possible, follow the machine's approved stop and recovery procedure.
  2. Identify the affected tool. Confirm the physical tool, tool number and offset register used by the program.
  3. Verify the active compensation. Check the controller's modal status and active H/D or equivalent data.
  4. Check the offset table. Compare the entered values against the approved measurement or setup record.
  5. Verify the reference convention. Establish whether the stored value is based on gauge length, radius, diameter or another defined quantity.
  6. Inspect the work offset separately. Confirm the part origin and coordinate system rather than changing tool data to compensate for a work-zero error.
  7. Measure the actual tool and part. Use the approved presetter, tool probe or inspection equipment.
  8. Review the program. Check tool selection, compensation activation/cancellation, approach moves and contour direction.
  9. Make only an authorized correction. Follow the machine's setup and production-control procedure.
  10. Validate the result. Use an approved verification procedure and measure the resulting feature before returning to normal production.

Never change an offset blindly to make a dimension appear correct. Offsets are part of the machine's coordinate model, not a collection of magic numbers.

12. Safety considerations

Tool offsets directly influence physical tool position, so an incorrect value can create a collision.

Important precautions:

  • Verify the tool and offset register before executing a new or modified program.
  • Follow the machine-specific setup and prove-out procedure.
  • Use approved single-block, reduced-rapid or other verification functions where appropriate and available.
  • Maintain working guards, interlocks and safety functions.
  • Keep clear of the tool, spindle, fixtures and moving axes.
  • Never treat a program stop as energy isolation.
  • Before maintenance intervention, isolate hazardous energy and follow the applicable lockout/tagout procedure.
  • Do not bypass safety functions to verify an offset.

A simulation or graphics preview is useful, but it cannot guarantee that the physical tool, holder, fixture and workpiece match the model.

13. Interview questions and answers

Q1. What is a tool offset?

A stored compensation value that allows the CNC to account for tool geometry or a dimensional correction.

Q2. What is the difference between tool length and cutter radius compensation?

Tool length compensation corrects the cutting tool's position relative to the tool reference. Cutter radius compensation adjusts the cutter-centre path relative to the programmed contour.

Q3. What is G43 commonly used for?

Positive tool length compensation on many Fanuc-style milling controls.

Q4. What are H and D addresses commonly used for?

H commonly selects a tool length offset register, while D commonly selects a cutter compensation register. Exact conventions depend on the control.

Q5. What is G49 commonly used for?

Cancellation of tool length compensation on controls that support that convention.

Q6. What is the difference between G41 and G42?

They commonly activate left and right cutter radius compensation relative to the direction of travel.

Q7. What is G40 commonly used for?

Cancellation of cutter radius compensation on controls that support that convention.

Q8. Why is a lead-in move required for cutter compensation?

The controller needs valid geometry to transition from the uncompensated path to the compensated path. An unsuitable approach can produce an alarm or an unexpected trajectory.

Q9. What is the difference between geometry and wear offsets?

Geometry offsets represent the tool's measured dimensions. Wear offsets apply smaller corrections to compensate for dimensional drift, where the control provides that structure.

Q10. Why must tool length be remeasured after tool replacement?

The replacement tool may have a different gauge length, tool-holder arrangement or measured cutting-tip position.

Q11. How can an incorrect D register affect a part?

The controller may apply an incorrect cutter compensation value, resulting in incorrect contour dimensions or a compensation alarm.

Q12. What happens if a radius is entered where a diameter is expected?

The compensation can be incorrect, potentially producing a dimensional error. The outcome depends on the controller's offset convention.

Q13. Can the same H number always be assumed to match the T number?

No. Matching numbers are common in some setups, but the mapping is configurable and must be verified.

Q14. How do tool offsets differ from work offsets?

Tool offsets describe tool-related geometry. Work offsets establish the programmed part coordinate system relative to the machine.

Q15. How should an incorrect hole depth be investigated?

Check the physical tool, active tool length register, measured length, work coordinate system, program coordinates and machine setup before making a correction.

Q16. Why might G41 or G42 generate an alarm?

Possible reasons include unsuitable lead-in geometry, an invalid compensation value, an unsupported command sequence or controller-specific restrictions.

Q17. Why is tool nose radius important in turning?

The cutting tip is rounded rather than perfectly sharp. Nose-radius compensation can account for this geometry when machining contours.

Q18. Why is an offset change a safety-critical action?

An incorrect value can change the commanded tool trajectory and cause collisions, tool breakage or workpiece damage.

15. Final mental model

  • Tool length offset: Accounts for the tool tip's position relative to a defined tool reference.
  • Cutter radius compensation: Accounts for the cutter's radius when following a programmed contour.
  • Geometry offset: Represents the measured tool geometry.
  • Wear offset: Applies a controlled correction to address dimensional drift.
  • H register: Commonly selects tool length compensation data.
  • D register: Commonly selects cutter compensation data.
  • Work offset: Establishes the programmed part origin, which is a separate function from tool compensation.
  • Verification: Confirms that the stored values, selected registers and physical tool match the intended machining process.

The core principle is simple: the CNC needs the correct part coordinate system and correct tool geometry to calculate the intended cutting-edge trajectory. If either is wrong, even a perfectly written program can machine the wrong part.
