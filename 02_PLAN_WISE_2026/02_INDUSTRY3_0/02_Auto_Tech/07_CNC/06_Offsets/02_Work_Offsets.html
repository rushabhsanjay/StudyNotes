02_Work_Offsets - Work offsets: G54-G59 part zero

1. Definition of work offsets

A work offset is a coordinate-system setting that defines the location of the workpiece's programmed origin relative to the CNC machine coordinate system.

A CNC machine has a machine coordinate system established through its reference and machine configuration. However, the workpiece may be mounted at different positions on the table, fixture, chuck or pallet.

Rather than rewriting every programmed coordinate whenever the workpiece moves, the operator or setup system defines a work offset.

Common work coordinate system commands on many Fanuc-style milling controls include:

  • G54
  • G55
  • G56
  • G57
  • G58
  • G59

These select different stored work coordinate systems. The actual number of available systems and their configuration depend on the CNC controller.

Why work offsets are necessary

Imagine machining the same component on three different fixtures. The part geometry and CNC program may be identical, but each fixture positions the workpiece at a different machine location.

Work offsets allow the same programmed coordinates to be interpreted relative to the appropriate part origin.

Common applications include:

  • Establishing the part zero for milling.
  • Defining the origin of a turning operation.
  • Machining multiple workpieces in one setup.
  • Supporting palletized production.
  • Using multiple fixtures on a machine table.
  • Reusing a program after a workpiece is repositioned, provided the setup and geometry remain valid.

Core principle: The work offset tells the CNC where the programmed part coordinate system is located relative to the machine coordinate system.

2. Machine coordinates versus work coordinates

CNC machines commonly use several coordinate concepts.

Machine coordinate system

The machine coordinate system is the controller's reference coordinate system for machine positions.

Its relationship to the physical machine is established through machine configuration, reference procedures and axis calibration.

Work coordinate system

The work coordinate system establishes the origin used by the part program.

For example, a milling program might use the top-left corner of a workpiece as its XY origin and the top surface as its Z zero.

Program coordinates

These are the coordinates written in the CNC program.

For example:

G90
G54
G00 X50.0 Y30.0

The X50.0 Y30.0 coordinates are interpreted using the active coordinate system and other applicable controller settings.

Coordinate relationship

Conceptually, for a simple translational setup:

\[ P\_{\text{machine}} = P\_{\text{work}} + O\_{\text{work}} \]

Where:

  • \(P\_{\text{machine}}\) is the commanded position expressed in machine coordinates.
  • \(P\_{\text{work}}\) is the programmed position in work coordinates.
  • \(O\_{\text{work}}\) is the work origin expressed in machine coordinates.

This equation is a simplified model. Actual CNC calculations may include axis transformations, tool compensation, rotary-axis kinematics and other machine-specific effects.

Example

Suppose a workpiece origin is located at machine coordinates:

  • X = 500 mm
  • Y = 200 mm
  • Z = 300 mm

The program commands:

  • X = 50 mm
  • Y = 30 mm
  • Z = 10 mm

Ignoring tool compensation and other transformations, the corresponding machine-coordinate position is:

  • X = 550 mm
  • Y = 230 mm
  • Z = 310 mm

The CNC converts the programmed position using the active coordinate system rather than requiring the programmer to write machine coordinates for every feature.

Work offsets and tool offsets solve different problems.

  • The work offset defines the part's coordinate origin.
  • The tool length offset accounts for tool length-related geometry.
  • Cutter radius compensation accounts for cutter geometry relative to a programmed contour.

Changing the wrong one can conceal the real problem and create additional dimensional errors.

4. G54 to G59 explained

On many CNC controllers, G54 through G59 select six commonly available work coordinate systems.

Command Common purpose
G54 Select work coordinate system 1
G55 Select work coordinate system 2
G56 Select work coordinate system 3
G57 Select work coordinate system 4
G58 Select work coordinate system 5
G59 Select work coordinate system 6

These are stored coordinate systems, not fixed physical locations. The values can be configured for different fixtures, parts or pallet positions.

The following is an illustrative arrangement:

Work offset Example use
G54 Fixture station 1
G55 Fixture station 2
G56 Fixture station 3
G57 Fixture station 4
G58 Fixture station 5

This mapping is only an example. A shop may use these offsets for separate parts, multiple vises, pallet positions or different setups.

Some controllers also provide additional work coordinate systems beyond G59. Their selection and configuration are controller-specific.

5. Work offset data table

A work offset typically stores coordinate values for the relevant axes.

For a three-axis machining centre, an illustrative table might look like this:

Offset X Y Z Example purpose
G54 500.000 200.000 300.000 Fixture A
G55 750.000 200.000 300.000 Fixture B
G56 500.000 450.000 300.000 Fixture C
G57 750.000 450.000 300.000 Fixture D
G58 1000.000 200.000 300.000 Fixture E
G59 1000.000 450.000 300.000 Fixture F

The numbers are illustrative and do not describe a real machine.

In this example, G54 and G55 have different X values because the corresponding work origins are located at different positions along the machine's X direction.

A production setup may also require rotary-axis values or other coordinate data, depending on the machine configuration.

Important distinction

The offset table is not necessarily a direct measurement of the physical fixture's dimensions. It stores coordinate values according to the CNC's configured conventions and measurement procedure.

Do not copy values from another machine or controller without validating the coordinate convention.

6. Selecting a work offset in a program

A simplified Fanuc-style milling example:

%
O1001
G90 G17 G21
G54
T01 M06
G00 X0 Y0
G43 H01 Z100.0
M30
%

Conceptual interpretation:

  • O1001: Program number.
  • G90: Absolute programming mode.
  • G17: Select the XY plane on controls using this convention.
  • G21: Select metric units on controls using this convention.
  • G54: Select the first work coordinate system.
  • T01 M06: Request a tool change to tool 1, where supported.
  • G00 X0 Y0: Rapidly command the programmed XY origin under the active coordinate system.
  • G43 H01 Z100.0: Apply the selected tool length compensation and command the specified Z position according to the controller's conventions.
  • M30: End the program with the controller's configured end/reset behaviour.

This is an illustrative syntax example, not a complete production-ready program. A real program must account for the machine's startup requirements, safe approach positions, tool-change requirements, fixture geometry, offset configuration and controller-specific behaviour.

The order of commands can matter. Tool changes and positioning moves must follow the machine builder's documented requirements.

7. How a work offset is established

The process used to set a work offset depends on the machine and measurement method.

Common approaches include:

  • Manual edge finding.
  • Mechanical or electronic touch probe.
  • Tool or workpiece setter.
  • Touching off against a known datum.
  • Fixture-based preset coordinates.
  • Automated probing cycles.
  • Pallet or fixture identification systems with validated coordinate data.

Example: Setting a Z work zero

Suppose the top surface of a workpiece is defined as Z = 0 for the part program.

The setup procedure measures the workpiece surface using the approved method and enters or calculates the corresponding work offset.

The CNC then interprets programmed Z coordinates relative to that work origin, subject to the active tool compensation and controller conventions.

Why the measurement method matters

A wrong measurement reference can shift every feature produced under the affected work offset.

If the workpiece origin is 2 mm too high or too low, programmed positions can be displaced accordingly, depending on the axis and coordinate convention.

This can result in:

  • Incorrect pocket depths.
  • Incorrect hole locations.
  • Incorrect facing depth.
  • Tool collision.
  • Dimensional rejection.

The correct procedure is to establish the datum accurately, verify the stored value and confirm the active offset before machining.

8. Multiple work offsets in production

Multiple work offsets are especially useful when machining more than one workpiece or fixture without rewriting the part program.

Example: Two fixtures on one machine

Machine table
+------------------------------------+
|                                    |
|  Fixture A          Fixture B      |
|  [Workpiece A]      [Workpiece B]  |
|                                    |
+------------------------------------+

G54 -> Work origin A
G55 -> Work origin B

A program may select G54 to machine a workpiece in Fixture A and use G55 for Fixture B.

However, multiple offsets alone do not make a program safe for every fixture. The program must account for tool reach, fixture clearance, workholding, machine travel and the intended machining sequence.

Example: Repeated production

If multiple identical parts are mounted at known locations, separate work offsets can make the programming and setup easier to manage.

This can reduce repetitive coordinate editing and improve consistency, provided the offset data is validated and maintained.

9. Work offsets and pallet changers

Palletized machining centres may use work offsets to represent different pallet or fixture positions.

A simplified arrangement:

Pallet A -> Work coordinate system A
Pallet B -> Work coordinate system B
Pallet C -> Work coordinate system C

When the pallet changes, the CNC must use the coordinate data corresponding to the correct setup.

The implementation may involve:

  • Separate work offsets.
  • Pallet management data.
  • CNC/PLC handshake logic.
  • Pallet identification.
  • Automatic coordinate selection.
  • Machine-specific macros or probing cycles.

Not every pallet changer uses a simple one-to-one G54/G55 mapping. Some machines calculate or select coordinate data through more advanced functions.

A pallet-change command is not proof that the correct work offset was selected. The machine's configured sequence and verification methods must establish that relationship.

10. Work offsets on turning machines

Work offsets are also used on CNC turning centres, but the coordinate system and setup conventions differ from those of milling machines.

A typical turning centre uses:

  • X for radial or diameter-related positioning, depending on the programming mode.
  • Z along the spindle axis.
  • A defined workpiece face or other datum as the program origin.

For example, Z zero may be established at the front face of the workpiece.

The controller may use different X conventions, including diameter programming or radius programming. The setup must match the active programming mode.

Work offsets on turning centres may also interact with:

  • Tool geometry and wear data.
  • Turret station and tool orientation.
  • Subspindle coordinate systems.
  • Bar feeders and workholding.
  • C-axis or live-tool operations.

Do not assume that an X coordinate has the same physical interpretation across every turning control.

11. Work offset versus tool offset

This is one of the most important distinctions in CNC setup and troubleshooting.

Feature Work offset Tool offset
Defines Part coordinate origin Tool-related geometry
Typical examples G54, G55 H and D registers on many milling controls
Changes when Part or fixture reference changes Tool measurement or correction changes
Typical problem Feature shifted relative to the workpiece Incorrect tool-tip position or contour compensation
Main verification Datum, fixture location and active coordinate system Tool identity, measurement and active compensation

Example A: Every hole is shifted in X

Possible causes include:

  • Incorrect X work offset.
  • Incorrect fixture location.
  • Incorrect program coordinates.
  • Incorrect probing or datum measurement.

Changing tool length is not the direct first response to an XY positioning error.

Example B: XY locations are correct, but every hole is too deep

Investigate:

  • Tool length compensation.
  • Z work offset.
  • Programmed Z depth.
  • Tool measurement and setup.
  • Relevant machine or process conditions.

The symptom narrows the search, but it does not prove one cause. Confirm the actual coordinate and compensation state before making corrections.

13. Diagnostic procedure for incorrect part location

Use this sequence when a component is machined in the wrong position.

Step 1: Record the actual error

Measure the part or affected feature and determine whether the error is in X, Y, Z or a combination of axes.

Step 2: Confirm the active work coordinate system

Verify whether the program selected the intended G54, G55 or other configured work coordinate system.

Step 3: Inspect the offset table

Compare the active coordinate values against the approved setup record or measurement results.

Step 4: Verify the physical datum

Check the workpiece location, fixture seating, clamping and datum surfaces.

Step 5: Check the program and modal state

Review the programmed coordinates, units, absolute/incremental mode and other relevant coordinate settings.

Step 6: Separate work offset from tool compensation

For an XY location error, examine the work coordinate system and programmed XY geometry first.

For a depth error, examine the Z work offset, tool length compensation and programmed depth together.

Step 7: Verify any automated coordinate selection

If a probing cycle, pallet changer or macro selects offsets, verify its inputs, logic and result.

Step 8: Validate the correction

Follow the approved prove-out procedure and inspect the resulting feature before returning the machine to production.

Never correct a coordinate error by blindly modifying another offset until the part happens to measure correctly. That merely hides the fault and creates a future surprise for the next shift.

14. Safety and setup controls

Incorrect work offsets can cause a tool to move into a fixture, workpiece, chuck or machine structure.

Maintain the following controls:

  • Verify the active work coordinate system before running a new setup.
  • Confirm that the stored values correspond to the actual fixture and datum.
  • Follow the approved first-piece or program prove-out procedure.
  • Use the machine's approved reduced-speed, single-block or other verification functions where appropriate.
  • Check clearances and machine travel limits.
  • Maintain safety guards and interlocks.
  • Never bypass a safety function to complete a setup.
  • Isolate hazardous energy before physical intervention, following the applicable lockout/tagout procedure.
  • Record approved offset changes when required by the production quality system.

A correct offset table is a critical part of machine setup control, not just an administrative convenience.

15. Interview questions and answers

Q1. What is a work offset?

A stored coordinate transformation or origin definition used to relate the programmed work coordinate system to the machine coordinate system.

Q2. What are G54 to G59?

Common CNC commands for selecting six work coordinate systems on many controllers.

Q3. What is the difference between machine coordinates and work coordinates?

Machine coordinates refer to the machine's coordinate system. Work coordinates refer to the selected part coordinate system.

Q4. Why are work offsets used?

They allow the same program coordinates to be used with different part origins or fixture positions.

Q5. Can G54 and G55 contain different coordinates?

Yes. They commonly represent different work origins or setups.

Q6. Does G54 always represent the first fixture?

No. Its actual stored values and operational purpose depend on the setup and machine configuration.

Q7. What is the difference between a work offset and a tool offset?

A work offset defines the part origin. A tool offset accounts for tool-related geometry or corrections.

Q8. What happens if the wrong work offset is selected?

The CNC interprets the programmed positions using the wrong coordinate origin, potentially machining the workpiece in the wrong location.

Q9. Why might a program work on one pallet but fail on another?

The second pallet may use different coordinate data, fixture geometry, clamping conditions or offset-selection logic.

Q10. How is a work offset established?

Using an approved measurement procedure such as edge finding, touch probing, datum touch-off or validated preset coordinates.

Q11. Why can a Z-depth error involve both tool length and work offset?

Both affect the relationship between the programmed Z position and the physical tool tip. Their individual contributions must be checked.

Q12. Are G54 to G59 the only available work coordinate systems?

No. Many controllers support additional coordinate systems or other coordinate-setting mechanisms.

Q13. What is a datum?

A defined reference feature, surface or point used to establish a coordinate origin or measurement relationship.

Q14. Why must the workpiece be securely clamped before establishing or validating an offset?

Movement after measurement invalidates the established relationship and can cause dimensional errors or collisions.

Q15. What is the purpose of pallet-specific work offsets?

They allow the control system to use the appropriate part coordinate data for the corresponding pallet or fixture setup.

Q16. How should an XY positioning error be investigated?

Check the active work coordinate system, datum measurement, fixture position and programmed coordinates before considering unrelated tool compensation values.

Q17. Can a probing cycle update work offsets automatically?

Yes, if the controller, probing system and program are configured for that function. The result still requires appropriate validation and safeguards.

Q18. Why is it dangerous to copy an offset table from another machine?

Machine references, coordinate conventions, fixture locations and controller configurations may differ.

  • Y = 250 mm
  • Z = 200 mm

The program commands:

  • X = 40 mm
  • Y = 25 mm
  • Z = 10 mm

Using the simplified translational relationship, calculate the corresponding machine-coordinate position while ignoring tool compensation and other transformations.

Expected result:

  • X = 440 mm
  • Y = 275 mm
  • Z = 210 mm

Exercise 2: Two-fixture setup

Fixture A uses G54 and Fixture B uses G55.

Prepare a setup verification checklist covering:

  • Fixture identification.
  • Work origin.
  • Stored coordinate values.
  • Program offset selection.
  • Tool clearance.
  • First-piece inspection.

Exercise 3: Part shifted by 3 mm

A part is machined 3 mm away from its intended position in the X direction.

Develop a diagnostic sequence that distinguishes between a work offset error, fixture movement, incorrect probing data and an incorrect program coordinate.

Exercise 4: Incorrect pocket depth

The XY position of a pocket is correct, but its depth is incorrect.

Identify how to check the Z work offset, tool length offset, programmed depth and workpiece datum without changing unrelated values.

Exercise 5: Pallet change fault

After a pallet change, the program uses the wrong part origin.

Document the relationship between pallet identification, CNC offset selection, PLC sequence completion and the coordinate data applied to the next operation.

Remember these distinctions:

  • G54-G59: Select work coordinate systems on controllers using this convention.
  • Work offset: Establishes the part origin relative to the machine coordinate system.
  • Tool offset: Accounts for tool geometry or dimensional correction.
  • Datum: The physical or defined reference used to establish coordinates.
  • Pallet or fixture mapping: Connects the physical setup to the correct coordinate data.
  • Verification: Confirms that the selected origin, physical setup and program agree.

The central principle is that the CNC must know both where the part is and how the cutting tool relates to its reference. Work offsets establish the first relationship; tool offsets establish the second.
