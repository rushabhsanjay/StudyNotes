1. Definition

VFD control wiring is the wiring used to send commands, speed references, enable signals, feedback signals, and status signals between a variable frequency drive and external control devices.

Unlike power wiring, which carries electrical power to the drive and motor, control wiring carries signals used to operate and monitor the drive.

Typical control devices include:

  • PLCs.
  • HMIs.
  • Push buttons and selector switches.
  • Relays and contactors.
  • Potentiometers.
  • Sensors and transmitters.
  • SCADA systems connected through a PLC or supported communication interface.

For example, in an automotive production line, a PLC may send a run command and speed reference to a conveyor VFD. The VFD then controls the motor and returns signals indicating that it is ready, running, or faulted.

2. Overall Control Wiring Architecture

A typical VFD installation may have both hardwired control and network communication.

          OPERATOR / HMI / SCADA
                    |
                    v
              +-----------+
              |    PLC    |
              +-----------+
                |       ^
        Commands|       |Status / Feedback
                v       |
          +------------------+
          |       VFD        |
          |                  |
          | Digital Inputs   |
          | Analog Inputs    |
          | Digital Outputs  |
          | Analog Outputs   |
          | Communication    |
          +---------+--------+
                    |
                    v
                  MOTOR

This is a conceptual architecture. Some systems wire operator controls directly to the VFD, while others route commands through a PLC. Communication-based control may replace some hardwired signals.

The control architecture must define which device owns each command and how faults, interlocks, and communication failures are handled.

3. Main Types of VFD Control Signals

Signal type Typical purpose Example
Digital input (DI) Receives an ON/OFF command Run enable
Digital output (DO) Sends an ON/OFF command to another device Relay-driven external enable
Analog input (AI) Receives a continuously varying signal Speed reference
Analog output (AO) Sends a continuously varying signal Actual speed feedback
Relay output Provides a switched contact status Drive fault indication
Communication data Transfers commands and values digitally PLC sends speed setpoint over EtherNet/IP
Feedback input Receives measured information Encoder feedback, where supported

The terms DI, DO, AI, and AO are relative to the device being discussed. A PLC output connected to a VFD input is a PLC DO and a VFD DI.

4. Start and Stop Control Using Digital Inputs

4.1 Purpose

A digital input detects a discrete electrical state, commonly interpreted as ON/OFF or TRUE/FALSE.

A VFD can be configured to interpret a digital input as a function such as:

  • Run forward.
  • Run reverse.
  • Enable.
  • External fault.
  • Reset fault.
  • Select preset speed.
  • Select a control mode.

The supported functions and input assignments vary by drive model.

4.2 Typical PLC-to-VFD wiring

A simplified example using a 24 V DC PLC output and a compatible VFD digital input is:

PLC                                      VFD

+24 V / Output Supply
       |
       v
PLC Digital Output --------------------> DI1
PLC Output Common ----------------------> Digital Common

This is a functional sketch, not a universal terminal diagram. Actual wiring depends on whether the VFD input is configured for sourcing or sinking operation, its internal input supply, the PLC output type, and the manufacturer's terminal arrangement.

Never assume that every VFD digital input accepts 24 V DC. Verify the input voltage range, polarity, common-terminal arrangement, and input-current requirements in the manual.

4.3 Two-wire control

Two-wire control commonly uses a maintained contact or signal level to request operation.

Conceptually:

Maintained RUN Signal = ON   -> Run requested
Maintained RUN Signal = OFF  -> Stop requested

A maintained selector switch is one possible source. A PLC output can also provide the signal.

The drive's configured command mode determines the exact behavior.

4.4 Three-wire control

Three-wire control commonly uses separate momentary START and STOP inputs. The drive's logic maintains the run state after a valid start command and clears it when the stop command is received.

Conceptually:

Momentary START -> Latch run request
STOP command    -> Clear run request

The exact terminal wiring and stop-input polarity vary by drive.

Comparison

Feature Two-wire control Three-wire control
Typical command device Maintained contact Momentary START and STOP buttons
Run request Determined by maintained signal state Established by START command and maintained by drive logic
Stop behavior Depends on maintained signal and configuration Stop input clears the run state
Typical application PLC-controlled run enable or selector switch Local push-button station
Important consideration State after power recovery or signal restoration Correct stop logic and restart behavior

A two-wire signal can cause a restart when the signal returns, depending on the drive's configuration and the machine's control design. Restart behavior must be evaluated during commissioning.

5. Start/Stop Control Using Relays

A relay provides electrically controlled contacts that can switch a circuit independently of the control signal that energizes its coil.

Relays may be used for:

  • Interposing between a PLC output and a VFD input.
  • Providing contact isolation between circuits.
  • Selecting a control source.
  • Switching a compatible control signal.
  • Transmitting a drive status contact to a PLC input.

Conceptual relay interface

PLC Output
    |
    v
Relay Coil
    |
    v
Relay Contact
    |
    v
VFD Digital Input

The actual coil supply, contact wiring, protection, and common terminals must be selected according to the relay and VFD specifications.

Why use an interposing relay?

A relay may be useful when:

  • The PLC output and VFD input are electrically incompatible.
  • A dry contact is required.
  • Additional contact isolation is needed.
  • A signal must be switched between supported circuits.

However, a relay is not automatically necessary. Direct PLC-to-VFD wiring is often simpler when the interfaces are compatible.

Relay contact terminology

Term Meaning
Coil Energized to operate the relay
COM Common contact terminal
NO Normally open contact
NC Normally closed contact
Contact rating Permitted switching conditions for the contact
Coil voltage Voltage required to energize the relay coil

Important: NO and NC describe the contact state when the relay coil is de-energized, not the logical state of the PLC or VFD.

A standard relay is not a substitute for a safety-rated relay or safety system where a safety function is required.

6. Speed Reference Using an Analog Input

A VFD often uses an analog input to receive a speed reference from a PLC, potentiometer, or process controller.

Common signal types include:

  • 0 to 10 V DC.
  • 4 to 20 mA.
  • Other ranges supported by the drive.

The chosen signal type must match the VFD input configuration and the signal source.

6.1 Voltage reference: 0 to 10 V

A simplified interface is:

PLC Analog Output                 VFD

Voltage Output -----------------> AI1
Analog Common ------------------> Analog Common

For a configured linear mapping of 0 to 10 V to 0 to 50 Hz:

Reference voltage Requested frequency
0 V 0 Hz
2 V 10 Hz
5 V 25 Hz
8 V 40 Hz
10 V 50 Hz

This mapping assumes the drive is configured for the stated range, the scaling is linear, and no other limit or override changes the requested frequency.

6.2 Current reference: 4 to 20 mA

A current signal is commonly used in industrial environments because it can be less sensitive to voltage drop than a voltage signal in suitable installations.

For a configured linear mapping of 4 to 20 mA to 0 to 50 Hz:

Reference current Requested frequency
4 mA 0 Hz
8 mA 12.5 Hz
12 mA 25 Hz
16 mA 37.5 Hz
20 mA 50 Hz

The linear conversion is:

\[ f = \frac{I-4}{20-4}\times 50 \]

where \(I\) is the input current in mA and \(f\) is the requested frequency in Hz.

For example, at 12 mA:

\[ f = \frac{12-4}{16}\times 50=25\text{ Hz} \]

This is the scaled reference, not necessarily the motor's measured operating frequency or speed. The drive may impose limits, ramps, or other control conditions.

Why use 4 to 20 mA instead of 0 to 20 mA?

The 4 mA lower endpoint is called a live zero. A current substantially below the configured valid range can help identify a broken wire or signal-source fault, if the drive supports that diagnostic.

A 4 to 20 mA signal does not guarantee wire-break detection by itself. The input configuration, thresholds, and fault response must be configured and tested.

7. Potentiometer-Based Speed Reference

A potentiometer can provide a manually adjustable reference where the drive supports it.

Conceptually:

VFD Reference Supply ---- Potentiometer End A
VFD Analog Common ------ Potentiometer End B
VFD Analog Input ------- Potentiometer Wiper

The exact terminals and permitted resistance range depend on the drive model.

Turning the potentiometer changes the voltage at the analog input, which the drive converts into a reference value.

Potential problems include:

  • Incorrect potentiometer resistance.
  • Incorrect terminal wiring.
  • No reference supply.
  • Faulty wiper contact.
  • Incorrect analog input mode.
  • Incorrect frequency scaling.

Use only the drive's supported reference supply and wiring arrangement. Do not apply an external voltage to a terminal intended for a different signal type.

8. Analog Output: Sending Feedback to the PLC

A VFD analog output can provide a scaled representation of a selected value, such as:

  • Output frequency.
  • Estimated motor speed.
  • Output current.
  • Torque estimate.
  • Other supported monitored parameters.

Example:

VFD Analog Output ----------------> PLC Analog Input
VFD Analog Common ----------------> PLC Analog Common

The signal may be a voltage or current output. The output type, scaling, and electrical compatibility must be verified.

For example, if a VFD is configured to output 0 to 10 V corresponding to 0 to 50 Hz, a reading of 6 V would represent 30 Hz under the configured linear mapping.

It would not necessarily prove that the motor shaft is rotating at the corresponding speed. The drive may be reporting its output-frequency command or an estimate rather than a direct shaft measurement.

9. VFD Relay Outputs: Ready, Running, and Fault

Many VFDs provide relay outputs with configurable functions.

Typical functions include:

  • Drive ready.
  • Drive running.
  • Fault active.
  • Frequency reached.
  • At-speed indication.
  • Other supported status conditions.

Conceptual wiring to a PLC input

PLC Input Supply
       |
       v
VFD Relay COM
       |
  VFD Relay NO
       |
       v
PLC Digital Input

This sketch illustrates a possible dry-contact interface only. The real circuit must use the correct supply, input common, relay terminal, and electrical ratings.

Typical status meanings

Status Meaning
Ready Drive is in a condition that permits operation according to its configured logic
Running Drive logic indicates operation according to the selected status definition
Fault A drive fault is active, according to the configured relay function
Frequency reached A configured frequency condition has been met
At speed A defined speed condition has been satisfied

The exact semantics are model- and configuration-dependent.

A running relay output does not necessarily prove that the motor is mechanically rotating. For applications requiring actual speed feedback, use a suitable measured or estimated speed signal and the appropriate control logic.

10. Local/Remote Control Selection

Many VFDs can accept commands from more than one source, such as:

  • Local keypad.
  • Hardwired terminals.
  • PLC communication network.

The drive's configuration determines which source is active and whether command or reference switching is permitted while operating.

A common industrial arrangement is:

LOCAL MODE
Keypad / Local Controls
          |
          v
         VFD

REMOTE MODE
PLC / Network Commands
          |
          v
         VFD

The keypad may be useful during commissioning or maintenance, while remote control is used for normal automatic operation.

Important considerations

  • Confirm which source controls start/stop.
  • Confirm which source controls the speed reference.
  • Verify that local and remote selections behave as intended.
  • Check what happens when communication is lost.
  • Confirm whether the drive can restart when control returns.
  • Ensure local operation cannot bypass required machine interlocks or safety functions.

A remote/local selector is a control function, not automatically a safety isolation device.

11. Hardwired Control Versus Network Control

A VFD may be controlled through hardwired I/O, an industrial network, or a combination of both.

Feature Hardwired control Network control
Run/stop Digital input Network command
Speed reference Analog input or preset speeds Numeric reference value
Status Digital or analog outputs Network status words and parameters
Diagnostics Limited by available signals Often richer diagnostic data
Wiring Individual conductors for signals Network cabling and supported interfaces
Failure modes Wiring faults, signal loss, incorrect levels Network loss, configuration errors, timeout behavior
Commissioning Verify electrical signals and scaling Verify network, device configuration, data mapping, and control ownership

Neither method is universally better. The choice depends on the drive, PLC architecture, diagnostics requirements, installation, and plant standards.

A network-controlled drive may still use hardwired inputs for specific enable or safety-related functions where required by the design.

12. Analog Scaling and Parameter Configuration

Correct wiring alone does not guarantee correct operation. The drive must be configured to interpret the signal properly.

Important settings may include:

  • Command source.
  • Speed-reference source.
  • Digital input assignments.
  • Analog input type.
  • Analog input minimum and maximum.
  • Frequency minimum and maximum.
  • Acceleration and deceleration ramps.
  • Relay output functions.
  • Communication timeout response.
  • Restart behavior.
  • Fault-reset behavior.

Example

A PLC analog output is configured for 0 to 10 V. The VFD analog input is configured for 4 to 20 mA.

The electrical signal types do not match, so the reference may be incorrect or invalid.

Likewise, if both sides use 0 to 10 V but one side maps 0 to 10 V to 0 to 50 Hz and the other side expects a different scaling, the motor speed reference will be wrong.

Always verify both the electrical signal type and the numerical scaling.

13. Control Wiring Faults and Troubleshooting

Symptom Possible cause Initial checks
Run command has no effect Wrong command source, input assignment, enable missing, active fault Check command source, input status, drive-ready status, and fault history
Drive runs continuously Maintained signal remains active, incorrect two-wire logic, PLC output stuck ON Verify input state and the configured stop behavior
Motor runs at the wrong speed Incorrect reference source, scaling, limits, or analog mode Compare reference value, measured signal, and drive parameters
Analog reference remains at zero Missing signal, broken wire, incorrect common, wrong input configuration Measure only under the approved procedure and verify input configuration
Speed fluctuates Noisy analog signal, poor connections, unstable reference, unsuitable control settings Inspect signal wiring, shielding, signal quality, and scaling
Fault relay does not operate Wrong relay assignment, incorrect contact selection, wiring fault Verify relay configuration and contact state
PLC does not detect drive running Incorrect relay wiring, wrong output function, PLC input mapping issue Check drive status, relay state, PLC input state, and I/O mapping
Drive trips on communication loss Network interruption or timeout configuration Inspect communication diagnostics and the configured loss response
Drive restarts unexpectedly Command remains active after power or signal restoration Review restart settings, command logic, and machine restart policy
Fault reset does not work Wrong input assignment, incorrect pulse, fault still present Check reset configuration and remove the underlying fault condition

For each problem, distinguish the command request from the drive's accepted command, its operating state, and the motor's actual behavior.

14. Control Wiring and Safety

Ordinary control wiring is not automatically safety-rated.

A standard PLC output, general-purpose relay, or ordinary VFD digital input should not be treated as a safety function unless the complete system is specifically designed and validated for that purpose.

For example:

  • A standard stop input may request a controlled stop.
  • A safety-rated circuit may be required to remove or control hazardous torque.
  • A supported Safe Torque Off (STO) function may be used within a properly designed safety system.
  • Emergency-stop and guard-interlock requirements must be based on the machine risk assessment and applicable standards.

The exact safety architecture depends on the machine and the required safety performance.

A standard PLC run command must not be able to defeat a required safety function.

15. Practical Automotive Manufacturing Example

Consider a conveyor VFD controlled by a PLC on an automotive production line.

The PLC provides:

  • Run command through a digital output.
  • Speed reference through a 4 to 20 mA analog output.
  • Feedback from the drive's running relay.
  • Fault feedback from a separate configured relay output.

Assume the VFD is configured so that 4 to 20 mA corresponds to 0 to 50 Hz.

At a 12 mA reference, the requested frequency is 25 Hz.

The PLC then evaluates the drive's status:

  1. The PLC requests operation, subject to the machine's control logic.
  2. The VFD checks its configured enable conditions and fault status.
  3. The VFD accelerates according to its configured ramp.
  4. The running output indicates the configured running condition.
  5. The PLC monitors the feedback and detects an abnormal response if the expected status does not occur within the defined time.

The PLC should not assume that a run command proves successful operation. It should monitor the relevant status, detect failures, and apply the machine's approved response.

16. Interview Questions and Answers

Q1. What is VFD control wiring?

It is the wiring used for commands, references, feedback, and status signals between a VFD and external control equipment.

Q2. What is the difference between power wiring and control wiring?

Power wiring carries the supply and motor power. Control wiring carries signals used to operate and monitor the drive.

Q3. What is two-wire control?

A common arrangement where a maintained signal determines the run request.

Q4. What is three-wire control?

A common arrangement using separate momentary start and stop commands, with the drive logic maintaining the run state.

Q5. What is an analog speed reference?

A continuously varying signal, such as 0 to 10 V or 4 to 20 mA, mapped to a requested operating value.

Q6. Why is 4 to 20 mA widely used?

It supports current-loop signalling and a live-zero range that can help detect certain signal faults when the system is configured for them.

Q7. What is an interposing relay?

A relay used to interface between circuits, provide suitable contact switching, or provide isolation where appropriate.

Q8. What is the difference between a PLC DO and a VFD DI?

The PLC DO produces the signal, while the VFD DI receives and interprets it.

Q9. What is a VFD relay output used for?

It can provide configured status signals such as ready, running, or fault to an external control circuit.

Q10. Why might a correctly wired analog signal still produce the wrong speed?

The analog input type, scaling, reference source, frequency limits, or other drive settings may be incorrect.

Q11. What is local/remote control selection?

It determines which configured source, such as a keypad, hardwired terminal, or PLC network, controls the drive.

Q12. Does a VFD running signal prove the motor shaft is rotating?

Not necessarily. The meaning depends on the drive's status definition. Direct or appropriate speed feedback may be required to verify actual motion.

Q13. Why is restart behavior important?

A drive may receive an active run command when power or communication returns. The system must prevent unintended restart where required by the machine's design.

Q14. Is an ordinary VFD stop input a safety-rated stop function?

Not automatically. Safety functions must use a suitable, designed, and validated safety architecture.

Remember these principles:

  • Start/stop wiring tells the drive what operation is requested.
  • Reference wiring tells the drive what operating value is requested.
  • Status and feedback wiring report what the drive indicates is happening.
  • Correct wiring and correct parameter configuration are both necessary.
  • Control signals must never bypass required machine safety functions.
