Photoelectric Sensors: Through-Beam, Retroreflective, Diffuse, Wiring, and Troubleshooting

1. Introduction

A photoelectric sensor detects an object by using light. It typically contains a light emitter, a light receiver, and electronic circuitry that evaluates the received light and switches an output.

Photoelectric sensors are widely used in industrial automation because they can detect objects without physical contact and often operate over longer distances than conventional proximity sensors.

Typical applications include:

  • Detecting products on conveyors.
  • Counting components moving along a production line.
  • Detecting cartons, bottles, trays, and packaging.
  • Checking whether a component is present before robot handling.
  • Monitoring material movement between machine stations.
  • Detecting transparent or reflective objects using suitable sensor types.
  • Monitoring object position and spacing.
  • Detecting a broken beam or interrupted light path.

The three major arrangements are through-beam, retroreflective, and diffuse-reflective. They differ mainly in the placement of the emitter and receiver and how the light reaches the receiver.

2. Basic Operating Principle

A photoelectric sensor emits light toward a target or reflector and monitors the received light.

The emitter may use visible red light, infrared light, or another specified wavelength. The receiver converts the received light into an electrical signal. The sensor's detection circuit evaluates that signal and changes its output when the configured threshold is crossed.

Light emitter
     ↓
Light travels through the sensing arrangement
     ↓
Object changes the received light
     ↓
Receiver detects a change in light intensity
     ↓
Electronic detection circuit evaluates the signal
     ↓
Output circuit switches
     ↓
PLC input changes state

Depending on the sensor arrangement, the target may interrupt a beam, reflect light toward the receiver, or reflect light back from its own surface.

Important: A photoelectric sensor does not necessarily detect an object because the object is opaque. Detection depends on the light path, target reflectivity, wavelength, geometry, background, and sensor design.

3. Main Internal Components

Component Function
Light emitter Produces the sensing light
Optical lens Directs or collects light
Photodetector Converts received light into an electrical signal
Amplifier and signal-conditioning circuit Processes the receiver signal
Detection threshold circuit Determines whether the received light represents the configured state
Output stage Provides a switching or specified analog output
Status indicator Shows power, output, or alignment status, depending on the model
Sensitivity adjustment Allows threshold adjustment on supported models
Housing and optical window Protect the sensor and optical path

Many industrial photoelectric sensors use modulated light and corresponding receiver electronics to help distinguish the sensor's own emitted signal from ambient light. The actual implementation depends on the product.

4. The Three Main Photoelectric Arrangements

4.1 Through-Beam Sensor

A through-beam arrangement uses a separate emitter and receiver positioned opposite each other.

The emitter continuously or periodically sends light toward the receiver. When an object enters the path, it blocks or sufficiently reduces the received light.

Emitter  ───────────────→  Receiver
              ↑
        Object blocks beam

Operating sequence

  1. The emitter sends light toward the receiver.
  2. The receiver detects sufficient light.
  3. An object enters the path.
  4. The received light drops below the detection threshold.
  5. The output changes state.

Advantages

  • Generally offers long sensing distances.
  • Provides a strong optical signal under suitable alignment.
  • Often works well with small objects and fast-moving targets.
  • Detection is less dependent on the target's reflectivity than diffuse sensing.
  • Can be suitable for dirty industrial environments when correctly selected and maintained.

Limitations

  • Requires separate emitter and receiver mounting positions.
  • Requires alignment between the two units.
  • Wiring and mechanical installation may be more involved.
  • The optical path must remain unobstructed except for the intended target.
  • Transparent targets may not interrupt the beam sufficiently without a suitable sensor design.

Typical applications

  • High-speed part counting.
  • Conveyor object detection.
  • Detecting components across a machine opening.
  • Monitoring the passage of products between stations.
  • Detecting small objects that reliably interrupt the beam.

4.2 Retroreflective Sensor

A retroreflective arrangement combines the emitter and receiver in one sensor housing. A separate reflector returns the emitted light toward the sensor.

Sensor  ───────────────→  Reflector
Sensor  ←───────────────  Reflected light

Object enters the path and interrupts the returned light.

Operating sequence

  1. The sensor emits light toward the reflector.
  2. The reflector returns light toward the sensor.
  3. The receiver detects the returned light.
  4. An object interrupts the optical path.
  5. The receiver detects reduced returned light and the output changes state.

Advantages

  • Emitter and receiver are housed in one unit.
  • Requires less wiring than a separate through-beam pair.
  • Usually easier to install than through-beam sensing.
  • Can provide longer sensing distances than typical diffuse arrangements.
  • Suitable for many conveyor and packaging applications.

Limitations

  • Requires a reflector and correct alignment.
  • Reflector contamination or damage can affect detection.
  • Highly reflective targets can cause false detection in some arrangements.
  • Transparent objects may not reliably interrupt the returned beam.
  • Polarized retroreflective models may be needed for reliable detection of reflective targets.

Typical applications

  • Carton detection.
  • Conveyor product detection.
  • Packaging machinery.
  • Object counting.
  • Detecting products passing through a defined optical path.

4.3 Diffuse-Reflective Sensor

A diffuse-reflective arrangement contains the emitter and receiver in the same housing. The emitted light reaches the target and some of the reflected light returns to the receiver.

Sensor  ───────────────→  Target
Sensor  ←───────────────  Reflected light

The target itself provides the reflected light.

Operating sequence

  1. The sensor emits light toward the sensing area.
  2. The light reaches the target.
  3. Some light reflects back toward the sensor.
  4. The receiver detects the returned light.
  5. The electronic circuit determines whether the detection threshold has been crossed.

Advantages

  • No separate reflector is required.
  • Only one sensor unit needs to be installed.
  • Wiring and mounting are often simple.
  • Useful for detecting objects in compact machine arrangements.

Limitations

  • Sensing distance depends strongly on target reflectivity.
  • Dark or light-absorbing surfaces may be difficult to detect.
  • Background objects may cause false detection.
  • Object angle, shape, and surface finish can affect the returned light.
  • Transparent objects may be difficult to detect with standard diffuse sensors.

Typical applications

  • Detecting objects near a conveyor.
  • Checking the presence of a component at a station.
  • Detecting packaging materials.
  • Detecting products where a reflector cannot be installed.

5. Comparison of the Three Arrangements

Feature Through-beam Retroreflective Diffuse-reflective
Emitter and receiver Separate units Same housing Same housing
Reflector required No Yes No
Target interrupts a return path Blocks direct beam Blocks reflected beam Changes reflected light from target
Typical sensing distance Long Medium to long Shorter, application-dependent
Target reflectivity dependence Relatively low Usually lower than diffuse, but optical effects matter High
Alignment effort Higher Moderate Usually simpler
Transparent target detection May require specialized setup Often requires specialized setup Often requires specialized setup
Common use Long-distance beam interruption Conveyor and packaging detection Local object presence detection

These are general comparisons. Exact range, response, and detection reliability depend on the sensor model and target conditions.

6. Other Photoelectric Sensor Variants

6.1 Background Suppression

A background-suppression sensor uses optical or electronic techniques to distinguish a target at the intended distance from objects farther behind it.

This helps when the target passes in front of a machine frame or conveyor structure.

Applications include:

  • Detecting a component on a conveyor without detecting the belt or frame.
  • Detecting products at a controlled distance.
  • Reducing false triggers from the background.

Background suppression is not the same as perfect immunity to all background conditions. The specified operating range and background characteristics still matter.

6.2 Foreground Suppression

Foreground suppression is designed to reduce the effect of objects within a specified near-field region, allowing detection to be focused farther away. Availability and behavior depend on the sensor design.

6.3 Polarized Retroreflective Sensors

A polarized retroreflective sensor uses optical polarization to help distinguish the intended reflector return from unwanted reflections from many shiny objects.

This is useful when detecting metal or glossy packaging near reflective machine surfaces.

It does not guarantee reliable detection of every reflective or transparent object. Target geometry and the sensor's optical design still matter.

6.4 Transparent-Object Sensors

Standard photoelectric sensors may struggle with clear glass, transparent plastic, and clear film because much of the light may pass through the target.

Specialized sensors may use particular wavelengths, optical arrangements, or signal processing to improve transparent-object detection.

Use a sensor specifically rated for the intended transparent target rather than assuming that any retroreflective or diffuse model will work.

6.5 Fiber-Optic Photoelectric Sensors

Fiber-optic sensors use optical fibers to carry light between a separate amplifier and a small sensing point.

They are useful when:

  • Installation space is limited.
  • The sensing point is difficult to access.
  • The sensor electronics must be located away from a hot or constrained area.
  • A small detection area is required.

The sensing distance and target capability depend on the amplifier and fiber arrangement.

7. Light-ON and Dark-ON Operation

Light-ON and dark-ON describe how the sensor output responds to the received light condition. They do not simply mean that the target is present or absent.

7.1 Light-ON

A light-ON configuration typically activates its output when sufficient light is received.

7.2 Dark-ON

A dark-ON configuration typically activates its output when the received light falls below the relevant threshold.

For example, in a through-beam arrangement:

Condition Received light Typical light-ON output Typical dark-ON output
Beam clear High ON OFF
Beam blocked Low OFF ON

The exact state convention and available settings vary by manufacturer. Verify the product's output logic.

This distinction matters because a sensor can detect an object correctly while its output behaves opposite to what the PLC program expects.

8. Wiring and PLC Integration

Many industrial photoelectric sensors use 24 V DC three-wire wiring, although two-wire, four-wire, connector-based, relay-output, and other designs are available.

A common three-wire DC colour convention is:

  • Brown: positive supply.
  • Blue: 0 V.
  • Black: output.

Some four-wire models provide an additional output or configuration function. Always check the wiring diagram for the exact model.

8.1 PNP Sensor

A typical PNP connection is:

Brown wire  → +24 V DC
Blue wire   → 0 V DC
Black wire  → PLC digital input
PLC common  → 0 V DC

When active, the PNP output typically supplies positive voltage to the input circuit.

8.2 NPN Sensor

A typical NPN connection is:

Brown wire  → +24 V DC
Blue wire   → 0 V DC
Black wire  → PLC digital input
PLC common  → +24 V DC

When active, the NPN output typically pulls the signal toward 0 V.

Confirm that the PLC input module supports the intended arrangement.

8.3 Signal Path

Object enters sensing area
        ↓
Optical signal changes
        ↓
Photoelectric receiver evaluates light
        ↓
Sensor output switches
        ↓
PLC digital input changes
        ↓
PLC logic evaluates the condition
        ↓
Machine sequence responds

8.4 PLC Logic Example

Suppose a photoelectric sensor detects a carton approaching a station.

IF Carton_Detected THEN
    Carton_Count := Carton_Count + 1;
END_IF;

This is a conceptual example, not production-ready code. If the input remains ON for several PLC scans, the counter could increment repeatedly. A rising-edge instruction or equivalent one-shot logic is normally required to count each passage once.

Additional considerations include:

  • Input filtering.
  • Pulse duration.
  • PLC scan time.
  • High-speed counter requirements.
  • Sensor switching frequency.
  • Object spacing.
  • Light-ON or dark-ON configuration.

9. Response Time and High-Speed Detection

Photoelectric sensors are often used for fast counting, but the complete system must be fast enough to capture the target event.

The relevant factors include:

  • Sensor response time.
  • Switching frequency.
  • Target speed.
  • Target length along the direction of travel.
  • Gap between adjacent objects.
  • PLC input filtering.
  • PLC scan or input-update behavior.
  • Communication update time, where remote I/O is used.

9.1 Example

A conveyor moves small components past a photoelectric sensor. If the components pass quickly and the sensor produces short output pulses, a standard PLC input filter may suppress those pulses.

The sensor may work correctly, but the PLC can miss the events.

Possible corrective actions include:

  • Selecting a sensor with suitable response characteristics.
  • Reducing excessive input filtering where appropriate.
  • Using a high-speed input or counter.
  • Improving target spacing.
  • Verifying the complete timing path.

Never assume that a sensor's maximum switching frequency alone guarantees correct counting by the PLC.

10. Optical Alignment and Installation

10.1 Through-Beam Alignment

The emitter and receiver must be aligned so the receiver receives the intended light signal.

Check:

  • Horizontal and vertical alignment.
  • Mounting stability.
  • Distance between the two units.
  • Optical-window cleanliness.
  • Vibration.
  • Obstructions.
  • Correct operating range.

Poor alignment can reduce the received signal and cause unstable switching.

10.2 Retroreflective Alignment

The sensor must point toward the reflector within the specified alignment tolerance.

Check that:

  • The reflector is the correct type.
  • The reflector is clean and undamaged.
  • The sensing path is clear.
  • The reflector is securely mounted.
  • The sensor is aligned after mechanical maintenance.

A reflector that looks visually aligned may still produce insufficient return light if its angle or distance is incorrect.

10.3 Diffuse-Reflective Alignment

The target must reflect sufficient light toward the sensor.

Check:

  • Target colour and surface finish.
  • Target angle.
  • Distance from the sensor.
  • Background position.
  • Variation between different target types.
  • Whether the target passes through the intended detection zone.

A sensor tested on a white carton may behave differently when the production line switches to a black or glossy carton.

11. Environmental Effects

11.1 Dust and Contamination

Dust, oil, coolant, and residue can reduce light transmission through the optical window or reflector.

Corrective measures include:

  • Cleaning optical surfaces using approved methods.
  • Checking protective covers.
  • Selecting an appropriate ingress-protection rating.
  • Using models designed for the process environment.
  • Inspecting contamination patterns during preventive maintenance.

11.2 Ambient Light

Strong external light may affect some installations, although many industrial sensors use modulation and filtering to reduce this problem.

If false switching occurs near welding equipment, sunlight, or strong industrial lighting, check the sensor's ambient-light specification and mounting conditions.

11.3 Reflective Backgrounds

Shiny metal surfaces can reflect emitted light toward the receiver.

This may cause a diffuse sensor to detect the background instead of the intended object, or may interfere with some retroreflective arrangements.

Possible remedies include:

  • Repositioning the sensor.
  • Changing the detection angle.
  • Using a background-suppression model.
  • Using a suitable polarized retroreflective sensor.
  • Selecting a through-beam arrangement where practical.

11.4 Vibration and Mechanical Movement

A vibrating bracket can change the beam alignment or target distance.

Secure the mounting, protect cables, and verify alignment during normal machine movement.

12. Common Faults and Troubleshooting

Symptom Possible cause Diagnostic approach
Sensor never detects target No supply, incorrect alignment, wrong distance, or unsuitable target Verify power, geometry, and target suitability
Sensor remains ON with no target Background reflection, incorrect output mode, or wiring fault Inspect the background and verify light-ON/dark-ON behavior
Sensor LED changes but PLC input does not Wiring, PNP/NPN incompatibility, PLC common, or input fault Measure output and inspect PLC input status
Through-beam sensor switches intermittently Poor alignment, vibration, contamination, or partial obstruction Clean optical surfaces and verify alignment
Retroreflective sensor fails Reflector damaged, dirty, misaligned, or unsuitable Check reflector type, condition, and alignment
Diffuse sensor detects some products but not others Different reflectivity, colour, angle, or target size Test representative production targets and select suitable sensing technology
Transparent object is missed Light passes through or reflects inadequately Use a sensor designed for the transparent target
False detection from shiny objects Specular reflection or optical interference Reposition sensor or choose a suitable optical arrangement
Counts multiple times per object Output remains active over several scans or signal oscillates Use edge detection and investigate sensor stability
Fast objects are missed Response time or PLC input processing is insufficient Review sensor speed, pulse duration, filtering, and input hardware
Sensor fails after cleaning Moisture, chemical incompatibility, or damaged optical window Inspect the surface and verify cleaning compatibility
Detection changes with distance Target moved outside reliable sensing range Check mounting, product position, and operating margin

12.1 Step-by-Step Troubleshooting

  1. Identify the sensor model and arrangement.
  2. Verify the supply voltage.
  3. Check the sensor's power and output indicators.
  4. Confirm emitter-receiver alignment or reflector alignment.
  5. Clean the optical windows and reflector using approved methods.
  6. Inspect the target material, colour, surface, and orientation.
  7. Check the light-ON/dark-ON setting.
  8. Measure the output and verify the PLC input.
  9. Check PLC filtering, input mapping, and edge-detection logic.
  10. Observe the sensor during actual machine operation.
  11. Record the root cause and corrective action.

Do not replace a sensor before checking alignment, contamination, target suitability, wiring, and PLC logic.

13. Sensor Selection Guide

Application requirement Suitable starting point
Long-distance detection with access to both sides Through-beam
Object detection with one sensor and a reflector Retroreflective
Local object detection without a reflector Diffuse-reflective
Target detection in front of a machine background Background-suppression sensor
Shiny targets that may cause unwanted reflection Evaluate polarized retroreflective or suitable background-suppression models
Transparent bottles or clear film Dedicated transparent-object sensor
Very small target in restricted space Suitable fiber-optic or miniature photoelectric sensor
High-speed object counting Sensor with suitable response and compatible high-speed input processing

13.1 Selection Parameters

Before selecting a part number, verify:

  • Sensing arrangement.
  • Required sensing distance.
  • Target size, colour, transparency, and surface finish.
  • Required switching frequency.
  • Response time.
  • Supply voltage.
  • PNP/NPN or other output type.
  • NO/NC or light-ON/dark-ON behavior.
  • Ambient-light tolerance.
  • Ingress protection and temperature range.
  • Mounting dimensions.
  • Connector and cable requirements.
  • Compatibility with the PLC input circuit.

14. Applications in Automotive Manufacturing

14.1 Conveyor Part Detection

Photoelectric sensors detect components as they pass a fixed point. The PLC can count products or trigger the next machine operation.

14.2 Presence Confirmation Before Robot Picking

A sensor detects whether a component is present at a pick station. The PLC can use this information to coordinate with the robot.

A single presence signal does not necessarily prove that the component is correctly positioned or securely gripped. Those conditions may require separate checks.

14.3 Packaging and Container Detection

Photoelectric sensors detect cartons, trays, bottles, and packaging materials. The appropriate arrangement depends on target transparency, surface reflectivity, distance, and background.

14.4 Part Counting

The sensor produces a transition as each object passes through the sensing area. PLC edge detection or a high-speed counter can convert the transitions into counts.

14.5 Machine Station Transfer

Photoelectric sensors can confirm that a component or carrier has reached a station, helping coordinate conveyors, indexing systems, and assembly processes.

14.6 Safety Applications

Ordinary photoelectric proximity sensors are not automatically safety devices.

Personnel protection requires equipment specifically designed and certified for the safety function, such as an appropriate safety light curtain or other safety-rated system, together with a validated safety architecture.

15. Preventive Maintenance Checklist

  • Inspect the sensor housing and optical window.
  • Clean the sensing surface and reflector where applicable.
  • Verify emitter-receiver or reflector alignment.
  • Inspect mounting brackets and fasteners.
  • Check cable routing, connectors, and strain relief.
  • Confirm that the sensor output and PLC input agree.
  • Test representative target types.
  • Verify sensitivity or operating-mode settings.
  • Review missed counts and intermittent detection alarms.
  • Check the sensor's environmental suitability.
  • Confirm compatibility when replacing the sensor.
  • Record the sensor model, location, settings, and test results.

For critical applications, validate detection under realistic operating conditions, including the actual target range, speed, and expected contamination.

16. Interview Questions and Answers

Q1. What is a photoelectric sensor?

A sensor that detects an object by emitting light and evaluating the light received by a photodetector.

Q2. What is the difference between through-beam and retroreflective sensing?

Through-beam sensing uses a separate emitter and receiver facing each other. Retroreflective sensing houses the emitter and receiver together and uses a reflector to return the light.

Q3. How does a diffuse photoelectric sensor work?

It emits light toward the target and detects a portion of the light reflected from the target back to the sensor.

Q4. Which arrangement usually provides the longest sensing distance?

Through-beam arrangements generally support longer distances than comparable retroreflective or diffuse arrangements, subject to the specifications of the actual products.

Q5. Why might a diffuse sensor fail to detect a black object?

A dark surface may return less light to the receiver. Whether detection succeeds depends on the sensor's optical design, distance, target size, and detection threshold.

Q6. What is light-ON versus dark-ON?

Light-ON typically activates the output when sufficient light is received. Dark-ON typically activates the output when received light falls below the specified threshold.

Q7. Why can shiny targets cause false detection?

Their surfaces may reflect light toward the receiver in an unintended way. Sensor orientation, target geometry, and the optical arrangement influence the result.

Q8. Why does a sensor LED change while the PLC input does not?

Possible causes include incompatible output wiring, incorrect PLC common connections, input-channel faults, or incorrect PLC input mapping.

Q9. Why are high-speed counters sometimes required?

Short sensor pulses may be missed by ordinary input processing due to input filtering, scan timing, or update delays. A suitable high-speed input can capture events that standard processing might miss.

Q10. Can any photoelectric sensor detect transparent objects?

No. Transparent objects may not sufficiently interrupt or reflect the light used by standard sensors. Specialized transparent-object sensors may be required.

17. Practical Exercises

Exercise 1: Identify the Sensing Arrangement

Find a photoelectric sensor installed on a machine and determine whether it is through-beam, retroreflective, diffuse-reflective, or another variant.

Record:

  • Manufacturer and model.
  • Sensing arrangement.
  • Sensing distance.
  • Output type.
  • Light-ON/dark-ON behavior.
  • Supply voltage.
  • PLC input address.
  • Target material and detection purpose.

Exercise 2: Trace a Conveyor Sensor

Trace the signal from the object to the PLC program.

Object movement
      ↓
Optical detection
      ↓
Sensor output
      ↓
PLC digital input
      ↓
Edge detection or sequence logic
      ↓
Counter or machine action

Identify where the signal could be lost or interpreted incorrectly.

Exercise 3: Investigate Missed Counts

For a controlled test or documented production fault:

  • Observe the sensor LED.
  • Check target spacing and speed.
  • Verify the sensor's response capability.
  • Monitor the PLC input.
  • Check input filtering and counter logic.
  • Record whether the fault originates in optical detection or PLC processing.

Exercise 4: Compare Sensor Arrangements

Evaluate through-beam, retroreflective, and diffuse arrangements for a carton-detection application.

Compare mounting effort, sensing distance, target reflectivity, background interference, and maintenance access. Select the arrangement that best meets the actual process requirements.

18. Final Mental Model

Photoelectric sensors convert changes in received light into electrical switching signals.

The key difference between the main arrangements is how the light reaches the receiver:

  • Through-beam: The receiver monitors light sent directly from a separate emitter.
  • Retroreflective: The receiver monitors light returned from a separate reflector.
  • Diffuse-reflective: The receiver monitors light reflected from the target itself.

Reliable application depends on more than selecting a sensor with sufficient range. Alignment, target properties, optical contamination, response time, output configuration, and PLC input processing must all work together.

When troubleshooting, separate the optical problem from the electrical and PLC logic problems. That distinction prevents unnecessary sensor replacement and helps isolate the real cause of missed or false detections.
