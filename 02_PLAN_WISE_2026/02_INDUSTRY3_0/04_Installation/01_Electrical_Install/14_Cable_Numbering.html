1. Definition and purpose

Cable numbering is the systematic assignment of a unique identification number or code to a cable so that it can be identified, traced, installed, tested, maintained, and replaced correctly.

In industrial automation, a cable connects electrical or electronic equipment such as PLCs, remote I/O modules, VFDs, servo drives, motors, sensors, junction boxes, CNC controllers, industrial switches, and operator panels.

Cable numbering links the physical installation to the electrical drawings, cable schedules, terminal plans, network diagrams, maintenance records, and troubleshooting procedures.

A cable number should help a technician answer these questions:

  • Which cable is this?
  • Where does it originate?
  • Where does it terminate?
  • What function does it perform?
  • Which drawing and cable schedule describe it?
  • Which terminals, connectors, or devices are involved?
  • Has the cable been tested, modified, or replaced?

Cable numbering is not merely printing a label. It is part of the installation's engineering information system.

2. Difference between cable numbering, wire numbering, and terminal numbering

These three identification systems are related but represent different objects.

Identification Identifies Example
Cable number A complete cable assembly or cable run CB-PLC-001
Wire or conductor number An individual conductor or electrical connection W-0245
Terminal number A connection point on a terminal block or device X1:15
Device tag A physical electrical device MTR-01
Connector identification A plug, socket, or connector interface X2
Network node identification A device or communication endpoint PLC-01

For example, a multi-core cable may carry several separately identified conductors. The cable has one cable number, while each conductor may have its own wire number according to the documentation standard.

Cable: CB-PLC-001
    ↓
Source: PLC Cabinet
    ↓
Destination: Field Junction Box
    ↓
Conductors: W-0245, W-0246, W-0247, W-0248
    ↓
Terminals: X1:15, X1:16, X1:17, X1:18

The identifiers in this example are illustrative. Actual numbering conventions depend on the site's engineering standard.

3. Why cable numbering matters

3.1 Installation accuracy

Cable numbers help installers connect the correct cable to the intended source and destination.

Without a consistent identification system, two similar cables may be connected incorrectly, especially when several machines, sensors, and drives are installed together.

3.2 Troubleshooting

During a breakdown, a technician can identify the cable physically and trace it to the correct drawing or cable schedule.

This reduces the need to follow a cable manually through multiple trays, ducts, junction boxes, and panels.

3.3 Maintenance and replacement

A numbered cable can be traced to its specification, length, route, termination details, and test records.

This is useful when replacing a damaged motor cable, encoder cable, communication cable, or sensor cable.

3.4 Modification control

When a new device or cable is added, the numbering system helps prevent duplicate identifiers and ensures the documentation remains consistent.

3.5 Safety

Correct cable identification supports safe isolation, circuit verification, and maintenance planning. However, a cable label is not proof that the cable is de-energized. Electrical isolation and verification must follow the approved safety procedure.

4. Cable numbering architecture

A typical engineering identification structure is:

Electrical Design
      ↓
Cable Schedule
      ↓
Unique Cable Number
      ↓
Physical Cable Labels
      ↓
Source and Destination Terminations
      ↓
Inspection and Test Records
      ↓
As-Built Drawings and Maintenance Records

All these elements should agree. A label that differs from the cable schedule or schematic can create the same troubleshooting problems as a missing label.

5. Cable numbering conventions

There is no single universal cable-number format used by every industrial plant. A project may use a simple sequential system or a structured identifier containing information about the machine, function, panel, or cable category.

5.1 Sequential numbering

Examples:

  • CB-0001
  • CB-0002
  • CB-0003

Advantages:

  • Simple to generate.
  • Easy to check for duplicates.
  • Independent of changes to equipment names.
  • Suitable for many installations.

Limitations:

  • The number does not reveal the cable's function.
  • The cable schedule is required to understand the connection.

5.2 Functional numbering

Examples:

  • CB-MTR-001
  • CB-PLC-014
  • CB-NET-003
  • CB-ENC-002

These identifiers include a function or cable category.

Advantages:

  • Easier to recognize during inspection.
  • Can help organize cable schedules.
  • Useful in maintenance-oriented installations.

Limitations:

  • Abbreviations must be standardized.
  • Changes in function may make a descriptive number misleading.
  • Duplicate prevention still requires a controlled register.

5.3 Machine or area-based numbering

Examples:

  • A01-CB-001
  • A02-CB-001
  • RB01-CB-025

Here, A01, A02, and RB01 could represent areas, stations, or robot cells under a project-defined naming convention.

This approach is useful for large assembly lines with multiple stations and machine zones.

5.4 Structured cable numbering

A project may combine area, cable category, and sequence.

Example:

A01-PWR-001

Possible interpretation:

  • A01: Area or station.
  • PWR: Cable category.
  • 001: Sequential identifier.

The format is only an example. A structured code should be documented and consistently applied across the project.

6. Rules for designing a numbering system

A robust numbering system should follow these principles.

  • Uniqueness: Each cable identifier must uniquely identify the intended cable object within the defined numbering scope.
  • Consistency: Apply the same format throughout the installation.
  • Readability: Use identifiers that can be read easily on physical labels.
  • Stability: Avoid encoding information that changes frequently unless the project standard requires it.
  • Traceability: Every cable number should connect to the cable schedule and relevant drawings.
  • Scalability: Allow new cables to be added without renumbering unrelated existing cables.
  • Controlled abbreviations: Maintain a standard list of approved codes.
  • Revision control: Record approved changes and preserve historical traceability.
  • Duplicate prevention: Use a controlled register or engineering database.
  • Physical suitability: Ensure labels remain readable under the installation's temperature, oil, coolant, dust, UV, and vibration conditions.

A cable number should not depend on undocumented assumptions known only to the original installer.

7. Cable number versus cable function

A common design decision is whether the cable number should encode the cable's function.

Consider these two identifiers:

  • CB-0085
  • A01-MTR-0085

The first is a neutral unique identifier. Its meaning is found in the cable schedule.

The second appears to encode an area and function, but that information must still be verified against the documentation.

For long-lived industrial systems, a stable unique identifier is often easier to manage than a number that must change whenever equipment is renamed or reassigned.

The project should decide which information belongs in the identifier and which belongs in the cable schedule.

8. Cable numbering and cable schedules

The cable schedule is the controlled engineering record connecting cable identifiers with their technical details.

Typical fields include:

Field Purpose
Cable number Unique cable identifier
Source equipment Originating device or panel
Source terminal Starting connection point
Destination equipment Receiving device or panel
Destination terminal Ending connection point
Cable type Construction and application
Number of cores Available conductors
Conductor size Cross-sectional area
Shielding Shield construction or requirement
Cable length Planned or recorded installed length
Route Tray, conduit, duct, or machine route
Voltage or circuit class Electrical classification
Function Power, control, feedback, or communication
Drawing reference Related schematic or layout
Test status Required inspection or test completion
Revision status Current approved document revision

Actual schedule fields depend on the project. Large installations may maintain additional details such as connector type, gland type, spare cores, fire rating, network specification, and supplier part number.

9. Cable numbering examples for industrial automation

9.1 PLC to remote I/O communication

A communication cable connects a PLC cabinet to a remote I/O station.

Item Example
Cable number CB-NET-001
Source PLC-01
Destination RIO-01
Function Industrial Ethernet
Cable type Specified industrial Ethernet cable
Route Network tray
Documentation Network topology and cable schedule

The cable number identifies the physical cable, while the device tags identify the endpoints.

9.2 VFD to motor

Item Example
Cable number CB-MTR-001
Source VFD-01
Destination MTR-01
Function Motor power
Cable type Drive-compatible motor cable
Route Designated motor cable route
Documentation Drive schematic and cable schedule

For drive output cables, the schedule should record relevant specifications such as cable construction and any applicable length restrictions.

9.3 Analog transmitter to PLC

Item Example
Cable number CB-ANA-001
Source PT-01
Destination PLC-01 analog input
Function Pressure measurement
Signal 4–20 mA
Cable type Specified instrumentation cable
Route Instrumentation route
Documentation Instrument loop drawing and I/O list

A cable number does not replace the instrument tag, PLC channel reference, or signal description.

9.4 Servo motor and feedback

A servo system may have separate cables for motor power, encoder feedback, brake wiring, and communication.

Each physical cable or assembly should be identified according to the project convention. Do not assume that all servo-related wiring belongs under a single cable number.

10. Cable numbering at both ends

A cable should normally be identifiable at both ends where the installation standard requires it.

This is especially useful when:

  • Several similar cables enter the same cabinet.
  • A cable runs through a long tray.
  • A cable terminates in a remote junction box.
  • Equipment is moved or replaced.
  • Troubleshooting must be performed from either end.

For long or complex routes, intermediate identification may also be necessary at accessible junctions or route locations.

Label placement should remain visible after the cable is installed and should not interfere with connector locking, gland sealing, bend radius, or maintenance access.

11. Cable identification methods

Common methods include:

  • Printed cable markers.
  • Wraparound labels.
  • Heat-shrink markers.
  • Marker sleeves.
  • Cable tags.
  • Durable self-laminating labels.
  • Engraved or industrial identification plates for suitable assemblies.

Select the method based on cable diameter, installation environment, expected service life, and site requirements.

Label type Typical consideration
Printed wraparound marker Convenient for many control cables
Heat-shrink marker Requires suitable installation equipment and dimensions
Self-laminating label Can protect printed information when correctly applied
Durable cable tag Useful for larger cables and demanding routes
Engraved marker Useful where a durable rigid marker is appropriate

Check label adhesion, legibility, temperature rating, resistance to oil or coolant, and suitability for outdoor exposure where relevant.

12. Cable numbering and wire numbering in a multi-core cable

Consider a four-core cable between a junction box and a PLC cabinet.

Cable Number: CB-0042

Source: JB-01
Destination: PLC-01

Core 1: Wire W-1001
Core 2: Wire W-1002
Core 3: Wire W-1003
Core 4: Wire W-1004

The cable number identifies the complete cable. The wire numbers identify individual conductors when the design uses conductor-level numbering.

In some projects, core numbers and wire numbers are handled differently. A core number may identify the physical core within the cable, while a wire number identifies its electrical connection in the schematic.

Follow the project's convention rather than treating these terms as interchangeable.

13. Spare cores and unused cables

Unused cores and spare cables should be managed according to the design and site procedure.

Good practices include:

  • Identify spare cores where required.
  • Terminate, insulate, or park unused cores according to the approved procedure.
  • Prevent exposed conductors from contacting adjacent terminals.
  • Record spare-core allocation in the cable schedule where applicable.
  • Preserve unused capacity only when the cable and circuit design permits it.
  • Update documentation when a spare core is assigned to a new function.

Never assume an unused conductor is safe to touch merely because it is not currently connected. Verify its condition and isolation according to the approved procedure.

14. Cable numbering and terminal plans

A terminal plan records the terminal points used to connect field wiring and panel wiring.

Example:

Cable number Source Destination Terminal reference
CB-ANA-001 PT-01 JB-01 X1:01
CB-ANA-001 JB-01 PLC-01 AI0+ / AI0-
CB-NET-001 PLC-01 RIO-01 Ethernet port P1

This example illustrates a cable path with an intermediate junction. A real cable schedule must clearly distinguish separate cable sections from a single continuous cable assembly.

Terminal references must match the physical labels and approved drawings.

15. Cable numbering and network documentation

Communication cables often need more information than a simple cable number.

Depending on the network, record:

  • Source and destination devices.
  • Port numbers.
  • Cable category or optical-fiber type.
  • Connector type.
  • Network name or segment.
  • Route.
  • Link length where relevant.
  • Shielding or bonding requirements.
  • Commissioning status.

For example, CB-NET-001 may connect SW-01:P08 to PLC-01:ENET1.

This identifies both physical endpoints, but the network topology and IP-address plan remain separate documentation items.

Cable numbers should not be confused with IP addresses, MAC addresses, PLC tag names, or switch-port numbers.

16. Cable numbering during installation and commissioning

A controlled process helps prevent duplicate numbers and mismatched documentation.

  1. Establish the project numbering standard.
  2. Assign a unique identifier in the cable register.
  3. Enter the cable details in the cable schedule.
  4. Reference the cable on the applicable drawings.
  5. Print and apply the physical cable markers.
  6. Verify source and destination before termination.
  7. Inspect the cable identification at both ends.
  8. Perform the required electrical or communication tests.
  9. Record the result and update the status.
  10. Update the as-built documents following approved changes.

Where possible, assign the cable number during design rather than after installation. Retrofitting identification onto an undocumented cable network creates avoidable tracing work.

17. Cable numbering change management

Industrial plants are modified over many years. New sensors, PLCs, drives, and communication devices are routinely added.

A numbering system must support these changes without destroying traceability.

Recommended practices:

  • Maintain one controlled cable register.
  • Check for duplicates before assigning a new number.
  • Record the source and destination.
  • Update drawings and schedules together.
  • Preserve historical identifiers where the project standard requires it.
  • Record removed, abandoned, or replaced cables.
  • Document approved rerouting and termination changes.
  • Verify physical labels after modification.
  • Keep the current approved revision accessible to maintenance personnel.

Do not reuse a retired cable number casually. A reused identifier can make historical drawings, breakdown reports, and maintenance records ambiguous.

18. Cable numbering in SAP and maintenance systems

In an industrial maintenance environment, cable identifiers can be linked to equipment records and work orders where the site's SAP or asset-management structure supports it.

Possible relationships include:

  • Cable number to functional location.
  • Cable number to source and destination equipment.
  • Cable number to electrical drawing.
  • Cable number to maintenance notification.
  • Cable number to work order.
  • Cable number to test report.
  • Cable number to replacement material or cable specification.

A practical maintenance record might contain:

Field Example
Cable number CB-MTR-001
Functional location Machine station defined in SAP
Related equipment VFD-01, MTR-01
Fault description Motor cable jacket damaged
Corrective action Cable replaced and terminations inspected
Test result Required checks completed
Documentation Cable schedule and drawing revision updated

The exact implementation depends on the plant's asset hierarchy and SAP configuration. Cable numbering should complement the equipment and functional-location system rather than create a conflicting identification scheme.

19. Common cable-numbering mistakes

Mistake Consequence Correct practice
Duplicate cable numbers Incorrect tracing and maintenance records Use a controlled register
Label only at one end Difficult identification from the other end Label both ends where required
Cable schedule not updated Physical installation disagrees with documentation Update records after approved changes
Cable number confused with wire number Incorrect circuit tracing Define each identifier clearly
Label placed where it cannot be seen Longer troubleshooting Position markers for practical access
Unreadable or damaged marker Loss of traceability Use suitable durable identification
Number changed without recording the old one Historical records become ambiguous Apply controlled revision and change procedures
Function encoded incorrectly in the number Misleading identification Keep naming rules stable and documented
Spare core not recorded Uncertain future use Document spare-core allocation
Device tag used as the cable number Ambiguity when multiple cables connect the same device Give each cable its own identifier
Connector port omitted from network records Difficult network troubleshooting Record endpoint and port details

20. Troubleshooting using cable numbers

When a fault occurs, cable numbering provides a starting point for structured investigation.

Example: Remote I/O station offline

  1. Identify the communication cable number at the remote I/O station.
  2. Locate the cable in the cable schedule.
  3. Confirm the source switch, destination device, and port numbers.
  4. Trace the physical route and inspect connectors.
  5. Check the relevant network diagnostics.
  6. Verify cable type, length, and installation requirements.
  7. Test or replace the cable if justified by the results.
  8. Record the findings and update the maintenance record.

Example: Motor fails to start after cable replacement

  1. Verify the cable number against the approved drawing.
  2. Confirm the source drive and destination motor.
  3. Check conductor identification and terminal assignments.
  4. Verify the installed cable specification.
  5. Perform the required inspection and electrical tests.
  6. Check drive fault information and the approved motor commissioning procedure.
  7. Correct documentation if the route or cable specification changed.

Cable identification accelerates fault-finding, but it does not replace safe isolation, electrical testing, or systematic diagnosis.

21. Practical cable-numbering quality checklist

Design and documentation

  • A documented numbering convention exists.
  • Every cable has a unique identifier within the defined scope.
  • Cable numbers match the cable schedule.
  • Source and destination equipment are recorded.
  • Terminal or connector references are available where required.
  • Cable specifications and route details are documented.
  • The applicable drawing revision is recorded.

Installation

  • Labels are correct and readable.
  • Both ends are identified where required.
  • Intermediate identification is provided where necessary.
  • Cable numbers match physical terminations.
  • Labels are suitable for the environment.
  • Spare cores and unused cable sections are handled according to procedure.

Commissioning and maintenance

  • Required cable tests are recorded.
  • Communication endpoints and ports are documented.
  • Modifications are reflected in the approved records.
  • Removed or replaced cables are handled in the register.
  • Current as-built documents are accessible.
  • Maintenance work orders reference the correct cable or connected equipment.

22. Standards and technical references

Cable numbering is usually defined by the project's engineering documentation rules and applicable identification standards rather than one universal cable-number format.

Relevant references may include:

  • IEC 60204-1: Electrical equipment of machines.
  • IEC 61082 series: Preparation of documents used in electrotechnology.
  • IEC 81346 series: Industrial systems, installations, equipment, and reference designations.
  • IEC 60445: Identification of equipment terminals, conductor terminations, and conductors.
  • Project electrical design standards: Cable tags, wire markers, terminal identification, and drawing conventions.
  • Plant maintenance standards: Asset identification, modification control, and record management.

These standards address different aspects of electrical documentation and identification. Confirm the applicable edition, local adoption, and project-specific rules before defining a numbering scheme.

23. Interview questions and answers

1. What is cable numbering?

Cable numbering is the assignment of a unique identifier to a cable so that it can be traced between its endpoints and linked to engineering and maintenance documentation.

2. What is the difference between cable numbering and wire numbering?

Cable numbering identifies the complete cable. Wire numbering identifies an individual conductor or electrical connection according to the project's documentation convention.

3. Why should a cable be identified at both ends?

It allows technicians to identify the cable from either endpoint, reducing tracing time and the risk of incorrect disconnection.

4. Is there one universal cable-numbering format?

No. Numbering conventions depend on the project or plant standard. The important requirements are uniqueness, consistency, traceability, and controlled documentation.

5. Can a cable number replace the equipment tag?

No. The equipment tag identifies a device, while the cable number identifies a cable. Multiple cables may connect to the same device.

6. What should a cable schedule contain?

At minimum, it typically records the cable identifier, source, destination, cable type, relevant electrical characteristics, route, and drawing reference. Additional fields depend on the installation.

7. Why is cable numbering important during a breakdown?

It helps the technician trace the correct physical cable, find its endpoints, consult the appropriate drawings, and record the repair accurately.

8. Should retired cable numbers be reused?

Not casually. Reuse can create ambiguity in historical drawings and maintenance records. Follow the controlled numbering and change-management procedure.

9. How does cable numbering help with industrial Ethernet?

It identifies the physical link and can connect the cable record to the source and destination devices, switch ports, network topology, and test results.

10. What should happen after a cable is rerouted?

The approved cable schedule, route drawings, physical identification, and relevant maintenance or commissioning records should be updated according to the site's change-control procedure.

24. Final engineering principles

  • Assign unique and stable cable identifiers.
  • Distinguish cable numbers from wire numbers, device tags, and terminal numbers.
  • Maintain a controlled cable schedule linked to electrical drawings.
  • Identify both cable ends where required.
  • Use labels suitable for the industrial environment.
  • Record network endpoints, connector ports, and relevant cable specifications.
  • Control modifications and avoid undocumented number reuse.
  • Connect cable identification to maintenance records and commissioning results.

Core principle: A cable number is valuable only when the physical label, cable schedule, electrical drawing, and maintenance record all refer to the same cable.
